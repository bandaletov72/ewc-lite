# Демо-база маркетплейса EWC Lite

В наборе 43 товара, 49 предложений и 7 разделов. Для товаров подготовлены отдельные демонстрационные фотографии.

- [catalog.json](catalog.json) содержит разделы, товары, варианты, цены, изображения и характеристики.
- [import.csv](import.csv) подходит для импорта товаров и вариантов через «Маркетплейс → Импорт». Выберите разделитель «Вертикальная черта».
- [images/](images/) содержит изображения из базы. Фотографии демонстрационные и иллюстрируют вид товара.
