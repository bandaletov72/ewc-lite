# Изменения проекта

- Сохраняйте PHP 7.2 как минимальную версию движка, админки, штатных модулей и обновлятора.
- Перед каждым выпуском проверяйте сайт, админку и установку подписанного обновления на PHP 7.2 и на актуальной стабильной версии PHP. Для новых возможностей PHP предусматривайте совместимый путь для PHP 7.2.
- При каждом добавлении или изменении функции обновляйте «Помощь» в админке, примеры вставки и Markdown-справку для всех поддерживаемых языков. Справка в поставке и на GitHub должна соответствовать опубликованной версии.
- Публикуйте проверенный полный архив и подписанное обновление движка в `bandaletov72/php-site-updates` вместе со справкой. Оставляйте рабочий контент, настройки, индексы, кеш, секретные ключи и данные пользователей вне релиза.
