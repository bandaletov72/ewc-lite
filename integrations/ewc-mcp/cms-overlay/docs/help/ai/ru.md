# ИИ: Подключить ChatGPT

Выберите способ подключения к редактору этого сайта. Настройку можно открыть позже во вкладке «ИИ».

## ChatGPT через Secure MCP Tunnel

1. В OpenAI Platform создайте отдельный туннель для сайта и ограниченный ключ Tunnels Read + Use для его запуска. Вставьте сюда только Tunnel ID.
2. На сервере установите пакет MCP и официальный клиент OpenAI. Задайте отдельный каталог черновиков и ключ в секретах службы. Запустите: `instance-from-cms.sh`.
3. В ChatGPT добавьте пользовательский MCP-сервер: название сайта, режим Tunnel и тот же Tunnel ID. Проверьте командой list_pages.

[Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)

## Прямой API EWC (без туннеля)

Для собственного клиента администратор сервера публикует MCP-вход /mcp по HTTPS и задаёт отдельный токен EWC. Передавайте его в заголовке Authorization: Bearer. По умолчанию доступ только на чтение.

Токен EWC не подходит для формы подключения ChatGPT. Для прямого доступа к закрытому редактору из ChatGPT настройте совместимый OAuth 2.1. В этом пакете OAuth не реализован. [OAuth](https://developers.openai.com/plugins/build/auth)

## Как проверить редактирование

`list_pages` → `draft_page` → `preview_draft` → явное подтверждение → `publish`.

Откройте нужную страницу в админке и сравните предпросмотр. В режиме чтения правки недоступны.
