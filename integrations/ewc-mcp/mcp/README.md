# EWC-lite MCP — прототип для отдельных установок

Один и тот же PHP-код обслуживает stdio и локальный Streamable HTTP с JSON-ответами. Названия, аргументы и схемы всех 14 инструментов оригинального архива совпадают. HTTP по умолчанию разрешает только чтение. Для проверки записи в одноразовой копии установите `EWC_MCP_TEST_WRITES=1`. Не включайте этот режим на рабочем сайте.

## Что указывать для каждой установки

| Где | Что указывать |
| --- | --- |
| Служба на сервере EWC-lite | `EWC_MCP_SITE_ROOT` (путь к файлам одной установки), `EWC_MCP_STATE_DIR` (отдельный закрытый каталог черновиков), `EWC_MCP_SITE_URL` (канонический URL сайта, в том числе подпапка). |
| Клиент Secure MCP Tunnel на том же сервере | `CONTROL_PLANE_TUNNEL_ID` и отдельный ключ `CONTROL_PLANE_API_KEY`, внедрённый из хранилища секретов хоста. |
| ChatGPT → Add custom MCP server → Tunnel | Название сайта и его `tunnel_id`. Ключ OpenAI и пароль администратора EWC-lite сюда не передаются. |

Запуск на Linux: `./instance-tunnel.sh` после настройки переменных в отдельной службе и установки официального `tunnel-client`. Можно указать путь к клиенту через `EWC_TUNNEL_BINARY` (в том числе `tunnel-client-runtime`) и к PHP через `EWC_PHP_BINARY`. Windows-пример команды stdio и запуска туннеля есть в README-STDIO.md. Для нескольких сайтов создайте разные службы и каталоги черновиков; в рабочей среде разделяйте их учётными записями ОС или контейнерами с разрешённым каталогом только своего сайта. Не принимайте путь к установке или произвольный URL из запроса MCP.

### Мастер установки и прямой доступ

Используйте [инструкцию комплекта](../README.md). Для настроек из формы «ИИ» запускайте `instance-from-cms.sh` вместо ручного задания Tunnel ID и URL. `direct.php` доступен отдельно по HTTPS для собственного клиента с Bearer-токеном. Локальный `http.php` по-прежнему используется только для тестов.

## Тестирование

Требуется чистая распакованная установка EWC-lite 1.6.93 или новее. Сами файлы CMS в ZIP не включены.
- `python3 test/verify-http.py /absolute/path/to/php /absolute/path/to/ewc-lite`: сопоставляет 14 схем через stdio и HTTP, проверяет авторизацию и изоляцию двух временных копий, черновик, предпросмотр и публикацию только в копии A.
- `node test/smoke.cjs /absolute/path/to/php /absolute/path/to/ewc-lite /absolute/path/to/scratch`: штатный тест stdio, включая страницы, магазин и темы. Для HTTP-теста магазина каталог PHP-сессий должен быть доступен на запись.

Локальный HTTP-вход: задайте переменные установки из таблицы и случайный тестовый `EWC_MCP_HTTP_TOKEN`, затем запустите `php -S 127.0.0.1:18081 http.php`. Обращайтесь к `POST /mcp` с заголовками `Authorization: Bearer …` и `Content-Type: application/json`. Это тестовый сервер только на loopback, не OAuth и не конечная версия для публичного каталога. Никакого публичного HTTP-развёртывания не выполнено.
