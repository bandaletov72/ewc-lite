# EWC-lite для ChatGPT

Приватный MCP-плагин для Eurowebcart CMS Lite. ChatGPT подготавливает изменения в диалоге. После публикации страницы, товары и темы появляются в EWC-lite и открываются в штатной админке.

| Задача | Инструменты |
| --- | --- |
| Найти нужный раздел сайта | `list_pages` |
| Создать страницу или добавить блоки в существующую | `draft_page`, `draft_add_content` |
| Создать категорию и товар в модуле магазина | `list_shop_categories`, `draft_shop_category`, `draft_shop_product` |
| Создать отдельную товарную страницу с ценой | `draft_product` |
| Создать тему оформления или обновить стили активной темы | `list_themes`, `draft_design`, `draft_restyle` |
| Собрать сайт с главной, разделами и товарными страницами | `draft_site` |
| Просмотреть предложение, применить его или переключить тему | `preview_draft`, `publish`, `draft_activate_theme` |

Блоки поддерживают обложку, текст, выделенный призыв к действию, изображения и ссылки. Тема настраивает палитру, шрифт и скругления. В качестве изображений можно указать адреса файлов из медиатеки или HTTPS-ссылки.

## Где запускать

Нужны EWC-lite 1.6.93 и PHP CLI 7.2 или новее. Запускайте плагин на машине, где ему доступны файлы этой установки. Понадобятся права PHP на штатную блокировку и каталоги, в которые нужно публиковать. Пакет не требует Composer, Node.js или базы данных. Node.js используется только для запуска приложенного теста.

Создайте отдельные каталоги для плагина и черновиков вне веб-корня. Для черновиков дайте доступ только учётной записи, под которой работает плагин. Укажите адрес сайта с префиксом, если CMS установлена в подпапку.

~~~powershell
php C:/ewc/ewc-lite-plugin/server.php C:/ewc/ewc-lite C:/ewc/private-drafts http://127.0.0.1:8000
~~~

Процесс принимает MCP-запросы через стандартный ввод и вывод. Для проверки в PowerShell отправьте запрос `initialize` по каналу ввода.

~~~powershell
'{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25"}}' |
  php C:/ewc/ewc-lite-plugin/server.php C:/ewc/ewc-lite C:/ewc/private-drafts http://127.0.0.1:8000
~~~

Ожидаемый ответ сообщит имя `ewc-lite` и возможность `tools`.

## Подключение к ChatGPT

1. Создайте Secure MCP Tunnel в OpenAI Platform для нужной рабочей области и установите `tunnel-client`. Передайте клиенту ключ с правами запуска туннеля через локальную переменную `CONTROL_PLANE_API_KEY`. Ограничьте доступ к туннелю пользователями, которым можно публиковать изменения на этом сайте. [Руководство Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)
2. Укажите команду PHP как stdio-сервер. Замените пример `tunnel_…` и пути своими значениями. Если PHP не добавлен в `PATH`, укажите полный путь к `php.exe`.

   ~~~powershell
   tunnel-client init --sample sample_mcp_stdio_local --profile ewc-lite --tunnel-id tunnel_0123456789abcdef0123456789abcdef --mcp-command 'php C:/ewc/ewc-lite-plugin/server.php C:/ewc/ewc-lite C:/ewc/private-drafts http://127.0.0.1:8000'
   tunnel-client doctor --profile ewc-lite --explain
   tunnel-client run --profile ewc-lite
   ~~~

3. В веб-версии ChatGPT откройте **Plugins → + → Add custom MCP server**. Выберите **Tunnel**, укажите ID и создайте плагин EWC-lite. Для этого приватного stdio-подключения отдельной OAuth-авторизации в CMS нет. После установки выберите **@EWC-lite** в новом чате. [Подключение собственного MCP-сервера к ChatGPT](https://developers.openai.com/api/docs/guides/custom-mcp-server)

4. Начните с запроса «Покажи главную страницу и разделы EWC-lite». Затем попросите создать черновик и показать его. Команда `publish` применяет конкретный черновик и возвращает адрес или ID темы. Плагин передаёт ChatGPT инструкции запрашивать явное подтверждение перед вызовом `publish`.

## Примеры запросов

> В разделе «Контакты» создай страницу «Как нас найти». Добавь часы работы и кнопку «Открыть карту». Покажи черновик перед публикацией.

> В магазине создай категорию «Керамика». Добавь в неё миску ручной работы, артикул CER-10, цена 1290 ₽, остаток 3. Покажи карточку и цену перед публикацией.

> Собери отдельную тему для студии керамики с главной, коллекцией и контактами. Используй тёплый фон, графитовый текст и тёмно-зелёный акцент. Предложи содержимое каждой страницы.

## Публикация и дальнейшее редактирование

- Сохранение темы добавляет её в EWC-lite. Активация выполняется отдельным черновиком. При переключении темы с собственными страницами меняется публичный набор страниц. Чтобы вернуться к прежнему набору, активируйте предыдущую тему.
- Товары магазина создаются в существующих категориях модуля «Магазин». Цена и остаток хранятся в штатных записях. Подключение способов оплаты и доставки выполняется в админке. Превью товара показывает цену с учётом текущего округления магазина.
- Самостоятельные товарные страницы используют штатную вкладку «Продажа». При создании на странице выводится цена. Кнопка покупки появляется после настройки способа оплаты.
- Черновик содержит предлагаемые поля и блоки. Открыть опубликованную страницу браузером можно по адресу из результата. Перед сменой оформления рабочего сайта можно активировать тему в отдельной тестовой установке CMS.
- Если исходная страница, тема или поколение каталога изменились после подготовки черновика, плагин потребует создать его заново. Для публикации используется штатная блокировка EWC-lite.

## Проверка

Сквозной тест запускает отдельную копию CMS и проверяет MCP, страницы, магазин, конфликты правок и переключение тем. Для него нужен Node.js 18 или новее и чистая распакованная копия EWC-lite.

~~~powershell
node test/smoke.cjs C:/php/php.exe C:/ewc/clean-ewc-lite C:/ewc/test-work
~~~

Пакет проверен на EWC-lite 1.6.93 с PHP 7.2.34 и 8.5.13. [Eurowebcart CMS Lite](https://github.com/bandaletov72/ewc-lite)
