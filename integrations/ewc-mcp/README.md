# EWC-lite: вкладка «ИИ» и MCP

В **EWC-lite 1.6.94** вкладка «ИИ» входит в подписанное обновление CMS. Установите MCP-сервер отдельно по инструкции ниже. Патч и накладка в этом каталоге предназначены только для тестовой **1.6.93**; не применяйте их поверх 1.6.94. Перед обновлением рабочего сайта сделайте резервную копию. В комплект не входят данные сайта, пароли и ключи.

## 1. Включить вкладку «ИИ»

На **1.6.94** откройте вкладку «ИИ», пропустите шаги 1–2 и продолжите с шага 3. Для тестовой установки 1.6.93 выполните все шаги.

1. Распакуйте чистую EWC-lite 1.6.93 или сделайте копию существующей тестовой установки.
2. Скопируйте содержимое `cms-overlay/` в корень этой копии с заменой файлов движка. Для изменённого движка используйте также `ewc-ai.patch`, чтобы перенести правки, не затерев свои. Прежде чем применять патч, выполните `git apply --check ewc-ai.patch` в корне сайта. Используйте только один способ.
3. Каталог `mcp/` разместите **вне публичной папки сайта**. Каждой установке нужен свой закрытый каталог черновиков вне её папки и отдельная учётная запись службы с доступом только к этой копии.
4. После создания первого администратора откроется необязательный шаг «Подключить ChatGPT». «Пропустить» продолжает обычную установку. На уже установленном сайте сразу откройте вкладку **«ИИ»** в админке. Здесь есть инструкции, те же настройки и ссылка на справку.

Канонический URL используется в ответах редактора. Он не заменяет адрес `/mcp` и не определяет, к какой папке служба имеет доступ. Путь установки задаёт администратор хостинга, а не запрос к API. Надпись «Настройки сохранены» означает сохранение полей, а не работающий туннель.

## 2. ChatGPT через Secure MCP Tunnel

1. На [OpenAI Platform](https://platform.openai.com/) создайте отдельный туннель для сайта. Для запуска выпустите ограниченный ключ с доступом **Tunnels Read + Use**. Сохраните в EWC «ИИ» режим туннеля, адрес сайта и только `tunnel_id`. Учётная запись сайта сама не даёт прав создавать ресурсы OpenAI.
2. Установите официальный клиент [OpenAI Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels). В отдельной службе задайте переменные:

   | Переменная | Что задать |
   | --- | --- |
   | `EWC_MCP_SITE_ROOT` | Абсолютный путь к этой установке EWC-lite |
   | `EWC_MCP_STATE_DIR` | Абсолютный путь к отдельной папке черновиков, доступной службе; вне веб-корня |
   | `CONTROL_PLANE_API_KEY` | Ограниченный ключ из хранилища секретов, не из публичного файла |
   | `EWC_TUNNEL_BINARY` | Необязательно, абсолютный путь к официальному клиенту |
   | `EWC_PHP_BINARY` | Необязательно, абсолютный путь к PHP CLI |

   Запустите `./instance-from-cms.sh` из `mcp/`. Он считывает адрес сайта и ID из сохранённых настроек; официальный клиент открывает соединение. После изменения ID или адреса перезапустите службу. Для Windows есть низкоуровневые команды в `mcp/README-STDIO.md`.
3. В [настройках пользовательского MCP-сервера ChatGPT](https://developers.openai.com/plugins/deploy/connect-chatgpt) выберите **Tunnel**, задайте название сайта и тот же ID. Не вставляйте туда ключ OpenAI или пароль EWC. Добавьте плагин в чат и для первой проверки попросите «Покажи страницы сайта через list_pages». Сверьте имя установки и пути в ответе.

## 3. Свой PHP-клиент без туннеля

1. Во вкладке «ИИ» сохраните режим **«Прямой API EWC»**. Tunnel ID не нужен. Закрытый MCP-вход размещают на `https://mcp.example.com/mcp` (или `/mcp` на домене сайта). Публичная страница сайта и URL MCP могут быть разными.
2. Настройте отдельный пул PHP-FPM и точный маршрут `/mcp` через HTTPS на `mcp/direct.php`; пример в `mcp/deploy/`. Не открывайте весь каталог MCP и не используйте встроенный PHP-сервер в интернете. Включите ограничения частоты и числа соединений на прокси. Для одной организации по возможности ограничьте доступ к API сетью или IP.
3. В защищённых настройках пула задайте `EWC_MCP_SITE_ROOT`, `EWC_MCP_STATE_DIR`, `EWC_MCP_DIRECT_HOST` (домен MCP, в нижнем регистре, без схемы) и случайный отдельный `EWC_MCP_DIRECT_TOKEN` (например, сгенерированный `openssl rand -hex 32`). Токен не передаётся в браузер, URL и логи. Ротация: замените его в секрете службы, перезапустите пул и обновите клиент. Разные установки не должны использовать один токен или каталог черновиков.
4. Пример команды проверки с клиентской машины после передачи токена в переменную окружения, без кавычек в самом токене:

   ```sh
   php mcp/direct-client.php https://mcp.example.com/mcp
   ```

   Скрипт делает MCP `initialize`, `notifications/initialized` и `list_pages`, не записывает ничего на сайт. Можно использовать другой Streamable HTTP клиент с заголовком `Authorization: Bearer …`.
5. По умолчанию доступ только на чтение. На отдельной тестовой копии `EWC_MCP_DIRECT_WRITES=1` открывает создание черновиков, но не публикацию. Только явная дополнительная настройка пула `EWC_MCP_DIRECT_PUBLISH=1` вместе с ней открывает `publish`. Клиенту с таким токеном доступны изменения сайта: не выдавайте его неавторизованным пользователям и требуйте подтверждение каждой публикации в клиенте.

**Из ChatGPT без туннеля:** защищённый удалённый MCP тоже возможен, но ChatGPT не принимает произвольный EWC-токен в форме подключения. Для закрытого редактора нужны совместимый OAuth 2.1, обнаружение сервера авторизации и проверка токенов и прав по установкам. [Требования OpenAI к авторизации](https://developers.openai.com/plugins/build/auth). В этом тестовом комплекте OAuth не реализован; не отключайте защиту ради проверки. Работа прямого режима проверена локально, внешний HTTPS-сервер не развёрнут.

## 4. Как подключить ИИ к редактору

В тестовом чате выберите плагин конкретной установки и попросите показать страницы (`list_pages`). Затем дайте путь и описание правки. ИИ может создать черновик (`draft_page` / `draft_add_content`), показать (`preview_draft`) и, после явного подтверждения, применить (`publish`), если режим подключения разрешает запись. Откройте страницу в админке EWC-lite и сравните результат с предпросмотром. В режиме чтения создание черновика и применение отключены. Результаты и черновики относятся только к выбранному сайту.

## Проверки

`python3 mcp/test/verify-wizard.py /путь/к/php /путь/к/проверяемой/копии` проверяет установку, пропуск, донастройку, авторизацию, защиту форм и прямой MCP.

`python3 mcp/test/verify-http.py /путь/к/php /путь/к/копии` проверяет схемы 14 команд и изоляцию двух копий. Полный регрессионный тест редактора: `mcp/test/smoke.cjs`.

Проверено локально на PHP 7.2.34 и PHP 8.4.27. Тесты проводят изменения только во временных копиях.
