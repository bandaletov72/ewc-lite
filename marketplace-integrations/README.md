# Интеграции маркетплейса EWC Lite

В «Маркетплейс → Интеграции» нажмите «Проверить каталог». Профили можно установить или обновить, а настройки и ключи — заполнить отдельно для каждого профиля.

ZIP профиля содержит один файл `integration.json`. В нём хранятся ID, название, версия и встроенный драйвер. Сборка подписывает ZIP ключом релизов EWC. Для установки CMS проверяет подпись и сверяет ID, драйвер и версию с каталогом. Ключи сервисов, данные заказов и исполняемые расширения в профиль не входят.
