# Тихий сад

Готовая тема Eurowebcart CMS Light для студии ландшафтного дизайна. В комплекте главная, услуги с прейскурантом, проекты с фильтрами, страница о студии, контакты и политика конфиденциальности.

В админке откройте **Шаблоны оформления → Темы дизайна**, выберите **Тихий сад** и нажмите **Применить**. Тема открывает собственные страницы, инфоблоки и настройки. При повторном применении сохраняются правки, сделанные ранее. Чтобы вернуться к своему сайту, снова выберите его тему в этом списке.

| Что изменить | Где редактировать |
| --- | --- |
| Тексты и навигацию | «Страницы». На главной заголовок находится в тексте страницы |
| Фото на главной | «Компоненты → Баннеры», набор `garden-cover` |
| Карточки проектов | «Содержимое → Инфоблоки», `garden-projects`. Фотографии загружаются в каталог темы `images/projects/` |
| Состав услуг и цены | Инфоблок `garden-prices` |
| Блок «Что растёт на вашем участке?» | Подшаблон `garden-consult` |
| Телефон, мессенджеры и соцсети | «Настройки → Контакты и соцсети» |
| Поля заявки и почту получателя | «Формы и заявки», форма `[form85]` |

Названия проектов, изображения и цены демонстрационные. Форма сохраняет заявки в админке. Для уведомлений задайте адрес получателя и проверьте отправку почты на сервере.
