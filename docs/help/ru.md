# Русский · 1.6.1

## Поиск

В «Настройки → Основные» выберите вид поиска: выключен, компактный с лупой или расширенный. Поле поиска в шапке админки ведёт к нужным настройкам. Индекс обновляется после правок в админке и может перестраиваться по расписанию для изменений по FTP. В индекс входят текст страниц, вложенные страницы и инфоблоки; произвольный PHP при индексации пропускается.

## PHP-модули

Раскройте модуль для просмотра настроек и списка страниц с его вставкой. Через «Создать модуль» добавьте имя, имя файла и тело функции PHP. Возвращаемая строка вставляется кодом [php]имя[/php]. При переименовании файла код вставки сохраняется. CodeMirror включается в разделе библиотек.

## Шаблоны и переводы

Можно отменить до восьми изменений каждого шаблона и вернуть исходный PHP для общих настроек и каждого домена. Чтобы изменить HTML, выберите «Свой HTML». Пользовательские PHP-шаблоны размещайте в templates/local/. Переключатель языков виден даже при создании перевода, а сохранённые переводы перемещаются вместе со страницей.

## Интеграции и обслуживание

В настройках CAPTCHA, карт, телефонии и аналитики есть ссылки на кабинеты и инструкции провайдеров. URL HTTP API обратного звонка и токен можно задать в админке. Подшаблоны зарегистрированного поддомена сохраняются при переходе на основной домен. Планировщик хостинга должен запускать php update.php --scheduled каждые 15 минут.

# Русский · 1.6.0

## Поиск и кеш

В разделе «Обслуживание» перестройте текстовый индекс после публикации или изменения страниц в админке или по FTP. Поиск показывает подсказки по открытым страницам и учитывает язык посетителя. Кеш разобранного контента выключен по умолчанию. Включайте и очищайте его там же. Сессионные формы и динамические блоки обрабатываются при каждом запросе.

## Правка на сайте

После входа над шапкой появится панель правки. Справа можно включить или выключить режим для всего сайта. Включите его, чтобы править параметры возле вставок. CSS и JS текущей страницы открываются в лайтбоксе. В админке доступны HTML и визуальный редактор, вставка кодов и AJAX-управление папками галерей и файлов с массовой загрузкой и сортировкой.

## Компоненты и навигация

Без параметров галерея, карусель и файлы используют общие настройки. Значения во вставке переопределяют только заданные параметры. width принимает 100, 50, 33 и 25 в процентах, допускается знак %. На телефоне блоки складываются в одну колонку. numbers=off убирает номер слайда, стрелки и свайпы остаются. Мобильное меню выезжает справа. Хлебные крошки можно выключить в разделе «Настройки → Основные».

```text
[gal width=50 numbers=off arrows=on fit=cover]/images/myfotos/[/gal]
[fotos width=50% columns=3 captions=on]/images/myfotos/[/fotos]
[files width=33 icons=off size=on download=on]/files/myfiles/[/files]
```

## Языки, оформление и цена

В региональных настройках выберите языки сайта и админки, валюту, форматы чисел, даты, времени и часовой пояс. index_en.php рядом с index.php задаёт перевод; без отдельного файла старый адрес откроет основной текст. Тип «Цена» в инфоблоке использует выбранную валюту. «Тема и цвета» показывает цвета сохранённых тем и меняет режим сразу. Загрузите отдельные логотипы для светлой и тёмной темы. Для Roboto Condensed и других шрифтов можно менять фразу предпросмотра.

```text
/contacts/index.php → /contacts/index_en.php
```

## Формы, заявки и интеграции

«Настройки → CAPTCHA» задаёт общие ключи Google reCAPTCHA v2 и включает защиту для всех обычных форм. Параметры отдельных форм остаются доступны в «Формах». Сообщения и обратные звонки идут по 20 на страницу, непрочитанные вверху. В «Интеграциях» настраиваются Zadarma, Telegram, аналитика и карты Google или Яндекса. Точки со страницы группируются на одной карте, кластеризацию можно выключить. В библиотечном лайтбоксе проверяется активная версия и доступен код вставки. CodeMirror включается отдельно и поддерживает «Авто», HTML, CSS, JS, PHP и RAW.

```text
[map lat=55.7558 lng=37.6173 title="Office" zoom=13 provider=yandex url="/contacts/" button="Open"]
```

```text
[callback button="Call me" title="Callback" submit="Send" placeholder="+7(900)123-45-67"]
```

## PHP-модули

В разделе «PHP-модули» настройте название, описание и доступность проверенного модуля. В редакторе выберите его код вставки. Тестовый server-date показывает дату с региональным форматом. Исполняемый код модулей хранится в защищённом каталоге и добавляется через файловый доступ разработчика.

```text
[php]server-date[/php]
```
