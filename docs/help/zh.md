## 服务文件、地图和模板 · 1.6.5

打开“维护→服务文件”。这里编辑.htaccess、robots.txt和sitemap.xml。生成 sitemap.xml 会使用“在站点地图中显示”复选框获取已发布的页面。以前的版本可用于 .htaccess。

在页面上填写纬度和经度。 [map]将显示其积分，[maps]将收集已发布页面的积分。在这两个标签中，center 指定中心，zoom 指定比例。交互式地图使用 Integrations 的提供程序。

带有下拉小节的 [main-menu] 显示在标题下方。在设计模板中，创建您自己的模板并配置移动设备和桌面设备上的可见性。在“子模板”中，“+ 添加域”按钮会导致添加表单。要参考该策略，请使用 [privacy]。

在“集成”中，指定 JivoSite、Microsoft Clarity 和 Umami Cloud ID、Botfaqtor 代码或 Slack 传入 Webhook。说明链接位于字段旁边。在扎达玛，检查您的余额、发送测试短信或拨打国际号码进行测试呼叫。短信和通话可能需要付费。对于 [payment]，插入现成的付款链接 YuMoney、PayPal 和 SBP。付款状态在提供商的帐户中检查。

在 HTML 和可视化编辑器中，图标格式化文本、添加 H1–H5 和列表。定位光标并单独选择模板、组件、图像或图标。保存的代码可用于表单，其参数可用于组件。启用库后，Font Awesome 插入即可使用。

单击左侧的文件夹名称可管理右侧的部分。您可以在其中选择父部分、配置常规菜单和移动菜单，或指定转换 URL。空白部分页面显示小节。在“维护”中，设置 /contact.html => /contacts/ 等规则，并在 /error/ 中编辑错误页面。手机上的搜索和语言可通过标题中的图标进行。

```text

[maps center="55.7558,37.6173" zoom=11]
[main-menu]
[lang]
[privacy]
[payment]
```

## 1.6.3版本新增

### 家庭和隐私政策

打开“设计模板”编辑主页和/privacy.php页面。代码[page-content]显示主页的内容。在策略 [site-name] 和 [site-url] 中，从“设置→常规”中获取名称和公共地址。使用有关您的站点和数据处理的信息完成初始文本。

### Cookie 并返回顶部

在页脚中，[conf-policy] 提供指向策略的链接，[cookies] 打开设置，[top] 滚动到页面顶部。分析和内置 CMS 地图正在等待达成协议。手动添加到模板或服务标头的脚本需要自己的配置。

### 编辑functions.php

打开“服务标题”选项卡后的“设计模板→功能”。将闭包添加到返回的数组中。在 PHP 模板中，调用 `translit("Москва")` 或 `ew_call("translit", "München")`。在 HTML 中插入 [func=translit value="Москва и München"]。该示例生成 `Moskva i Muenchen`。

### 编辑标准模板

在“设计模板”字段中已经包含突出显示的 PHP 和 HTML 源代码。编辑标准模板时，选择“自定义 PHP”。保存会创建自定义版本。使用模板旁边的按钮，您可以撤消上次编辑或恢复原始内容。

### 保存前 PHP 检查

设计模板、模块和 functions.php 编辑器使用 `php -l` 命令检查语法。如果出现错误，则保留以前的版本。要选择服务器上的 PHP CLI，请使用变量 `SITE_PHP_LINT_BINARY`。

### 背光和紧凑搜索

新安装时默认启用 CodeMirror。该设置位于“库和字体”中。在紧凑搜索中，字段向左扩展，十字清除该行，然后按 Enter 键开始搜索。

### 管理菜单和编辑面板

管理面板标题下的菜单和网站上的编辑面板显示带有标题的图标。图标保留在窄屏幕上。悬停时工具提示会打开，键盘会聚焦在窄屏幕上。 “隐藏”位于其余页面操作旁边。编辑模式开关位于右侧。

### PHP模块说明及代码

在“PHP 模块”中，简短描述适用于纯文本。将函数主体粘贴到单独的字段“源代码·PHP”中。

## 1.6.1版本新增

### 搜索

在“设置 → 常规”中选择搜索类型：关闭、带放大镜的紧凑型或扩展型。管理标题中的搜索字段可引导至所需的设置。在管理面板中进行编辑后，索引会更新，并且可以通过 FTP 按计划重建索引。索引包括页面文本、子页面和信息块；索引过程中会跳过任意​​ PHP。

### PHP 模块

展开模块以查看设置和包含其插入的页面列表。通过“创建模块”添加 PHP 函数的名称、文件名和主体。返回的行插入代码为 [php]name[/php]。重命名文件时，嵌入代码将被保存。 CodeMirror 包含在库部分中。

### 模板和翻译

对于每个模板，您最多可以撤消八次更改，并将常规设置和每个域恢复为原始 PHP。要更改 HTML，请选择自定义 HTML。将自定义 PHP 模板放置在 templates/local/. 中即使在创建翻译时，语言切换器也是可见的，并且保存的翻译会随页面移动。

### 集成和维护

在验证码、地图、电话和分析设置中，有指向提供商办公室和说明的链接。回调 HTTP API URL 和令牌可以在管理面板中设置。当移动到主域时，已注册子域的子模板将被保留。托管调度程序应每 15 分钟运行一次 php update.php --scheduled。

## 1.6.0版本新增

### 搜索和缓存

在“维护”部分中，在管理区域或通过 FTP 发布或更改页面后重建文本索引。搜索会显示打开页面的建议，并考虑访问者的语言。默认情况下禁用已解析内容缓存。打开它并在那里清洁它。会话表单和动态块根据每个请求进行处理。

### 在网站上编辑

登录后，标题上方将出现一个编辑面板。在右侧，您可以打开或关闭整个站点的模式。打开它可以编辑插入旁边的参数。当前页面的 CSS 和 JS 在灯箱中打开。管理面板中提供 HTML 和可视化编辑器、代码插入以及画廊和文件夹的 AJAX 管理以及批量加载和排序功能。

### 组件和导航

如果没有参数，图库、轮播和文件将使用相同的设置。插入中的值仅覆盖指定的设置。 width 接受 100%、50%、33% 和 25%，允许使用 % 符号。在手机上，这些块堆叠成一列。 Numbers=off 删除幻灯片编号，保留箭头和滑动。移动菜单在右侧滑出。可以在“设置”→“常规”中关闭面包屑导航。

```text
[gal width=50 numbers=off arrows=on fit=cover]/images/myfotos/[/gal]
[fotos width=50% columns=3 captions=on]/images/myfotos/[/fotos]
[files width=33 icons=off size=on download=on]/files/myfiles/[/files]
```
