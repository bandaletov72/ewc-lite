# 관리자 FAQ

## 설치 및 로그인

### 웹사이트를 시작하고 관리 패널을 여는 방법은 무엇입니까?

로컬로 시작하려면 프로젝트 디렉터리에서 php -S 127.0.0.1:8000 router.php 명령을 실행하고 http://127.0.0.1:8000/admin/.를 엽니다. 호스팅에서 먼저 php admin/setup.php를 실행한 다음 마법사의 첫 번째 단계에서 받은 일회성 코드를 /admin/.에 입력합니다.

### 처음 시작할 때 무엇을 구성할 수 있나요?

먼저 사용자 이름과 비밀번호를 만드세요. 두 번째 단계에서는 사이트 이름, 기본 메타 설명, 바닥글 텍스트, 팔레트 및 테마 모드를 설정합니다. PHP GD가 있으면 즉시 로고를 다운로드하여 파비콘을 만들 수 있습니다. 두 번째 단계를 건너뛰거나 다음에 로그인할 때 계속할 수 있습니다.

## 페이지 및 메뉴

### 페이지를 만드는 방법과 어떤 주소를 입력해야 하나요?

페이지 → 새 페이지로 이동합니다. 예를 들어 /Services-1/Repair/ 또는 /Services-1/Price_2.php와 같은 주소를 입력하고 제목을 입력한 후 저장합니다. 폴더 주소의 경우 엔진 자체가 디렉토리와 index.php를 생성합니다. 이름에는 A-Z, a-z, 0-9, 하이픈 및 밑줄이 허용됩니다. 메인 페이지는 루트에 예약되어 있으며 서비스 디렉토리의 페이지 생성은 닫힙니다.

### "메뉴 내" 확인란과 "숨기기" 버튼의 차이점은 무엇입니까?

"메뉴에 있음" 상자를 선택 취소하면 직접 주소에 대한 액세스는 유지하면서 일반 메뉴에서 링크가 제거됩니다. 폴더 주소가 있는 페이지에서 확인란은 하위 페이지의 항목도 제어합니다. "숨기기" 버튼을 누르면 링크가 제거되고 페이지가 다시 게시될 때까지 페이지의 공개 주소가 닫힙니다.

### 페이지 순서를 변경하거나 전체 폴더를 이동하려면 어떻게 해야 합니까?

같은 레벨 내에서 페이지를 재정렬하려면 ⠿ 아이콘을 드래그하세요. 한 페이지를 이동하려면 편집기에서 '페이지 이동'을 엽니다. 첨부된 페이지 및 파일과 함께 폴더를 전송하려면 폴더 이름 옆에 있는 ↪을 클릭하세요. 전송 후 이전 주소를 가리키는 수동 링크와 [include] 코드를 확인하세요.

### 페이지 변경 사항이 즉시 표시되지 않는 이유는 무엇입니까?

편집기에서 "저장"을 클릭하세요. 그런 다음 "페이지 열기" 또는 "이동" 링크를 사용하십시오. 링크가 사라진 경우 페이지가 게시되었는지 확인하세요. 하위 도메인에 대한 변경 사항은 주소 표시줄에서 도메인을 확인하세요.

## 디자인 및 하위 도메인

### 제목, 바닥글, 로고, 파비콘은 어디에서 변경할 수 있나요?

설정 → 일반을 엽니다. 바닥글 텍스트 필드는 현재 연도에 대해 [year]를 지원합니다. "로고 및 사이트 아이콘" 블록에서 이미지를 업로드하거나 "로고에서 파비콘 만들기"를 클릭할 수 있습니다. 로딩 및 변환에는 PHP GD가 필요합니다.

### 테마나 글꼴을 변경한 다음 이전 글꼴로 돌아가는 방법은 무엇입니까?

설정 → 테마 및 색상에서 모드와 팔레트를 선택하세요. 나중에 사용할 수 있도록 현재 팔레트를 목록에 저장합니다. "기본값으로 사용" 버튼은 "테마를 기본값으로 되돌리기" 명령에 대한 팔레트를 기억합니다. 글꼴은 "라이브러리 및 글꼴" 섹션에서 변경할 수 있습니다. 목록의 이름과 샘플은 적절한 글꼴로 표시됩니다. "시스템" 값은 일반 글꼴을 반환합니다.

### 헤더를 변경할 위치와 카운터, CSS 또는 JavaScript를 삽입할 위치는 무엇입니까?

공통 블록 헤더, 모바일 메뉴, 메뉴 및 바닥글은 "디자인 템플릿" 탭에서 편집됩니다. 같은 위치에서 "서비스 헤더"는 HTML을 헤드 또는 닫는 body 태그 앞에 삽입합니다. 일반 CSS 및 JavaScript의 경우 별도의 "CSS 및 JS" 탭이 있습니다. 한 페이지의 코드가 해당 편집기에 추가됩니다.

### 하위 도메인에 대해 다른 전화번호와 헤더를 설정하는 방법은 무엇입니까?

"도메인" 섹션에 하위 도메인을 추가합니다. 그런 다음 원하는 도메인을 선택하여 하위 템플릿 섹션에서 별도의 하위 템플릿 값을 설정합니다. 도메인 옆에 있는 "템플릿" 버튼을 사용하여 헤더 및 기타 블록을 변경하세요. 도메인 버전이 일반 버전보다 우선합니다. DNS와 웹 서버는 하위 도메인이 해당 사이트의 디렉터리를 가리켜야 합니다.

### 소셜 네트워크 링크와 그 옆에 있는 캡션을 어디에서 변경할 수 있나요?

'설정 → 연락처 및 소셜 네트워크'를 엽니다. 주소, 서명, 전화번호를 입력하세요. [soc-icons] 코드는 구성된 모든 네트워크의 아이콘을 표시합니다. 단일 링크의 경우 [tg] 또는 [vk] 등을 사용합니다.

## 양식 및 신청서

### 페이지에 양식을 추가하는 방법은 무엇입니까?

양식을 열고 필드, 필수, 최대 길이 및 버튼 텍스트를 구성합니다. 양식을 저장하고 해당 코드(예: [form1])를 페이지의 HTML에 붙여넣습니다.

### 이메일로 알림을 받지 못한 경우 지원서는 어디서 확인할 수 있나요?

메시지를 엽니다. 양식을 성공적으로 제출한 후 신청서가 여기에 저장됩니다. 알림을 받으려면 양식 메일 템플릿의 "받는 사람" 필드에 있는 주소와 호스팅의 mail() 기능 기능을 확인하세요.

### 편지를 설정하고 사본을 보내는 방법은 무엇입니까?

원하는 양식을 열고 "메일 템플릿" 블록을 찾으세요. "받는 사람" 및 "사본(참조)" 필드에 주소를 쉼표로 구분하여 입력합니다. 제목과 본문에서는 중괄호 안에 필드 키를 사용합니다(예: Hello {name}!). 텍스트 아래의 버튼은 선택한 변수를 삽입합니다. 빈 제목이나 텍스트는 표준 알림을 사용합니다.

### 양식에서 메시지를 거부하거나 "로봇이 아닙니다"라고 묻는 이유는 무엇입니까?

필수 항목, 길이, 전화번호, 이메일 형식을 확인하세요. 무료 입력 필드는 HTML이나 웹사이트 주소 없이 일반 텍스트를 사용합니다. 금지 단어 및 IP 목록은 안티스팸 섹션에 있습니다. 'CAPTCHA 사용' 확인란을 선택하려면 원하는 도메인에 대한 사이트 키와 Google reCAPTCHA v2 비밀 키가 필요합니다.

### 콜백 요청은 어디서 확인할 수 있나요?

"콜백" 섹션에서. 구성요소는 [callback] 또는 [callback=Вызвать мастера] 코드와 함께 페이지에 추가됩니다. "아니요" 공급자를 사용하면 응용 프로그램이 관리자 패널에 저장됩니다. 전화 통신이 구성되면 수동 또는 자동 전송이 가능합니다.

## 정보 블록 및 구성요소

### 정보 블록을 생성하고 페이지에 표시하는 방법은 무엇입니까?

'Infoblocks' 섹션에서 'New Infoblock'을 클릭하고 열을 구성하고 행을 추가합니다. 인포블록 이름과 열 키에는 A~Z, a~z, 0~9, 하이픈 또는 밑줄을 공백 없이 사용하세요. 인포블록 편집기에서 임베드 코드를 저장하고 복사하세요. 전화 목록을 보려면 전화 템플릿을 사용하세요.

### 정보블록의 모든 행을 복사하거나 바꾸는 방법은 무엇입니까?

정보 블록을 열고 '텍스트로 편집'을 클릭하세요. CSV는 | 구분 기호. 처음 세 줄에는 열의 키, 이름 및 유형이 포함됩니다. 다음은 데이터입니다. 구분 기호, 따옴표 또는 줄 바꿈이 있는 필드를 큰따옴표 및 큰 내부 따옴표로 묶습니다.

### 갤러리나 파일 목록이 비어있는 경우 어떻게 확인하나요?

서버에 있는 폴더로 구성요소 코드의 경로를 확인하세요. 예를 들어, [fotos]/images/myfotos/[/fotos]는 images/myfotos/ 또는 templates/images/myfotos/.의 사진을 사용합니다. [files]의 경우 파일 확장자를 확인하세요. 지원되는 확장 및 매개변수 목록은 구성 요소 도움말에서 찾을 수 있습니다.

### ?ajax=1 요청이 403을 반환하는 이유는 무엇입니까?

페이지 조각에는 동일한 사이트에 유효한 공개 세션과 토큰이 필요합니다. 사이트 내부를 로드하려면 토큰을 전송하는 window.siteFetchContent()를 사용하세요. 정상적인 전환을 위해서는 ajax 매개변수 없이 페이지 주소를 엽니다.

## 업데이트 및 백업

### 설치된 사이트의 엔진을 업데이트하는 방법은 무엇입니까?

설정 → 업데이트에서 설치된 버전을 GitHub의 최신 버전과 비교한 다음 엔진 업데이트를 클릭하세요. GitHub를 사용할 수 없는 경우 관리자 패널에 마지막으로 확인한 버전이 표시됩니다. 수동으로 업데이트하려면 php-site-update.zip 아카이브를 PHP 명령 update.php에 전달하세요. 업데이트 패키지는 엔진 파일과 표준 템플릿을 대체합니다. templates/local/.에 PHP 템플릿을 저장하세요.

### 업그레이드하거나 마이그레이션하기 전에 무엇을 복사해야 합니까?

숨겨진 파일과 함께 전체 사이트 디렉터리의 복사본을 만듭니다. 페이지는 루트 및 해당 디렉터리, data/의 정보 블록, admin/.의 설정 및 계정 파일에 있습니다. 또한 템플릿, 업로드된 이미지, 메시지 및 요청을 저장하세요. 복사본에는 구성 비밀이 포함되어 있으므로 공용 디렉터리 외부에 보관하세요.

### 관리자 패널이 변경 사항을 저장할 수 없는 경우 무엇을 확인해야 합니까?

먼저 양식 옆에 있는 메시지를 읽어보세요. 변경 사항이 충돌하는 경우 편집 내용을 복사하고 편집기를 다시 엽니다. 쓰기 오류가 있는 경우 원하는 폴더 및 파일 admin/write-lock.php.에서 PHP 프로세스의 쓰기 권한을 확인하도록 호스팅에 요청하세요. 업데이트에 실패하면 서버의 GitHub 액세스 및 PHP Zip 및 OpenSSL 사용 가능 여부를 확인하세요.

## 버전 1.6.3의 새로운 기능

### 홈 및 개인 정보 보호 정책

홈 페이지와 /privacy.php 페이지를 편집하려면 "디자인 템플릿"을 엽니다. [page-content] 코드는 메인 페이지의 내용을 표시합니다. 정책 [site-name] 및 [site-url]에서는 "설정 → 일반"에서 이름과 공개 주소를 가져옵니다. 사이트 및 데이터 처리에 대한 정보로 초기 텍스트를 완성하세요.

### 쿠키 및 맨 위로 돌아가기

바닥글에서 [conf-policy]는 정책에 대한 링크를 제공하고, [cookies]는 설정을 열고, [top]는 페이지 상단으로 스크롤합니다. 분석 및 내장 CMS 지도는 합의를 기다리고 있습니다. 템플릿이나 서비스 헤더에 수동으로 추가된 스크립트에는 자체 구성이 필요합니다.

### 편집기 functions.php

"서비스 헤더" 탭 다음에 "디자인 템플릿 → 기능"을 엽니다. 반환된 배열에 클로저를 추가합니다. PHP 템플릿에서 `translit("Москва")` 또는 `ew_call("translit", "München")`를 호출합니다. HTML에 [func=translit value="Москва и München"]를 삽입하세요. 이 예에서는 `Moskva i Muenchen`를 생성합니다.

### 표준 템플릿 편집

"디자인 템플릿" 필드에는 강조 표시된 PHP 및 HTML 소스 코드가 이미 포함되어 있습니다. 표준 템플릿을 편집할 때 "Custom PHP"를 선택하세요. 저장하면 사용자 정의 버전이 생성됩니다. 템플릿 옆에 있는 버튼을 사용하면 마지막 편집 내용을 취소하거나 원본을 복원할 수 있습니다.

### 저장하기 전에 PHP 확인

디자인 템플릿, 모듈 및 functions.php 편집기는 `php -l` 명령을 사용하여 구문을 확인합니다. 오류가 있으면 이전 버전이 유지됩니다. 서버에서 PHP CLI를 선택하려면 `SITE_PHP_LINT_BINARY` 변수를 사용하십시오.

### 백라이트 및 컴팩트 검색

CodeMirror는 새로 설치 시 기본적으로 활성화됩니다. 설정은 "라이브러리 및 글꼴"에 있습니다. 압축 검색에서는 필드가 왼쪽으로 확장되고 십자 표시로 줄이 지워지며 Enter 키를 누르면 검색이 시작됩니다.

### 관리 메뉴 및 편집 패널

관리자 패널 헤더 아래의 메뉴와 사이트의 편집 패널에는 캡션과 함께 아이콘이 표시됩니다. 아이콘은 좁은 화면에 남아 있습니다. 좁은 화면에서는 마우스를 가져가면 도구 설명이 열리고 키보드 초점이 맞춰집니다. "숨기기"는 나머지 페이지 작업 옆에 있습니다. 편집 모드 스위치는 오른쪽에 있습니다.

### PHP 모듈 설명 및 코드

"PHP 모듈"에서 간단한 설명은 일반 텍스트용입니다. 함수 본문을 별도의 필드인 "소스 코드 · PHP"에 붙여넣습니다.

## 관리자 화면 상단 버튼 · 1.6.4

지구본 아이콘은 사이트를 열고 화살표 아이콘은 로그아웃합니다. 휴대전화에서는 아이콘만 표시됩니다. 마우스를 올리거나 키보드로 초점을 맞추면 이름을 볼 수 있습니다.

콘텐츠, 양식 및 요청, 사이트 및 서비스는 바로 열립니다. 기본 메뉴 아래에 선택한 섹션의 탭이 표시됩니다.

홈 화면(index.php)이나 템플릿의 HTML에 [bread-crumbs] 또는 [search]를 넣으면 지정한 위치에 한 번씩 표시됩니다. 탐색 경로와 검색 설정이 적용됩니다. [privacy]는 /privacy/로 연결됩니다. 정책 문구는 페이지 메뉴에서 편집할 수 있습니다.

```text
[bread-crumbs]
[search]
[privacy]
```
