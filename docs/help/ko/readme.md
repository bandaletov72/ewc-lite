# Eurowebcart CMS Light

저자-Бандалетов Павел. [원본 프로젝트 및 업데이트](https://github.com/bandaletov72/php-site-updates).

최소 버전은 PHP 7.2입니다. 사이트와 관리자 화면은 PHP 8.6을 지원합니다. 사용자 정의 모듈과 템플릿은 서버에 설치된 버전의 문법을 사용하세요.

[관리자 FAQ](faq.md)는 "도움말" 탭에서도 사용할 수 있습니다.

[10개 언어로 제공되는 최신 버전에 대한 도움말](../README.md)는 검색, 사이트 편집, 현지화 및 유지 관리에 대해 설명합니다. [Admin FAQ in English](../en/faq.md).

예약된 유지 관리를 위해 15분 간격으로 호스팅 스케줄러에 `php update.php --scheduled` 명령을 추가합니다. 유지 관리 섹션에서는 재인덱싱을 독립적으로 활성화하고 서명된 GitHub 업데이트에 대한 확인 간격을 설정할 수 있습니다.

## 현지 출시

`php-site` 디렉토리로 이동하여 내장 PHP 서버를 시작하십시오.

```sh
php -S 127.0.0.1:8000 router.php
```

사이트는 주소 `http://127.0.0.1:8000/`에서 열리고 관리자 패널은 `http://127.0.0.1:8000/admin/`에 있습니다.

## 설치 및 최초 로그인

로컬 서버에서 `/admin/`를 열고 계정을 만드세요. 두 번째 단계에서는 사이트 이름, 메타 설명, 바닥글 텍스트, 팔레트 및 테마 모드를 설정합니다. PHP GD가 있으면 로고를 즉시 다운로드할 수 있습니다. 마법사는 여기에서 파비콘을 생성합니다. "관리자 저장 및 열기"를 클릭하거나 현재 설정을 계속 진행하세요. 마법사를 종료하면 다음에 로그인할 때 마법사가 계속됩니다.

호스팅의 경우 프로젝트 디렉터리에서 `php admin/setup.php`를 실행하고 마법사의 첫 번째 단계에서 일회성 코드를 입력하세요. 계정을 만들면 코드가 사용됩니다. 설치 전에 명령을 다시 실행하면 이전 코드가 대체됩니다. 업데이트를 설치하면 이전 계정과 설정이 유지됩니다. 업데이트 이전 버전에서 `SITE_ADMIN_PASSWORD_HASH`를 사용한 경우 로그인은 로그인 `admin` 및 이전 비밀번호와 함께 저장됩니다.

응용 프로그램이 작동하려면 PHP 세션과 `admin/`, `admin/write-lock.php`, `admin/inbox/`, `data/` 및 편집 가능한 페이지 디렉터리에 대한 쓰기 권한이 필요합니다. 루트에 페이지와 디렉터리를 생성하려면 PHP 프로세스에 프로젝트 루트에 대한 쓰기 액세스 권한을 부여하세요. HTTPS가 있는 웹 서버를 사용하여 인덱스 파일 목록에서 `.php` 및 `index.php`를 처리합니다. 디렉토리 목록을 비활성화합니다. 역방향 프록시 뒤에 있는 HTTPS의 경우 신뢰할 수 있는 서버 구성을 통해 PHP 속성 `HTTPS`를 전달합니다.

## 페이지 및 메뉴

관리자 패널에서 기본 페이지는 `/`로 나열되고 폴더의 나머지 페이지는 `/contacts/`로 나열됩니다. 하위 페이지를 생성하려면 예를 들어 `/Services-1/Repair/`를 입력합니다. 관리자 패널은 카탈로그와 `index.php` 자체를 생성합니다. 별도의 파일인 경우 `/Services-1/About_2.php`와 같은 주소를 입력하세요. 파일 및 폴더 이름에는 `A–Z`, `a–z`, `0–9`, 하이픈 및 밑줄이 허용됩니다. 이름은 공백 없이 입력됩니다. 루트에서는 메인 페이지만 허용됩니다. `data`, `admin`, `templates`, `css` 및 `js`를 포함한 서비스 디렉토리는 예약되어 있습니다.

페이지 목록에서 폴더를 확장할 수 있습니다. 메뉴 확인란에서 숨기기, 게시 및 삭제는 AJAX를 통해 저장됩니다. 숨기기, 게시 및 삭제에는 확인이 필요합니다. 인접한 페이지를 정렬하려면 ⠿ 아이콘을 드래그하세요. 숨겨진 페이지가 열리지 않고 게시되기 전에 메뉴에서 사라집니다.

페이지 편집기에서 "페이지 이동" 블록을 열고 대상 폴더를 지정합니다. 예를 들어 `/contacts/`를 `/company/`로 전송하면 새 주소는 `/company/contacts/`가 됩니다. 중첩된 페이지는 동일한 주소에 남아 있습니다. 마이그레이션된 페이지로 연결되는 링크와 코드 `[include]`를 업데이트하세요.

⠿ 핸들을 끌어 같은 수준의 페이지를 다시 정렬하세요. 개별 페이지는 페이지 설정에서 이동합니다. 폴더 옆 아이콘은 상위 섹션 선택을 엽니다. 다른 섹션 또는 루트를 선택한 뒤 폴더 이동을 누르면 페이지와 파일이 함께 이동합니다. 이전 주소를 쓰는 링크와 [include]를 확인하세요.

콘텐츠는 텍스트 편집기에서 편집하고 FTP 또는 SFTP를 통해 추가할 수 있습니다. 파일은 BOM 없이 UTF-8 형식이어야 합니다. PHP 서비스 블록을 `__halt_compiler();` 줄까지 저장합니다. 새 페이지 파일에서 예제의 이 블록을 원하는 깊이에 삽입하고 루트 `index.php`에 대한 상대 경로를 확인합니다. 다음에는 헤더, 빈 줄 하나, 페이지의 HTML 조각이 옵니다.

```php
<?php
$pageFile = __FILE__;
require __DIR__ . '/../index.php';
__halt_compiler();
Title: Контакты
Heading: Как с нами связаться
Description: Контактная информация
Menu: Контакты
MenuVisible: 1
Order: 20

<p>Укажите здесь контактную информацию.</p>
```

`Title`가 필요합니다. 빈 `Heading`는 `Title`에서 가져옵니다. `Description`는 페이지의 메타 설명을 채웁니다. `MenuVisible: 1`는 메뉴에 링크를 표시하고, `MenuVisible: 0`는 이를 숨깁니다. `index.php` 폴더의 경우 확인란을 선택 취소하면 메뉴에서 모든 하위 페이지도 숨겨집니다. `MenuVisible`가 누락된 경우 확인란은 이전 규칙을 상속하며 `Menu`가 채워지면 활성화된 것으로 간주됩니다. 확인란을 활성화하면 빈 필드 `Menu`가 헤더 `Title`로 대체됩니다. `Order`는 한 수준 내의 시퀀스를 지정하고 기본값은 100입니다.

CSS 및 JS 탭에는 공개 페이지에 대한 일반적인 CSS 및 JavaScript가 저장됩니다. 페이지 편집기에는 별도의 블록 "CSS 및 JavaScript 페이지"가 ​​있습니다. 페이지 코드는 일반 코드 다음에 로드됩니다. `<style>` 및 `<script>` 태그 없이 파일의 내용만 지정하십시오. 각 필드에 허용되는 크기는 최대 64KiB입니다. CSS의 이미지에 연결하려면 사이트 루트의 경로를 사용할 수 있습니다. 도움말 탭에는 사용 가능한 템플릿 및 구성 요소의 예가 포함되어 있습니다.

"디자인 템플릿" 섹션에서는 `header.php`, `footer.php`, `menu.php` 및 `mobile-menu.php`의 소스를 보고 각각에 대한 공통 HTML을 설정할 수 있습니다. "서비스 헤더"는 `<head>` 또는 `</body>` 앞에 공통 메타 태그, 카운터 코드 및 스크립트를 삽입합니다. 게시된 각 전체 페이지에서 `rel="canonical"`는 쿼리 매개변수 없이 일반 주소로 구성됩니다.

## 설정, 하위 템플릿 및 도메인

"설정" 섹션에서는 사이트 이름, 기본 메타 설명, 바닥글 텍스트 및 변수를 설정합니다. 바닥글 텍스트에서 `[year]`는 현재 연도를 자동으로 표시합니다. 변수는 한 줄에 하나씩 작성됩니다(예: `[city] = Москва` 및 `[spb] = Санкт-Петербург`). 사이트 제목, 페이지 콘텐츠, 머리글 또는 바닥글에 값을 표시하려면 `[city]`를 삽입하세요. PHP 템플릿에서는 `site_escape($settings['variables']['city'] ?? '')`를 사용할 수 있습니다.

시스템 대체에는 `[year]`, `[month]`, `[day]`, `[time]`(시간 및 분), `[dmY]` 및 `[date]`(날짜 DD.MM.YYYY), `[datetime]`(날짜 및 시간)가 포함됩니다. PHP 시간대가 사용됩니다.

“기본 → 사이트 로고 및 아이콘”에서 PNG, JPEG, GIF 또는 WebP를 업로드할 수 있습니다. 다운로드는 PHP GD에 의해 처리됩니다. 파비콘 생성 버튼은 선택되거나 저장된 로고에서 투명한 64×64 PNG를 만듭니다. 이미지는 `templates/images/branding/` 및 `templates/icons/branding/`에 저장됩니다.

"하위 템플릿"은 각 코드의 이름, 설명 및 의미를 저장합니다. 전화기의 경우 `[tel]`를 생성합니다. 하위 템플릿을 통해 탭 제목을 설정하려면 `[title]`를 생성하고 페이지의 `Title` 필드에 지정합니다. 탭 제목 뒤에 사이트 이름이 표시됩니다. 대체는 페이지 텍스트 및 텍스트 메타데이터에서 작동합니다. 링크의 경우 전체 `<a>` 태그를 하위 템플릿 값으로 삽입하고 태그 사이의 텍스트에 코드를 배치합니다. 메타데이터에서 HTML은 값에서 텍스트로 변환됩니다.

'도메인' 섹션에 하위 도메인을 추가합니다. 동일한 이름의 하위 도메인의 관리자 패널에서 "현재 도메인"을 선택하거나 일반 목록에서 원하는 도메인을 엽니다. 지역적 의미가 일반적인 의미보다 우선합니다. 공개 페이지는 해당 주소에서 도메인별로 값을 선택하고, 내부 링크는 이를 저장합니다. 하위 도메인을 연결하려면 도메인이 동일한 프로젝트 디렉터리를 제공하도록 호스팅에서 DNS 및 웹 서버를 구성하세요.

도메인 옆에 있는 "템플릿" 버튼을 누르면 `[header]`, `[mobile-menu]`, `[menu]` 및 `[footer]` 편집기가 열립니다. 각 블록에 대해 자신만의 HTML을 설정하거나 일반 버전을 사용할 수 있습니다. 일반 템플릿은 동일한 섹션에서 구성됩니다.

## HTML의 구성 요소

| 암호 | 결과 |
| --- | --- |
| `[gal]/images/myfotos/[/gal]` | 부드러운 스크롤, 화살표, 스와이프 기능을 갖춘 사진 회전식 슬라이드쇼 |
| `[fotos]/images/myfotos/[/fotos]` | 원본 링크가 포함된 사진 갤러리 |
| `[files]/files/myfiles[/files]` | 확장자별 아이콘이 있는 파일 목록 |
| `[include]/contacts/[/include]` | 하위 템플릿 및 구성 요소가 포함된 다른 페이지의 HTML |
| `[form1]` | 양식 섹션에 구성된 양식 |
| `[callback=Вызвать мастера]` | 콜백 요청 버튼 및 양식 |
| `[iblock=table]/data/myiblock.txt[iblock]` | 정보 블록 테이블 |
| `[iblock=phones]/data/myiblock.txt[iblock]` | 정보 차단 전화 목록 |
| `[phones]`, `[contacts]` | 전화 또는 구성된 전체 연락처 블록 |
| `[soc-icons]` | 맞춤형 링크가 포함된 모든 소셜 네트워크 아이콘 |
| `[tg]`, `[vk]`, `[whatsapp]`, `[youtube]`, `[instagram]`, `[max]` | 아이콘과 서명이 있는 소셜 네트워크 링크 |

`templates/images/myfotos/` 또는 `images/myfotos/`에 사진을 배치하세요. 파일 목록에는 `zip`, `pdf`, `xls`, `xlsx`, `doc`, `docx`, `png`, `gif`, `jpg`, `jpeg`, `mp4`, `mov` 및 `mp3`. `[include]`의 경우 최대 10개의 중첩 수준이 지원됩니다. 현재 스레드의 페이지 반복을 건너뜁니다. 페이지 본문의 HTML 블록 사이에 별도의 줄에 구성 요소 코드를 배치합니다.

"설정 → 연락처 및 소셜 네트워크"에서 링크, 번호, 서명 및 블록 제목을 설정하세요. "설정 → 테마 및 색상"에서 시스템, 어둡고 밝은 모드 및 개별 팔레트를 사용할 수 있습니다. "설정 → 구성요소"에서 캐러셀 및 사진 갤러리의 일반 매개변수를 설정합니다. 설정 아래에는 선택한 값을 삽입하는 예가 있습니다. 페이지 코드의 매개변수는 일반 값을 재정의합니다.

테마 및 색상에서 선택한 설정의 복사본을 자신의 이름으로 저장하거나 이름을 자동으로 남겨둘 수 있습니다. "적용"은 현재 디자인을 변경합니다. 기본값 사용은 저장된 테마를 적용하고 테마를 기본값으로 재설정 명령에 대해 이를 기억합니다. 목록에서 제거하면 사이트의 현재 디자인이 유지됩니다.

```text
[gal arrows=off numbers=off effect=fade fit=cover]/images/myfotos/[/gal]
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off]/images/myfotos/[/fotos]
[files icons=on size=on order=desc download=on]/files/myfiles/[/files]
```

`[fotos]`의 경우 와이드 화면에 대해 열 수를 수동으로 설정하거나 자동으로 선택된 상태로 둘 수 있습니다. 좁은 화면에서는 그리드가 열 수를 줄입니다. 사용 가능한 화면 비율은 4:3, 1:1, 16:9 및 원본, `cover` 및 `contain` 모드, 파일 이름의 서명 및 원본 링크입니다.

## 양식 및 스팸 방지

"양식" 섹션에서는 `[form1]`를 편집하고 `[form2]` 및 다음 양식을 생성할 수 있습니다. 양식에는 수신자의 주소, 버튼 서명 및 필드가 지정됩니다. 필드에는 최대 길이가 있을 수 있습니다. 빈 값은 필드 유형에 대한 기본 제한을 사용합니다. `89031234567`를 입력하면 전화 필드에서 `+7(903)123-45-67`로 형식을 지정합니다. 서버는 요청의 길이, 유형, 유효한 선택 사항을 확인하고 요청의 전체 크기를 제한합니다. 무료 입력 필드에는 일반 텍스트가 허용됩니다. 메시지의 HTML은 출력 시 이스케이프되며 새 메시지의 HTML 태그는 거부됩니다.

"CAPTCHA 사용" 확인란을 선택하면 선택한 양식에 대해 "로봇이 아닙니다" 확인 기능과 함께 Google reCAPTCHA v2가 활성화됩니다. 도메인의 사이트 키와 비밀 키를 입력하세요. 비밀은 보호된 설정 파일에 저장되며 서버 확인에만 사용됩니다. [서버 확인 문서](https://developers.google.com/recaptcha/docs/verify).

양식은 AJAX를 통해 제출됩니다. 애플리케이션은 "메시지" 섹션에 저장됩니다. 수신자가 지정되면 `mail()`가 알림에 사용되며 호스팅에 구성된 메일이 필요합니다. 안티스팸 섹션에서는 단어, 표현, IPv4 및 IPv6 주소 목록을 편집할 수 있습니다. 서버에서 링크가 차단되었습니다. 보낸 사람의 주소는 `REMOTE_ADDR`에서 가져옵니다. 역방향 프록시 뒤에는 신뢰할 수 있는 프록시에 대한 웹 서버의 원래 IP 복구를 구성합니다.

각 양식에는 "받는 사람", "참조(참조)", "이메일 제목" 및 "이메일 본문" 필드가 있는 "메일 템플릿"이 있습니다. 주소는 쉼표로 구분되어 표시됩니다. 기본 수신자가 한 명 이상 지정된 경우 사본이 전송됩니다. 필드 키는 제목과 중괄호 안에 있는 텍스트에 삽입됩니다(예: `Привет {name}!`). 빈 필드 값은 빈 문자열로 대체되며 알 수 없는 키는 문자에 남아 있습니다. 제목이나 본문이 비어 있으면 표준 문자의 해당 부분이 사용됩니다.

## 콜백 요청

HTML 페이지에 `[callback]` 또는 `[callback=Вызвать мастера]`를 삽입합니다. 버튼을 누르면 전화번호가 포함된 양식이 열립니다. 요청은 '콜백' 섹션에 저장됩니다. 버튼 서명과 요청을 전화 통신으로 전송하는 모드도 여기에서 설정됩니다. 기본적으로 "없음" 공급자가 선택되어 있으며 요청은 저장만 됩니다. 목록에서 수동으로 전송하거나 번호를 받은 후 즉시 전송하도록 전화 통신을 활성화할 수 있습니다.

- **Zadarma.** 관리자 패널에서 번호, SIP 또는 교환원 내선 번호를 설정하고 `SITE_ZADARMA_KEY` 및 `SITE_ZADARMA_SECRET`를 통해 키를 PHP로 전송합니다. [Zadarma API 문서](https://zadarma.com/en/support/api/)
- **HTTP API.** HTTPS 주소로 `SITE_CALLBACK_WEBHOOK_URL`를 지정하고 선택적으로 `SITE_CALLBACK_WEBHOOK_TOKEN`를 지정합니다. 사이트는 JSON 필드 `id`, `phone`, `host`, `page`, `requested_at` 및 헤더 `Idempotency-Key`가 포함된 POST를 보냅니다. 토큰은 Bearer로 전송됩니다. 응답 코드 2xx는 요청을 "전화 통화 승인" 상태로 전환합니다.

`admin/callbacks/`에 PHP 프로세스 쓰기 권한을 부여합니다. 응용 프로그램은 양식 스팸 방지 설정을 사용합니다. 같은 번호의 반복은 1분으로 제한됩니다. IP를 통해 15분당 최대 3개의 요청이 허용됩니다.

## 정보 블록 및 폐쇄된 데이터 폴더

"Infoblocks" 섹션에서는 데이터 세트를 생성하고 행을 편집하고 드래그할 수 있습니다. 인포블록 이름과 열 키에는 `A–Z`, `a–z`, `0–9`, 하이픈, 밑줄이 허용됩니다. 이름과 키는 공백 없이 입력됩니다. 열 이름과 셀 값은 러시아어로 작성할 수 있습니다. 컨트롤은 열 유형에 해당하며 저장은 AJAX를 통해 수행됩니다. ☰ "텍스트로 편집" 버튼은 전체 정보 블록을 구분 기호 `|`와 복사 버튼을 사용하여 CSV로 전환합니다. 처음 세 줄에는 열의 키, 이름 및 유형이 포함됩니다. 그런 다음 데이터 라인이 있습니다. CSV의 날짜는 `ГГГГ-ММ-ДД`이고, 예/아니요는 `1` 또는 `0`로 저장됩니다.

```text
name|phone|is_open
Название|Телефон|Открыто
text|tel|bool
Справочная|+7(903)123-45-67|1
```

`phones` 템플릿은 `tel` 유형의 열과 제목이 있는 텍스트 열을 사용합니다. `$block['columns']` 및 `$block['rows']`를 사용할 수 있는 `templates/local/iblock/имя.php`에 템플릿을 배치할 수 있습니다.

코드 내부의 `/data/myiblock.txt` 경로는 `data/myiblock.txt.php` 파일에 해당합니다. 이것은 직접 호출할 때 404를 반환하는 PHP 스텁이 포함된 UTF-8 텍스트입니다. `router.php`는 로컬로 실행할 때 전체 폴더를 닫습니다. `data/`에는 Apache 및 IIS에 대한 규칙이 있습니다. Apache의 경우 `data/.htaccess`를 활성화합니다. Nginx에서는 하위 디렉터리에 설치할 때 접두사를 고려하여 사이트 구성에서 폴더가 닫히도록 구성합니다.

```nginx
location = /data { return 404; }
location ^~ /data/ { return 404; }
```

설치 후 `/data/`에 대한 직접 요청과 infoblock 파일이 403 또는 404를 수신하는지 확인하십시오.

## HTML 조각 로드

일반적인 주소 `/contacts/`는 전체 페이지를 엽니다. `?ajax=1` 요청은 `X-Site-Fragment` 헤더에 세션 키가 있는 경우 H1 및 처리된 콘텐츠와 함께 `<main>`를 반환합니다. 조각은 현재 원본에 연결됩니다. 키가 있는 페이지와 조각은 캐싱 없이 제공됩니다.

사이트 페이지의 JavaScript에서 내장 기능을 사용하십시오.

```js
const html = await window.siteFetchContent('/contacts/');
document.getElementById('content').outerHTML = html;
```

하위 디렉터리에 설치하는 경우 사이트 접두어가 포함된 URL을 전달하세요. 스크립트와 스타일은 조각을 삽입하는 페이지에서 가져옵니다. 공개 페이지는 일반 주소에서 계속 액세스할 수 있습니다.

## 템플릿 및 리소스

"설정 → 라이브러리 및 글꼴"에서 jQuery, Bootstrap, Font Awesome, Material UI, Alpine.js, htmx, Chart.js 및 GLightbox가 별도로 활성화됩니다. Font Awesome은 로컬에 저장됩니다. 나머지 라이브러리는 활성화되면 브라우저를 통해 CDN에서 다운로드됩니다. 재질 UI는 `type="module"`부터 `import { Button } from '@mui/material'`까지의 스크립트에서 사용할 수 있습니다. 아이콘의 경우 `[fa-icon=house]` 또는 일반적인 마크업 `<i class="fa-solid fa-house"></i>`가 적합합니다.

키릴 문자가 포함된 10개의 Google 글꼴을 사용할 수 있습니다. 선택 항목이 사이트의 시스템 글꼴을 대체합니다. "시스템" 값은 이전 디자인을 반환합니다. "설정 → 테마 및 색상 → 저장된 테마"에는 밝은 옵션과 어두운 옵션이 있는 미리 만들어진 5개의 팔레트가 있습니다.

| 길 | 목적 |
| --- | --- |
| `index.php` | 홈 페이지 및 일반 진입점 |

## 엔진 업데이트

새로 설치하려면 전체 아카이브가 필요합니다. 라이브 사이트의 경우 `php-site-update.zip`를 사용하세요. 여기에는 엔진과 표준 템플릿만 포함되어 있습니다. 저장된 페이지, 정보 블록, 설정, 비밀번호, 메시지 및 사용자 확장은 아카이브에 포함되지 않습니다.

"설정 → 업데이트"에서 "엔진 업데이트"를 클릭하거나 호스팅 스케줄러에서 동일한 검사를 실행하세요.

```sh
php update.php --github
```

기본 소스는 `bandaletov72/php-site-updates`입니다. 자신의 리포지토리의 경우 `SITE_GITHUB_REPO`로 설정하세요. 공개 저장소에는 토큰이 필요하지 않습니다. 개인 저장소의 경우 콘텐츠에 대한 읽기 액세스 권한이 있는 PHP 프로세스에 `SITE_GITHUB_TOKEN` 변수를 전달합니다. 서버에는 Zip 및 OpenSSL PHP 확장과 GitHub에 대한 HTTPS 요청 기능이 필요합니다.

수동 설치의 경우 ZIP을 사용하세요.

```sh
php update.php /path/to/php-site-update.zip
```

`update.php`가 없는 이전 버전에서는 먼저 프로젝트 위에서 패키지의 압축을 풀고 기존 `.htaccess`와 `maintenance/`의 파일(있는 경우)을 유지합니다. 표준 템플릿을 편집한 경우 업데이트하기 전에 편집 내용을 `templates/local/`로 전송하세요. 설치 프로그램은 파일의 목록과 체크섬을 확인하고, GitHub의 경우 신뢰할 수 있는 공개 키 `maintenance/release-public.pem`를 사용하여 서명도 확인합니다.

다음 릴리스에서는 버전을 `app/version.php`로 변경하고 `php update.php --build php-site-update.zip`를 통해 패키지를 빌드합니다. SHA-256을 사용하는 RSA 개인 키로 ZIP에 서명하고 개인 키를 사이트와 별도로 저장하세요. 그런 다음 ZIP 및 `.sig`를 `vX.Y.Z` 태그가 있는 GitHub 릴리스 또는 `updates/vX.Y.Z/`로 푸시하고 `updates/latest.json`를 `{"version":"X.Y.Z"}`로 업데이트합니다.

## 확장

업데이트와 함께 엔진 모듈을 `app/extensions/`에 추가할 수 있습니다. 업데이트 패키지 외부의 `extensions/`에 자신의 모듈을 저장하십시오. PHP 파일은 정의 배열을 반환합니다. 단일 구성 요소에는 `kind`가 `single`와 같고 인수가 있는 구성 요소는 `wrapped`와 같습니다. 엔진은 기존 페이지의 새 코드를 인식합니다. 구성 요소는 `settings`에서 옵션 메뉴를 선언하고 각 옵션을 `label`, `default` 및 배열 `options`로 설정할 수 있습니다. 값은 `$context['settings']`로 수신됩니다.

```php
<?php
if (!defined('SITE_ROOT')) {
    http_response_code(404);
    exit;
}

return ['notice' => [
    'kind' => 'wrapped',
    'render' => static function (string $text, array $context): string {
        return '<strong>' . site_escape($text) . '</strong>';
    },
]];
```

예제 구성 요소는 `[notice]Важное сообщение[/notice]`로 삽입됩니다.

## 버전 1.6.3의 새로운 기능

### 홈 및 개인 정보 보호 정책

홈 페이지와 /privacy.php 페이지를 편집하려면 "디자인 템플릿"을 엽니다. [page-content] 코드는 메인 페이지의 내용을 표시합니다. 정책 [site-name] 및 [site-url]에서는 "설정 → 일반"에서 이름과 공개 주소를 가져옵니다. 사이트 및 데이터 처리에 대한 정보로 초기 텍스트를 완성하세요.

### 쿠키 및 맨 위로 돌아가기

바닥글에서 [conf-policy]는 정책에 대한 링크를 제공하고, [cookies]는 설정을 열고, [top]는 페이지 상단으로 스크롤합니다. 분석 및 내장 CMS 지도는 합의를 기다리고 있습니다. 템플릿이나 서비스 헤더에 수동으로 추가된 스크립트에는 자체 구성이 필요합니다.

### 편집기 functions.php

"서비스 헤더" 탭 다음에 "디자인 템플릿 → 기능"을 엽니다. 반환된 배열에 클로저를 추가합니다. PHP 템플릿에서 `translit("Москва")` 또는 `ew_call("translit", "München")`를 호출합니다. HTML에 [func=translit value="Москва и München"]를 삽입하세요. 이 예에서는 `Moskva i Muenchen`를 생성합니다.

### 표준 템플릿 편집

"디자인 템플릿" 필드에는 강조 표시된 PHP 및 HTML 소스 코드가 이미 포함되어 있습니다. 표준 템플릿을 편집할 때 "Custom PHP"를 선택하세요. 저장하면 사용자 정의 버전이 생성됩니다. 템플릿 옆에 있는 버튼을 사용하면 마지막 편집 내용을 취소하거나 원본을 복원할 수 있습니다.

### 저장하기 전에 PHP 확인

디자인 템플릿, 모듈 및 functions.php 편집기는 `php -l` 명령을 사용하여 구문을 확인합니다. 오류가 있으면 이전 버전이 유지됩니다. 서버에서 PHP CLI를 선택하려면 `SITE_PHP_LINT_BINARY` 변수를 사용하십시오.

### 백라이트 및 컴팩트 검색

CodeMirror는 새로 설치 시 기본적으로 활성화됩니다. 설정은 "라이브러리 및 글꼴"에 있습니다. 압축 검색에서는 필드가 왼쪽으로 확장되고 십자 표시로 줄이 지워지며 Enter 키를 누르면 검색이 시작됩니다.

### 관리 메뉴 및 편집 패널

관리자 패널 헤더 아래의 메뉴와 사이트의 편집 패널에는 캡션과 함께 아이콘이 표시됩니다. 아이콘은 좁은 화면에 남아 있습니다. 좁은 화면에서는 마우스를 가져가면 도구 설명이 열리고 키보드 초점이 맞춰집니다. "숨기기"는 나머지 페이지 작업 옆에 있습니다. 편집 모드 스위치는 오른쪽에 있습니다.

### PHP 모듈 설명 및 코드

"PHP 모듈"에서 간단한 설명은 일반 텍스트용입니다. 함수 본문을 별도의 필드인 "소스 코드 · PHP"에 붙여넣습니다.

## 설정 파일, 지도 및 서식 · 1.6.5

유지 관리의 설정 파일에서 .htaccess, robots.txt, sitemap.xml을 편집합니다. 생성 시 사이트맵에 포함하도록 지정한 공개 페이지만 사용합니다. 이전 .htaccess 버전을 복원할 수 있습니다.

위도와 경도를 입력하세요. [map]은 현재 페이지 위치를 표시하고 [maps]는 좌표가 있는 공개 페이지를 모읍니다. center와 zoom으로 위치와 배율을 설정합니다. 연동 메뉴에서 지도 제공사를 선택합니다.

[main-menu]는 헤더 아래의 펼침 메뉴입니다. 사용자 서식과 기기별 표시 여부를 설정할 수 있습니다. 조각 메뉴에서 도메인 추가 양식을 열 수 있습니다. 개인정보 처리방침 링크에는 [privacy]를 사용하세요.

연동 메뉴에서 JivoSite, Microsoft Clarity, Umami Cloud ID, Botfaqtor 코드 또는 Slack 웹훅을 설정하세요. 각 필드 옆에 설명 링크가 있습니다. Zadarma에서 잔액을 확인하거나 SMS와 통화를 테스트할 수 있습니다. 테스트에는 요금이 발생할 수 있습니다. [payment]에 YooMoney, PayPal, SBP 결제 링크를 설정하고 결제 상태는 제공사에서 확인하세요.

HTML 편집기와 시각적 편집기의 아이콘으로 글자 서식, H1–H5 제목 및 목록을 설정할 수 있습니다. 커서를 놓고 서식, 컴포넌트, 이미지 또는 아이콘을 선택하세요. 저장된 양식과 컴포넌트 옵션을 이용할 수 있습니다. Font Awesome은 라이브러리를 활성화하면 사용할 수 있습니다.

### 지도에서 지점 선택

Yandex Maps 콘솔에서 «JavaScript API» 키를 만들고 HTTP Referer로 제한하세요. 페이지의 지도 탭에서 지점을 선택한 뒤 좌표를 적용하세요.

텍스트를 선택하여 정렬하거나 서식을 지웁니다. 이미지를 클릭해 속성을 열고 끌어서 이동하거나 모서리로 크기를 조절합니다. URL, 이메일, 전화번호, 앵커를 링크할 수 있습니다. 버튼은 URL, 양식, 콜백 또는 결제 링크를 엽니다.

HTML과 시각 편집기 탭에서 모드를 전환합니다. SUP, SUB, 문단 버튼은 해당 요소를 삽입합니다. 구성 요소 이름 옆에 코드가 표시됩니다. 삽입할 때 없는 폴더를 만듭니다. 폴더 이름에는 영문, 숫자, 하이픈, 밑줄을 사용할 수 있습니다. 언어 탭에서 사이트 언어 설정으로 이동합니다. 삽입 패널은 편집 영역 위에 열립니다. 패널 상단의 «닫기» 또는 Esc 키를 누르면 패널이 닫히고 버튼 선택이 해제됩니다. 도구 모음의 화살표로 서버를 통해 최근 텍스트 편집을 최대 10개까지 실행 취소하거나 다시 적용할 수 있습니다. 시계 아이콘은 마지막으로 저장한 텍스트를 불러옵니다. 저장하지 않은 변경 사항이 있으면 페이지를 떠날 때 확인 메시지가 표시됩니다. 화살표 앞의 저장 아이콘은 저장하지 않은 변경 사항이 있으면 강조 표시됩니다. 텍스트를 선택한 뒤 텍스트 서식을 엽니다. 글꼴 크기, 텍스트 색, 배경색 또는 사이트 설정에서 활성화한 글꼴을 선택합니다.

```text

[button action="form" label="Write to us" form="form1"]
[button action="callback" label="Call me"]
[button action="payment" label="Pay" amount="1250.00" currency="RUB" yoomoney="410010000000000"]
[map]
[maps]
```

## 페이지 템플릿

새 페이지를 만들 때 템플릿을 선택하면 편집 가능한 콘텐츠와 SEO 필드가 채워집니다. 페이지 템플릿에서 사용자 템플릿을 추가할 수 있습니다. 지도, 양식, 구매는 각 구성 요소의 설정을 사용합니다.

템플릿의 CSS와 JavaScript는 페이지 필드로 복사됩니다. HTML에 사용자 클래스를 추가하고 템플릿의 CSS에서 스타일을 지정하세요.

### 공통 클래스

레이아웃 컨테이너, 반응형 그리드, 강조 영역, 카드 및 강조된 가격.

`.page-preset` · `.page-preset-grid` · `.page-preset-hero` · `.page-preset-card` · `.page-preset-price`

레이아웃 템플릿은 처음에 접혀 있습니다. 제목을 누르거나 모두 펼치기를 선택하세요. 다시 누르면 목록이 접힙니다.

배너 캐러셀 전체 너비를 바꾸려면 편집 모드를 켜고 배너 옆 구성 요소 편집에서 블록 너비를 선택하세요.

## 도시 · 전화번호 · 1.6.18

도시 이름만 필수입니다. 도메인과 전화번호는 선택 항목입니다. 전화번호는 +와 국가 번호를 포함해야 합니다. 예: +7 (900) 000-00-00. [tel]과 같은 코드도 사용할 수 있습니다.

저장된 도시, 도메인에 연결된 도시, 목록의 첫 도시 순으로 선택합니다. 도시가 없으면 사이트 공통 전화번호가 표시됩니다.

양식, 콜백 요청 및 신규 주문은 도시 이메일로 전송되며 비어 있으면 사이트의 기본 주소를 사용합니다. 두 주소 모두 없으면 양식의 수신자를 사용합니다. 비어 있는 소셜 링크는 사이트 설정을 상속합니다.

편집 모드에서 템플릿에 마우스를 올리면 편집 링크가 표시됩니다. 설치된 모든 [php] 구성 요소의 소스와 설정을 대화상자에서 열 수 있습니다. 슬라이드 편집기에는 양식 이름과 코드가 표시됩니다. 사이드바 없는 페이지에서 독립된 [banners width=100] 블록은 창 너비를 채웁니다. 템플릿 편집기는 사이트 내 모달에서 열립니다.

파일 관리자는 삭제 전에 참조를 확인하고 비어 있지 않은 폴더를 백업합니다. 배너에 제목과 부제목을 설정할 수 있습니다.

전화번호는 입력하는 동안 검증합니다. 8로 시작하는 러시아 번호는 +7로 바뀝니다. 전송을 마치면 양식이 숨겨지고 창을 다시 열면 확인 메시지가 표시됩니다.

선택한 국가 번호는 +가 없는 번호에 추가합니다. +로 시작하는 번호는 입력한 국가 번호를 유지합니다.

## 디자인 테마

파일을 테마에 복사해 저장합니다. 누락된 파일은 기본 배포본을 사용합니다. 레이아웃 변경, 새 코드, 기록과 도메인 설정은 활성 테마에만 저장됩니다. css/theme.css와 js/theme.js에 스타일과 스크립트를 추가할 수 있습니다.

`templates/themes/demo/header.php` · `templates/themes/demo/components/banners.php`

모바일 메뉴 하단에 언어가 표시됩니다. 데스크톱에서는 헤더 아래 메뉴의 검색 옆에 지구본이 있습니다.

갤러리, 배너 및 파일 목록은 활성 테마 폴더를 우선 사용하고, 폴더가 없으면 공통 파일을 사용합니다. 새 폴더, 업로드, 로고와 파비콘은 테마에 저장됩니다. 백업에 테마와 설정이 포함됩니다.

창 너비(width=page), 콘텐츠 너비(width=content), 상위 블록 너비(width=parent)를 선택할 수 있습니다. height는 데스크톱, mobile-height는 휴대전화에 적용됩니다. auto는 기본 크기를 유지합니다.

`[banners width=page height=520 mobile-height=240]` · `[form1 width=parent]`

마지막 탐색 경로에 메인 메뉴에서 숨긴 공개 형제 섹션도 표시됩니다. 링크는 설정된 URL을 사용합니다.

## 디자인 테마 · КОНТУР · 1.6.19

완성형 사이트 테마는 디자인, 페이지, 데이터 블록, 설정을 함께 전환합니다. 다른 테마는 사이트 공용 페이지를 사용합니다.

체크 표시는 CMS 기본 파일보다 우선하는 테마 파일을 뜻합니다. 파일을 편집하거나 복원할 수 있습니다.

**출고 상태로 복원**

### 포트폴리오

콘텐츠 → 데이터 블록에서 kontur-works를 엽니다. 제목, 분류, 설명, 쉼표로 구분한 사진과 선택 링크를 입력합니다. 첫 사진이 표지가 됩니다. 다른 컬렉션에도 같은 열을 사용합니다.

```text
[portfolio]
[iblock=portfolio limit=2]/data/kontur-works.txt[/iblock]
[maps source=kontur-map]
```
