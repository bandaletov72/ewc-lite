## 페이지에서 컴포넌트 데이터 편집 · 1.6.6

편집 모드에서 정보 블록, [formX] 양식, [tel] 조각 등은 데이터와 전체 화면 메뉴를 제공합니다. 보기 유형 목록에는 등록된 서식이 표시됩니다. 루트 폴더는 섹션을 최상위로 옮깁니다. [list-pages]는 섹션과 하위 폴더의 공개 페이지를 나열합니다. 언어 메뉴는 바깥을 클릭하거나 Escape 키를 누르면 닫힙니다.


## 설정 파일, 지도 및 서식 · 1.6.5

유지 관리의 설정 파일에서 .htaccess, robots.txt, sitemap.xml을 편집합니다. 생성 시 사이트맵에 포함하도록 지정한 공개 페이지만 사용합니다. 이전 .htaccess 버전을 복원할 수 있습니다.

위도와 경도를 입력하세요. [map]은 현재 페이지 위치를 표시하고 [maps]는 좌표가 있는 공개 페이지를 모읍니다. center와 zoom으로 위치와 배율을 설정합니다. 연동 메뉴에서 지도 제공사를 선택합니다.

[main-menu]는 헤더 아래의 펼침 메뉴입니다. 사용자 서식과 기기별 표시 여부를 설정할 수 있습니다. 조각 메뉴에서 도메인 추가 양식을 열 수 있습니다. 개인정보 처리방침 링크에는 [privacy]를 사용하세요.

연동 메뉴에서 JivoSite, Microsoft Clarity, Umami Cloud ID, Botfaqtor 코드 또는 Slack 웹훅을 설정하세요. 각 필드 옆에 설명 링크가 있습니다. Zadarma에서 잔액을 확인하거나 SMS와 통화를 테스트할 수 있습니다. 테스트에는 요금이 발생할 수 있습니다. [payment]에 YooMoney, PayPal, SBP 결제 링크를 설정하고 결제 상태는 제공사에서 확인하세요.

HTML 편집기와 시각적 편집기의 아이콘으로 글자 서식, H1–H5 제목 및 목록을 설정할 수 있습니다. 커서를 놓고 서식, 컴포넌트, 이미지 또는 아이콘을 선택하세요. 저장된 양식과 컴포넌트 옵션을 이용할 수 있습니다. Font Awesome은 라이브러리를 활성화하면 사용할 수 있습니다.

폴더 이름을 누르면 오른쪽에서 섹션을 관리할 수 있습니다. 상위 섹션, 데스크톱과 모바일 메뉴 또는 이동 URL을 설정하세요. 빈 섹션은 하위 항목을 표시합니다. 유지 관리에서 /contact.html => /contacts/ 규칙을 추가하고 /error/ 페이지를 수정할 수 있습니다. 모바일에서는 언어와 검색이 아이콘으로 표시됩니다.

```text
[map]
[map center="55.7558,37.6173" zoom=14]
[maps center="55.7558,37.6173" zoom=11]
[main-menu]
[lang]
[privacy]
[payment]
```

```php
$var = translit("Москва"); // Moskva
```


## 관리자 화면 상단 버튼 · 1.6.4

지구본 아이콘은 사이트를 열고 화살표 아이콘은 로그아웃합니다. 휴대전화에서는 아이콘만 표시됩니다. 마우스를 올리거나 키보드로 초점을 맞추면 이름을 볼 수 있습니다.

콘텐츠, 양식 및 요청, 사이트 및 서비스는 바로 열립니다. 기본 메뉴 아래에 선택한 섹션의 탭이 표시됩니다.

홈 화면(index.php)이나 템플릿의 HTML에 [bread-crumbs] 또는 [search]를 넣으면 지정한 위치에 한 번씩 표시됩니다. 탐색 경로와 검색 설정이 적용됩니다. [privacy]는 /privacy/로 연결됩니다. 정책 문구는 페이지 메뉴에서 편집할 수 있습니다.

```text
[bread-crumbs]
[search]
[privacy]
```


## 버전 1.6.3의 새로운 기능

### 홈 및 개인 정보 보호 정책

홈 페이지와 /privacy.php 페이지를 편집하려면 "디자인 템플릿"을 엽니다. [page-content] 코드는 메인 페이지의 내용을 표시합니다. 정책 [site-name] 및 [site-url]에서는 "설정 → 일반"에서 이름과 공개 주소를 가져옵니다. 사이트 및 데이터 처리에 대한 정보로 초기 텍스트를 완성하세요.

### 쿠키 및 맨 위로 돌아가기

바닥글에서 [conf-policy]는 정책에 대한 링크를 제공하고, [cookies]는 설정을 열고, [top]는 페이지 상단으로 스크롤합니다. 분석 및 내장 CMS 지도는 합의를 기다리고 있습니다. 템플릿이나 서비스 헤더에 수동으로 추가된 스크립트에는 자체 구성이 필요합니다.

### 편집기 functions.php

"서비스 헤더" 탭 다음에 "디자인 템플릿 → 기능"을 엽니다. 반환된 배열에 클로저를 추가합니다. PHP 템플릿에서 `translit("Москва")` 또는 `ew_call("translit", "München")`를 호출합니다. HTML에 [func=translit value="Москва и München"]를 삽입하세요. 이 예에서는 `Moskva i Muenchen`를 생성합니다.

### 표준 템플릿 편집

"디자인 템플릿" 필드에는 강조 표시된 PHP 및 HTML 소스 코드가 이미 포함되어 있습니다. 표준 템플릿을 편집할 때 "Custom PHP"를 선택하세요. 저장하면 사용자 정의 버전이 생성됩니다. 템플릿 옆에 있는 버튼을 사용하면 마지막 편집 내용을 취소하거나 원본을 복원할 수 있습니다.

### 저장하기 전에 PHP 확인

디자인 템플릿, 모듈 및 functions.php 편집기는 `php -l` 명령을 사용하여 구문을 확인합니다. 오류가 있으면 이전 버전이 유지됩니다. 서버에서 PHP CLI를 선택하려면 `SITE_PHP_LINT_BINARY` 변수를 사용하십시오.

### 백라이트 및 컴팩트 검색

CodeMirror는 새로 설치 시 기본적으로 활성화됩니다. 설정은 "라이브러리 및 글꼴"에 있습니다. 압축 검색에서는 필드가 왼쪽으로 확장되고 십자 표시로 줄이 지워지며 Enter 키를 누르면 검색이 시작됩니다.

### 관리 메뉴 및 편집 패널

관리자 패널 헤더 아래의 메뉴와 사이트의 편집 패널에는 캡션과 함께 아이콘이 표시됩니다. 아이콘은 좁은 화면에 남아 있습니다. 좁은 화면에서는 마우스를 가져가면 도구 설명이 열리고 키보드 초점이 맞춰집니다. "숨기기"는 나머지 페이지 작업 옆에 있습니다. 편집 모드 스위치는 오른쪽에 있습니다.

### PHP 모듈 설명 및 코드

"PHP 모듈"에서 간단한 설명은 일반 텍스트용입니다. 함수 본문을 별도의 필드인 "소스 코드 · PHP"에 붙여넣습니다.

## 버전 1.6.2의 새로운 기능

### 관리자 및 도움말 언어

지역 설정에서 원하는 언어를 활성화하세요. 헤더의 언어 선택 메뉴는 현재 섹션을 유지하면서 인터페이스와 도움말을 변경합니다. 페이지 텍스트와 설정 값은 원래 형식으로 저장됩니다.

### 지하 장식

코드 [author]는 서명 Eurowebcart CMS Light, 작성자 이름 Бандалетов Павел 및 GitHub에 대한 링크를 표시합니다. 사용자 정의 HTML 바닥글에 서명을 넣을 위치를 선택하려면 [author]를 해당 줄에 붙여넣으세요.

### 편집 모드의 백라이트

구성요소 편집 링크 위로 마우스를 가져가거나 키보드 포커스를 해당 링크로 설정하십시오. 프레임은 이 특정 삽입의 출력을 강조 표시합니다.

### 검색을 변경할 위치

'설정 → 일반'에서 검색 유형을 선택하세요. "유지 관리"에서는 페이지 색인을 다시 생성할 수 있으며 관리자 헤더의 필드는 설정별로 검색됩니다.

### 결과 및 추천

검색 결과는 페이지당 20개씩 번호와 함께 표시됩니다. 간단한 검색창은 돋보기 왼쪽으로 펼쳐지고 입력란 안에 Enter 아이콘이 나타납니다. 관리자 검색 추천은 설정으로 바로 연결됩니다.

## 버전 1.6.1의 새 기능

### 검색

기본 설정에서 검색을 끄거나 돋보기 또는 확장 표시를 선택합니다. 관리자 상단에서도 설정을 검색할 수 있습니다. 관리자 편집 후 색인이 갱신되며 FTP 변경에는 예약 갱신을 사용합니다. 포함 페이지와 데이터 블록을 색인하고 PHP 모듈은 실행하지 않습니다.

### PHP 모듈

모듈을 펼치면 설정과 사용 중인 페이지가 표시됩니다. 모듈 ID, 파일 이름 및 함수 본문을 입력하세요. 파일 이름을 바꿔도 [php]id[/php]는 유지됩니다. CodeMirror를 켜면 구문을 강조합니다.

### 템플릿과 번역

템플릿마다 최대 여덟 번의 변경을 취소하거나 원본 PHP를 복원할 수 있습니다. 도메인별로 기록이 따로 저장됩니다. HTML은 관리자에서 편집하고 PHP는 templates/local/에 둡니다. 번역을 만드는 중에도 언어를 전환할 수 있으며 페이지를 옮기면 번역도 이동합니다.

### 연동과 유지 관리

CAPTCHA, 지도, 전화, 분석 설정에 공식 링크가 있습니다. 콜백 HTTP URL과 토큰을 입력할 수 있습니다. 등록된 하위 도메인에서 기본 도메인으로 이동해도 기존 설정이 적용됩니다. php update.php --scheduled 명령을 15분마다 실행하세요.

## 버전 1.6.0의 새 기능

### 검색과 캐시

페이지를 게시하거나 관리자 화면 또는 FTP에서 수정한 경우 유지 관리에서 텍스트 색인을 다시 생성하세요. 추천 검색은 방문자 언어의 공개 페이지를 사용합니다. 캐시는 기본적으로 꺼져 있으며 같은 곳에서 설정하거나 지울 수 있습니다. 양식과 동적 요소는 요청마다 처리합니다.

### 사이트에서 편집

로그인 후 상단 바 오른쪽 스위치로 사이트 전체 편집 모드를 켭니다. 구성 요소 옆의 링크에서 옵션을 수정할 수 있습니다. 페이지 CSS와 JS는 라이트박스에서 엽니다. 관리자 화면에서 HTML, 시각 편집, 코드 삽입, AJAX 일괄 업로드와 정렬을 사용할 수 있습니다.

### 구성 요소와 탐색

지정하지 않은 값은 공통 설정을 따릅니다. width에는 100, 50, 33, 25와 선택적인 %를 쓸 수 있습니다. 모바일에서는 한 열로 표시됩니다. numbers=off로 번호를 숨기고 좌우로 밀어 사진을 넘길 수 있습니다. 모바일 메뉴는 오른쪽에서 열리며 경로 탐색은 기본 설정에서 끌 수 있습니다.

```text
[gal width=50 numbers=off arrows=on fit=cover]/images/myfotos/[/gal]
[fotos width=50% columns=3 captions=on]/images/myfotos/[/fotos]
[files width=33 icons=off size=on download=on]/files/myfiles/[/files]
```

### 언어·디자인·가격

지역 설정에서 관리자 및 사이트 언어, 통화, 숫자·날짜·시간 형식과 시간대를 고릅니다. 번역은 index.php 옆의 index_en.php에 저장하며, 번역이 없으면 기본 콘텐츠를 표시합니다. 가격 필드는 선택한 통화를 사용합니다. 테마 색상과 모드를 미리 보고 밝은·어두운 로고를 따로 업로드하거나 Roboto Condensed를 사용자 문구로 확인할 수 있습니다.

```text
/contacts/index.php → /contacts/index_en.php
```

### 양식·요청·연동

CAPTCHA 설정에서 Google reCAPTCHA v2 공통 키를 관리하고 양식별로도 설정할 수 있습니다. 메시지와 콜백 요청은 읽지 않은 항목부터 한 페이지에 20개씩 표시됩니다. 연동에서 Zadarma, Telegram, 분석 도구 및 Google 또는 Yandex 지도와 클러스터를 설정합니다. 라이브러리 라이트박스에서 현재 버전을 테스트하고 삽입 코드를 확인합니다. CodeMirror에는 자동, HTML, CSS, JS, PHP, RAW 모드가 있습니다.

```text
[map lat=55.7558 lng=37.6173 title="Office" zoom=13 provider=yandex url="/contacts/" button="Open"]
```

```text
[callback button="Call me" title="Callback" submit="Send" placeholder="+7(900)123-45-67"]
```

### PHP 모듈

PHP 모듈에서 이름, 설명, 삽입 가능 여부를 수정합니다. server-date는 지역 날짜 형식을 사용합니다. 실행 파일은 개발자가 보호된 디렉터리에 설치합니다.

```text
[php]server-date[/php]
```

## 페이지 설정 · 1.6.8

편집에서 콘텐츠를 작성하세요. 주소, 메뉴, 공개 일정은 페이지 설정에 있습니다. SEO에는 제목, 설명, 키워드, 사이트맵 포함 여부가 있습니다. 지도에는 좌표와 태그 예제가 있습니다.

날짜를 비워 두면 기간 제한이 없습니다. 사이트의 시간대를 사용합니다. 숨긴 페이지는 별도로 공개해야 합니다.

- `[map]` — 현재 페이지의 위치를 표시합니다.
- `[maps]` — 공개된 모든 페이지의 위치를 표시합니다.

## 배너 및 이미지 편집기 · 1.6.8

구성 요소에서 세트와 슬라이드를 관리하세요. 폴더의 사진을 사용하고 설명과 링크, 양식 또는 콜백 버튼을 추가하고 표시 기간을 설정할 수 있습니다. 편집 모드에서는 슬라이드 작업이 표시됩니다. 이미지 선택기에서 폴더 탐색, 업로드, 삭제 및 GD를 사용한 회전 또는 크기 조정 사본을 만들 수 있습니다. Font Awesome 아이콘은 이름으로 검색할 수 있습니다.

```text
[banners]
[banners set=summer arrows=on numbers=off]
[banners]/images/myfotos/[/banners]
```

## 언어 · 1.6.9

언어 탭에는 페이지의 언어가 표시됩니다. 열기를 누르면 저장된 버전으로 이동합니다. 번역 만들기는 빈 편집기를 엽니다.

하위 섹션은 현재 섹션 안에, 같은 수준의 섹션은 그 옆에, 최상위 섹션은 사이트의 맨 위 수준에 생성됩니다.

## PHP 호환성과 탐색 · 1.6.10

최소 버전은 PHP 7.2입니다. 사이트와 관리자 화면은 PHP 8.6을 지원합니다. 사용자 정의 모듈과 템플릿은 서버에 설치된 버전의 문법을 사용하세요.

[bread-crumbs]의 현재 항목을 펼치면 주 메뉴에 있는 같은 수준의 공개 섹션을 볼 수 있습니다. 설정한 URL은 메뉴, 섹션 목록, 탐색 경로, 검색 결과와 제안에 사용됩니다.

휴지통은 인포블록 편집기에서 행을 제거합니다. 열을 제거하면 해당 열의 값도 모두 사라집니다. 변경 사항은 저장할 때 기록되며 순서 변경 뒤의 자동 저장도 포함됩니다.

### 사이트 백업

비공개 ZIP에는 페이지, 미디어, 인포블록, 설정, 템플릿, PHP 모듈이 들어갑니다. 관리자 계정과 요청은 별도로 보관됩니다. PHP Zip이 필요합니다.

콘텐츠와 설정을 교체합니다. 먼저 현재 상태를 백업합니다.

### 사용하지 않는 파일 정리

저장된 콘텐츠에서 참조되지 않는 미디어를 찾습니다. 목록을 검토하고 파일을 선택하세요. 삭제 전 백업을 만듭니다. 구성 요소 코드를 제거해도 폴더와 파일은 유지됩니다.

### 지도에서 지점 선택

Yandex Maps 콘솔에서 «JavaScript API» 키를 만들고 HTTP Referer로 제한하세요. 페이지의 지도 탭에서 지점을 선택한 뒤 좌표를 적용하세요.

텍스트를 선택하여 정렬하거나 서식을 지웁니다. 이미지를 클릭해 속성을 열고 끌어서 이동하거나 모서리로 크기를 조절합니다. URL, 이메일, 전화번호, 앵커를 링크할 수 있습니다. 버튼은 URL, 양식, 콜백 또는 결제 링크를 엽니다.

HTML과 시각 편집기 탭에서 모드를 전환합니다. SUP, SUB, 문단 버튼은 해당 요소를 삽입합니다. 구성 요소 이름 옆에 코드가 표시됩니다. 삽입할 때 없는 폴더를 만듭니다. 폴더 이름에는 영문, 숫자, 하이픈, 밑줄을 사용할 수 있습니다. 언어 탭에서 사이트 언어 설정으로 이동합니다.

```text
[button action="url" label="Contacts" url="/contacts/"]
[button action="form" label="Write to us" form="form1"]
[button action="callback" label="Call me"]
[button action="payment" label="Pay" amount="1250.00" currency="RUB" yoomoney="410010000000000"]
[map]
[maps]
```

## 판매 · 1.6.11

판매 탭에서 가격과 결제 수단을 설정하거나 언어별로 변경하세요. [item-price]와 [item-buy-button]을 삽입합니다. 결제 전에 주문을 기록합니다. 상태 알림은 이메일이나 Zadarma SMS로 보낼 수 있습니다.

주문 접수 · 결제 확인 · 발송 완료 · 종료 · 취소

```text
[item-price]
[item-buy-button]
```

이미지를 삽입하려면 파일이나 URL을 선택하세요. 이미지를 클릭하면 크기, 정렬, 네 방향 여백 및 CSS를 설정할 수 있습니다. 이미지 정렬은 텍스트와 독립적입니다. HTML에서는 블록이 줄별로 표시됩니다. [list-pages]는 구성 요소 목록에 있습니다. CMS 로고는 테마 색상을 사용합니다.

## 데이터 블록 차트

페이지 편집기에서 구성 요소 삽입을 열고 표 또는 차트를 선택합니다. 차트를 사용하려면 Chart.js를 활성화하고 레이블 열과 숫자 또는 가격 열을 선택합니다. 원형, 도넛, 극좌표 차트에는 음수가 아닌 값 계열 하나가 필요합니다. 라이브러리를 끄면 표가 표시됩니다.

편집기를 다시 열면 저장한 양식, 템플릿, 스니펫과 등록한 구성 요소가 삽입 목록에 표시됩니다. 새 배너 세트 ID에는 A–Z, a–z, 하이픈, 밑줄을 쓸 수 있습니다. [banners] 폴더에 이미지를 올리면 각 파일 옆에 슬라이드 편집 링크가 표시됩니다. 편집 모드에서는 선택한 슬라이드만 대화상자에 열리고 기본 설정은 별도 링크로 이동합니다. 캐러셀, 갤러리, 파일 목록의 저장 옆 파일 관리자에서 업로드, 삭제, 정렬, 하위 폴더 생성(A–Z, a–z, 0–9, -, _)을 할 수 있습니다. 슬라이드 색상은 사각형 견본으로 표시됩니다.

```text
[iblock=table]/data/myiblock.txt[/iblock]
[iblock=charts type=line labels=month values=sales,orders]/data/myiblock.txt[/iblock]
[banners set=summer-promo]
```
