# 模板和组件

## 设计模板

### 页眉、菜单和页脚

整页自动连接这些块。通用版本在“设计模板”中编辑，对于单个域，则在“域”部分中编辑。

```text
[header]
[mobile-menu]
[menu]
[footer]
```

### 插入另一页

插入已发布页面的内容。最大嵌套为十层。跳过同一链中重复的页面。

```text
[include]/contacts/[/include]
```

### 菜单中的链接

“在菜单中显示”复选框添加到标准菜单的链接。如果名称为空，则使用标题。如果取消选中文件夹页面的复选框，其子页面也将从菜单中消失。

```text
MenuVisible: 1
Menu: Контакты
```

### CSS 和 JavaScript

通用代码在“CSS和JS”选项卡中编辑。页面代码在“CSS 和 JavaScript 页面”块中编辑，并包含在常规页面之后。将 CSS 和 JavaScript 内容粘贴到字段中。

```text
.page-content { max-width: 72rem; }
```

```text
document.documentElement.classList.add('custom-script-loaded');
```

### 服务标头

在“设计模板→服务标题”部分中，您可以在标题内或结束正文之前插入通用元标记和计数器代码。 Canonical 会自动添加到整页上。

```text
<meta name="theme-color" content="#065f63">
```

### 字体真棒图标

Font Awesome Free 7.3.1 已连接。简短的代码适用于内容和 HTML 设计块。有纯色、常规和品牌款式可供选择。如果图标代表操作，则在图标旁边添加文本。

```text
[fa-icon=house] [fa-icon=regular:envelope] [fa-icon=brands:github]
```

```text
<i class="fa-icon fa-solid fa-phone" aria-hidden="true"></i> Связаться
```

### 库和字体

连接在“设置→库和字体”中管理。对于 Material UI，请使用模块化 JavaScript。所选的 Google 字体将替换网站的系统字体。

```text
<script type="module">import { Button } from "@mui/material";</script>
```

```text
GLightbox({selector: ".glightbox"});
```

## 变量、子模板和日期

### 站点变量

将条目添加到“设置→常规”。将密钥插入文本、页眉、站点标题或页脚中。

```text
[city] = Москва
[spb] = Санкт-Петербург
```

```text
Сервис в городе [city]
```

### 子模式

在子模板部分中，指定名称、描述和值。对于域，首先取其值，然后取其一般值。子模板可以包含 HTML。标头中的标记已被删除。

```text
[tel]
```

```text
[title]
```

### 日期和时间

时区取自 PHP。 [year] - 年、[month] - 月、[day] - 月中的某天、[time] - 小时和分钟、[dmY] 和 [date] - 日期 DD.MM.YYYY、[datetime] - 日期和时间。

```text
© [year] [city]
Дата [dmY], время [time]
```

### CMS 名称和作者

代码 [author] 输出 Eurowebcart CMS Lite、作者姓名 Бандалетов Павел 以及 GitHub 的链接。在标准页脚中，签名会自动出现。在您自己的 HTML 页脚中，将代码粘贴到您想要的位置。

```text
[author]
```

### 主页模板和政策

代码 [page-content] 将正文插入模板 [home] 中。在 Pages 中，转至 /privacy/ 编辑策略文本。替换 [site-name] 和 [site-url] 取自主设置。

```text
[page-content]
```

```text
[site-name] · [site-url]
```

### 页脚中的链接和设置

代码 [privacy] 显示指向 /privacy/ 的链接，[top] 将页面滚动到顶部，[cookies] 打开同意设置。

```text
[privacy]
[cookies]
[top]
```

### 常用 PHP 函数

在“设计模板→功能”部分中，编辑functions.php。在 PHP 代码中，translit() 或 ew_call() 调用已注册的函数。短代码 [func=translit] 可在内容和“自定义 HTML”字段中找到。

```text
[func=translit value="Москва и München"]
```

```text
$var = translit("Москва");
```

```text
echo ew_escape(ew_call("translit", "München"));
```

## 轮播、照片库和文件

### 转盘 [gal]

显示文件夹中的照片。箭头和数字接受打开或关闭，效果 - 滑动、淡入淡出或无，适合 - 包含或覆盖。

```text
[gal]/images/myfotos/[/gal]
```

```text
[gal arrows=on numbers=off effect=fade fit=cover width=50]/images/myfotos/[/gal]
```

### 照片库 [fotos]

显示响应式网格。列 — 自动或 1 到 6 之间的数字，比率 — 4x3、1x1、16x9 或原始，适合 — 覆盖或包含。标题和链接可通过打开或关闭启用。

```text
[fotos]/images/myfotos/[/fotos]
```

```text
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off width=50%]/images/myfotos/[/fotos]
```

### 文件列表 [files]

列出支持的文件。图标、大小和下载接受打开或关闭、顺序 - 升序或降序。允许使用 Zip、pdf、xls、xlsx、doc、docx、png、gif、jpg、jpeg、mp4、mov 和 mp3。

```text
[files]/files/myfiles/[/files]
```

```text
[files icons=on size=on order=desc download=on width=33]/files/myfiles/[/files]
```

## 表格和回电

### 表格 [formN]

在“表单”部分中，配置字段、最大长度、按钮文本和收件人。 “使用验证码”启用 Google reCAPTCHA v2 小部件，并在服务器上进行响应验证。请求通过 AJAX 发送，并在“消息”部分中可见。

```text
[form1]
[form2]
```

### 邮件表格模板

每个表单的主题和文本分别存储。在您的电子邮件模板中，在花括号中插入字段键。收件人列表和副本列表以逗号分隔。

```text
Привет {name}!
Телефон: {phone}
Сообщение: {message}
```

### 回拨 [callback]

打开包含电话号码的表单。该应用程序保存在“回调”部分。按钮标签可以在代码中设置。对于“否”提供商，将禁用发送到电话。

```text
[callback]
[callback=Вызвать мастера]
```

## 信息块

### 电话表和清单

在“Infoblocks”部分创建一个数据集。信息块名称和列键中允许使用 A–Z、a–z、0–9、连字符和下划线。不允许有空格。表格模板显示表格，电话显示带有呼叫链接的电话列。支持关闭代码 [iblock] 和 [/iblock]。

```text
[iblock=table]/data/myiblock.txt[iblock]
[iblock=phones]/data/myiblock.txt[/iblock]
```

## 联系人和社交网络

### 通用块和图标

[contacts] 显示联系人块，[phones] 显示电话号码，[soc-icons] 收集所有社交网络的图标以及自定义链接。

```text
[contacts]
[phones]
[soc-icons]
```

### 个人社交网络

每个代码都会显示其社交网络的链接。地址和签名在“设置→联系人和社交网络”中设置。

```text
[tg] [vk] [whatsapp] [youtube] [instagram] [max]
```

```text
[wa] [yt] [ig]
```

`[cities]` · `[phones]` · `[tel]`

## 滚动动画

在基本设置中选择滚动时内容区块的出现效果。动画默认关闭，并遵循设备的减少动态效果设置。

## 页面模板

创建页面时选择模板，可预填内容和 SEO 字段，之后仍可编辑。在“页面模板”中可以添加自定义模板。地图、表单和购买功能采用相应组件的设置。

模板的 CSS 和 JavaScript 会复制到页面字段。可在 HTML 中添加自定义类，并在模板 CSS 中定义样式。

### 通用样式类

布局容器、响应式网格、重点区域、卡片和突出显示的价格。

`.page-preset` · `.page-preset-grid` · `.page-preset-hero` · `.page-preset-card` · `.page-preset-price`

布局模板默认折叠。点击标题可打开单个模板，也可点击“全部展开”。再次点击可收起列表。

要调整整个横幅轮播的宽度，请开启编辑模式，点击横幅旁的“编辑组件”，然后选择区块宽度。

编辑模式下，将鼠标移到模板上即可打开编辑。已安装的任意 [php] 组件都能在弹窗中编辑源码和设置。幻灯片编辑器显示表单名称和代码。在无侧栏的页面上，单独插入的 [banners width=100] 会填满窗口宽度。 模板编辑器在网站内的弹窗中打开。

## 设计主题

把文件复制到主题并保存。缺少的文件使用默认发行版。布局修改、新短代码、历史及域名设置仅保存在启用的主题中。可通过 css/theme.css 和 js/theme.js 添加样式和脚本。

`templates/themes/demo/header.php` · `templates/themes/demo/components/banners.php`

手机菜单底部显示语言。桌面端的地球图标位于页眉下方菜单的搜索旁边。

相册、横幅和文件列表优先查找启用主题中的文件夹，找不到时使用公共文件。新文件夹、上传、标志和网站图标保存在主题中。备份包含主题目录及其设置。

可选择窗口宽度 (width=page)、内容宽度 (width=content) 或父区块宽度 (width=parent)。height 设置桌面高度，mobile-height 设置手机高度。auto 保留自然尺寸。

`[banners width=page height=520 mobile-height=240]` · `[form1 width=parent]`

面包屑的最后一项列出已发布的同级栏目，包括从主菜单隐藏的栏目。链接使用栏目设置的 URL。

## 摘要

摘要会显示在页面列表和搜索结果中。列表优先显示图片。菜单在页面名称前显示图标。

在编辑器中点击“插入页面列表…”。选择当前栏目可插入 `[list-pages]`，或点击目标文件夹旁的“插入”。`[dir]/sample/[/dir]` 列出 /sample/ 及其子栏目中已发布的页面。`[dir]/[/dir]` 从根目录开始列出页面。


在图标选择器中输入名称。例如，home 也会找到名称包含 house 的图标。

打开页面组件 → [banners] → 横幅幻灯片，即可添加、编辑或调整该组幻灯片的顺序。编辑组件可打开区块设置。

## 栏目页面地图 · `[maplist]`

从组件菜单选择“栏目页面地图”，或插入 `[maplist]`。地图会显示当前栏目及其子栏目中设置了坐标的已发布页面。在首页使用时会显示全站页面。气泡显示标题、图标、全宽摘要图片、摘要正文以及跳转按钮。请先在集成设置中配置地图。

`[maplist]/sample/[/maplist]` 显示指定栏目的地图。`[points]/sample/[/points]` 将设置了坐标的页面列为卡片。每张卡片包含标题、图片、摘要和跳转按钮。 “打开路线”按钮使用该点位的坐标和集成设置中选定的地图服务。

SEO 选项卡可设置页面是否包含在 sitemap.xml 中。在页面设置中启用“展开菜单分支”后，悬停或在手机上点击箭头即可显示菜单中可见的子页面。

在已设置坐标的页面插入 `[route]`。按钮使用集成设置选定的地图服务。使用 provider=yandex 或 provider=google 可明确指定服务。地图关闭时默认使用 Yandex。
