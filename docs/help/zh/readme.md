# Eurowebcart CMS Lite

作者 - Бандалетов Павел。 [原始项目和更新](https://github.com/bandaletov72/ewc-lite)。

最低 PHP 版本为 7.2。该网站和管理面板支持 PHP 8.6。对于您的 PHP 模块和模板，请使用服务器上安装的版本的语法。

[管理员常见问题解答](faq.md) 也可在“帮助”选项卡中找到。

[当前版本的十种语言帮助 ](../README.md) 描述了搜索、网站编辑、本地化和维护。 [英文版管理员常见问题解答](../en/faq.md)。

对于定期维护，请将命令 `php update.php --scheduled` 添加到托管调度程序，周期为 15 分钟。在维护部分，您可以独立启用重新索引并设置签名 GitHub 更新的检查间隔。

## 本地发布

进入解压后的 EWC Lite 文件夹，找到 `router.php`，然后启动内置 PHP 服务器。

```sh
php -S 127.0.0.1:8000 router.php
```

该网站将在地址 `http://127.0.0.1:8000/` 上打开，管理面板位于 `http://127.0.0.1:8000/admin/`。

## 安装和首次登录

在本地服务器上，打开 `/admin/` 并创建一个帐户。第二步，设置站点名称、元描述、页脚文本、调色板和主题模式。如果您有 PHP GD，则可以立即下载徽标。向导将从中创建一个网站图标。单击“保存并打开管理”或继续当前设置。如果您退出向导，它将在您下次登录时继续。

在主机上，从项目目录运行 `php admin/setup.php` 并在向导的第一步中输入一次性代码。当您创建帐户时，将兑换该代码。安装前再次运行该命令将替换之前的代码。安装更新会保留以前的帐户和设置。如果更新之前的版本使用`SITE_ADMIN_PASSWORD_HASH`，则使用登录名`admin`和之前的密码保存登录。

为了使应用程序正常工作，您需要 PHP 会话以及对 `admin/`、`admin/write-lock.php`、`admin/inbox/`、`data/` 和可编辑页面目录的写入权限。要在根目录创建页面和目录，请授予 PHP 进程对项目根目录的写入权限。使用带有 HTTPS 的 Web 服务器，处理索引文件列表中的 `.php` 和 `index.php`。禁用目录列表。对于反向代理后面的 HTTPS，请通过可信服务器配置将 `HTTPS` 属性传递给 PHP。

## 页面和菜单

在管理面板中，主页列为 `/`，文件夹中的其余页面列为 `/contacts/`。例如，要创建子页面，请输入 `/Services-1/Repair/`。管理面板将创建目录和 `index.php` 本身。对于单独的文件，请输入类似 `/Services-1/About_2.php` 的地址。文件和文件夹名称中允许使用 `A–Z`、`a–z`、`0–9`、连字符和下划线。输入的名称不带空格。在根目录下，只允许使用主页。保留`data`、`admin`、`templates`、`css`、`js`等服务目录。

在页面列表中，可以展开文件夹。在菜单复选框中，隐藏、发布和删除都是通过 AJAX 保存的。隐藏、发布、删除都需要确认。拖动 ⠿ 图标对相邻页面进行排序。隐藏页面在发布前停止打开并从菜单中消失。

在页面编辑器中，打开“移动页面”块并指定目标文件夹。例如，如果您将 `/contacts/` 转账至 `/company/`，则新地址将为 `/company/contacts/`。嵌套页面保留在相同的地址。更新您自己的链接和指向迁移页面的 `[include]` 代码。

拖动⠿图标可更改同一级别内的顺序。对于一页，在其设置中打开“移动页面”。文件夹旁边的图标可打开父部分的选择。选择不同的分区或根文件夹，然后单击移动文件夹。该文件夹与所有附加的页面和文件一起传输。检查指向旧地址的链接和 [include]。

可以在文本编辑器中编辑内容并通过 FTP 或 SFTP 添加内容。文件必须采用 UTF-8 无 BOM 格式。将 PHP 服务块保存到 `__halt_compiler();` 行。在新页面文件中，在所需深度插入示例中的此块，并检查根 `index.php` 的相对路径。接下来是标题、一个空行和页面的 HTML 片段。

```php
<?php
$pageFile = __FILE__;
require __DIR__ . '/../index.php';
__halt_compiler();
Title: Контакты
Heading: Как с нами связаться
Description: Контактная информация
Menu: Контакты
MenuVisible: 1
Order: 20

<p>Укажите здесь контактную информацию.</p>
```

`Title` 为必填项。空的 `Heading` 取自 `Title`。 `Description`填写页面的元描述。 `MenuVisible: 1` 在菜单中显示链接，`MenuVisible: 0` 隐藏它。对于 `index.php` 文件夹，取消选中该复选框也会隐藏菜单中的所有子页面。如果缺少 `MenuVisible`，则该复选框将继承之前的规则，并在填写 `Menu` 时被视为已启用。启用该复选框后，空字段 `Menu` 将替换为标头 `Title`。 `Order` 指定一级内的顺序，默认为 100。

CSS 和 JS 选项卡存储公共页面的常用 CSS 和 JavaScript。页面编辑器有一个单独的块“CSS 和 JavaScript 页面”。页面代码是在通用代码之后加载的。仅指定文件的内容，不指定 `<style>` 和 `<script>` 标签。每个字段允许的大小最大为 64 KiB。要从 CSS 链接到图像，您可以使用站点根目录中的路径。“帮助”选项卡包含可用模板和组件的示例。

在“设计模板”部分，您可以查看 `header.php`、`footer.php`、`menu.php` 和 `mobile-menu.php` 的源，并为每个模板设置通用 HTML。 “服务标头”将通用元标记、计数器代码和脚本插入 `<head>` 或 `</body>` 之前。在每个发布的完整页面上，`rel="canonical"` 都是由其常规地址形成的，不带查询参数。

## 设置、子模板和域

在“设置”部分，您可以设置站点名称、默认元描述、页脚文本和变量。在页脚文本中，`[year]` 自动显示当前年份。每行写入一个变量，例如 `[city] = Москва` 和 `[spb] = Санкт-Петербург`。要在网站标题、页面内容、页眉或页脚中显示值，请插入 `[city]`。在 PHP 模板中，您可以使用 `site_escape($settings['variables']['city'] ?? '')`。

系统替换包括 `[year]`、`[month]`、`[day]`、`[time]`（小时和分钟）、`[dmY]` 和 `[date]`（日期 DD.MM.YYYY）、`[datetime]`（日期和时间）。使用 PHP 时区。

在“基本 → 站点徽标和图标”中，您可以上传 PNG、JPEG、GIF 或 WebP。下载由 PHP GD 处理。创建图标按钮可以根据所选或保存的徽标创建透明的 64×64 PNG。图像存储在`templates/images/branding/` 和`templates/icons/branding/` 中。

“子模板”存储每个代码的名称、描述和含义。对于电话，创建 `[tel]`。要通过子模板设置选项卡标题，请创建 `[title]` 并在页面上的 `Title` 字段中指定它。选项卡标题后显示站点的名称。替换适用于页面文本和文本元数据。对于链接，插入整个 `<a>` 标记作为子模板值，并将代码放置在标记之间的文本中。在元数据中，HTML 从值转换为文本。

在“域”部分添加子域。在同名子域的管理面板中，选择“当前域”，或从常规列表中打开所需的域。局部含义优先于一般含义。公共页面在其地址中按域选择值，内部链接保存它。要连接子域，请在您的主机上配置 DNS 和 Web 服务器，以便该域提供相同的项目目录。

域旁边的“模板”按钮可打开 `[header]`、`[mobile-menu]`、`[menu]` 和 `[footer]` 编辑器。对于每个块，您可以设置自己的 HTML 或使用通用版本。通用模板在同一部分中配置。

在“主题和颜色”中，您可以将所选设置的副本保存在您自己的名称下或保留自动名称。 “应用”更改当前设计。使用默认值应用保存的主题并记住它以用于将主题重置为默认值命令。从列表中删除会保留站点的当前设计。

## 表单和反垃圾邮件

在“表单”部分，您可以编辑`[form1]`，创建`[form2]`和以下表单。对于表单，指定了收件人的地址、按钮签名和字段。该字段可以有最大长度。空值使用字段类型的默认限制。当您输入 `89031234567` 时，电话字段将其格式设置为 `+7(903)123-45-67`。服务器检查长度、类型、有效选择，并限制请求的总大小。免费输入字段接受纯文本。输出时消息中的 HTML 会被转义，并且新消息中的 HTML 标记会被拒绝。

“使用验证码”复选框启用 Google reCAPTCHA v2，对所选表单进行“我不是机器人”检查。输入域的站点密钥和秘密密钥。该秘密存储在受保护的设置文件中，仅用于服务器验证。 [服务器验证文档](https://developers.google.com/recaptcha/docs/verify)。

表单通过 AJAX 提交。申请保存在“消息”部分。如果指定了收件人，则 `mail()` 用于通知，这需要在主机上配置邮件。在反垃圾邮件部分，您可以编辑单词、表达式、IPv4 和 IPv6 地址的列表。链接在服务器上被阻止。发件人地址取自 `REMOTE_ADDR`。在反向代理后面，为可信代理配置Web服务器中原始IP的恢复。

每个表单都有一个“邮件模板”，其中包含“收件人”、“抄送（抄送）”、“电子邮件主题”和“电子邮件正文”字段。地址用逗号分隔。如果至少指定了一个主要收件人，则会发送副本。字段键插入到大括号中的主题和文本中，例如 `Привет {name}!`。空字段值被替换为空字符串，未知密钥保留在字母中。如果主题或正文为空，则使用标准信件的相应部分。

## 回调

将 `[callback]` 或 `[callback=Вызвать мастера]` 插入 HTML 页面。该按钮将打开一个包含电话号码的表单。请求保存在“回调”部分。按钮的签名以及将请求传输到电话的模式也在那里设置。默认情况下，选择“无”提供商并仅保存请求。可以启用电话从列表中手动发送或在收到号码后立即发送。

- **Zadarma.** 在管理面板中设置号码、SIP 或操作员分机，并通过 `SITE_ZADARMA_KEY` 和 `SITE_ZADARMA_SECRET` 将密钥传输到 PHP。 [Zadarma API](https://zadarma.com/en/support/api/) 文档
- **HTTP API。** 使用 HTTPS 地址指定 `SITE_CALLBACK_WEBHOOK_URL`，也可以选择指定 `SITE_CALLBACK_WEBHOOK_TOKEN`。该站点发送包含 JSON 字段 `id`、`phone`、`host`、`page`、`requested_at` 和标头 `Idempotency-Key` 的 POST。令牌作为 Bearer 进行转移。响应代码 2xx 将请求转移到“电话已接受”状态。

授予 PHP 进程写入权限给 `admin/callbacks/`。应用程序使用表单反垃圾邮件设置。重复同一号码的时间限制为一分钟；每 15 分钟最多接受 3 个通过 IP 的请求。

## 信息块和封闭数据文件夹

在“信息块”部分中，您可以创建数据集、编辑和拖动行。信息块名称和列键中允许使用 `A–Z`、`a–z`、`0–9`、连字符和下划线。输入的名称和密钥不带空格。列名和单元格值可以用俄语书写。控件对应于列类型，并通过 AJAX 完成保存。☰“编辑为文本”按钮将整个信息块切换为带有 `|` 分隔符和复制按钮的 CSV。前三行包含列的键、名称和类型。然后是数据线。CSV 中的日期为 `ГГГГ-ММ-ДД`，是/否存储为 `1` 或 `0`。

```text
name|phone|is_open
Название|Телефон|Открыто
text|tel|bool
Справочная|+7(903)123-45-67|1
```

`phones` 模板使用 `tel` 类型的列和带有标题的文本列。您可以将模板放置在 `templates/local/iblock/имя.php` 中，其中 `$block['columns']` 和 `$block['rows']` 可用。

代码里面的路径`/data/myiblock.txt`对应的是文件`data/myiblock.txt.php`。这是带有 PHP 存根的 UTF-8 文本，直接调用时会返回 404。 `router.php` 在本地运行时关闭整个文件夹。`data/` 有针对 Apache 和 IIS 的规则。对于 Apache，启用 `data/.htaccess`。在 Nginx 上，在站点配置中配置要关闭的文件夹，并在子目录中安装时考虑前缀。

```nginx
location = /data { return 404; }
location ^~ /data/ { return 404; }
```

安装后，检查对 `/data/` 的直接请求和信息块文件是否收到 403 或 404。

## 加载 HTML 片段

通常的地址 `/contacts/` 打开整个页面。如果 `X-Site-Fragment` 标头中存在会话密钥，则请求 `?ajax=1` 将返回带有 H1 的 `<main>` 和已处理的内容。片段链接到当前原点。带有键的页面和片段无需缓存即可提供。

在网站页面上的 JavaScript 中，使用内置函数。

```js
const html = await window.siteFetchContent('/contacts/');
document.getElementById('content').outerHTML = html;
```

在子目录中安装时，传递带有站点前缀的 URL。脚本和样式取自插入片段的页面。公共页面仍然可以通过常规地址访问。

## 引擎更新

新安装需要完整的存档。对于实时站点，请使用 `ewc-lite-update.zip`。它仅包含引擎和标准模板。保存的页面、信息块、设置、密码、消息和用户扩展不包含在存档中。

单击“设置→更新”中的“更新引擎”或从托管调度程序运行相同的检查。

```sh
php update.php --github
```

默认源是 `bandaletov72/ewc-lite`。对于您自己的存储库，将其设置为 `SITE_GITHUB_REPO`。公共存储库不需要令牌。对于私有存储库，将变量 `SITE_GITHUB_TOKEN` 传递给具有内容读取权限的 PHP 进程。服务器需要 Zip 和 OpenSSL PHP 扩展以及向 GitHub 发出 HTTPS 请求的能力。

对于手动安装，请使用 ZIP。

```sh
php update.php /path/to/ewc-lite-update.zip
```

在没有 `update.php` 的旧版本上，首先将包解压到项目顶部，保留现有的 `.htaccess` 和 `maintenance/` 中的文件（如果有）。如果您编辑了标准模板，请在更新之前将编辑内容传输到 `templates/local/`。安装程序会验证文件的列表和校验和，对于 GitHub，它还会使用可信公钥 `maintenance/release-public.pem` 验证签名。

对于下一个版本，将版本更改为 `app/version.php` 并通过 `php update.php --build ewc-lite-update.zip` 构建包。使用 SHA-256 的 RSA 私钥对 ZIP 进行签名，并将私钥与站点分开存储。然后将 ZIP 和 `.sig` 推送到带有标签 `vX.Y.Z` 的 GitHub Release 或 `updates/vX.Y.Z/` 并将 `updates/latest.json` 更新为 `{"version":"X.Y.Z"}`。

## 扩展

引擎模块可以随更新一起添加到 `app/extensions/`。将您自己的模块存储在更新包之外的 `extensions/` 中。 PHP 文件返回定义数组。对于单个组件，`kind` 等于 `single`，对于带参数的组件，它等于 `wrapped`。引擎识别现有页面上的新代码。组件可以在 `settings` 中声明选项菜单，将每个选项设置为 `label`、`default` 和数组 `options`。这些值转到 `$context['settings']`。

