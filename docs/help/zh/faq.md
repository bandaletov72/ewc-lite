# 管理员常见问题解答

## 安装与登录

### 如何启动网站并打开管理面板？

本地运行，在项目目录下运行命令 php -S 127.0.0.1:8000 router.php 并打开 http://127.0.0.1:8000/admin/.在托管上，首先运行 php admin/setup.php，然后在 /admin/. 中输入向导第一步中收到的一次性代码

### 第一次启动时可以配置什么？

首先创建用户名和密码。第二步，设置站点名称、默认元描述、页脚文本、调色板和主题模式。如果您有 PHP GD，您可以立即下载徽标并从中创建网站图标。您可以跳过第二步或下次登录时继续。

## 页面和菜单

### 如何创建页面以及输入什么地址？

转到页面 → 新页面。输入地址，例如/Services-1/Repair/或/Services-1/Price_2.php，填写标题并保存。对于文件夹地址，引擎本身会创建目录和index.php。名称中允许使用 A-Z、a-z、0-9、连字符和下划线。主页面保留在根目录下，服务目录下的页面创建是关闭的。

### “在菜单中”复选框和“隐藏”按钮有什么区别？

取消选中“在菜单中”框将从常规菜单中删除链接，同时保留对直接地址的访问。在具有文件夹地址的页面上，该复选框还控制子页面上的项目。“隐藏”按钮会删除链接并关闭页面的公共地址，直到再次发布。

### 如何更改页面顺序或移动整个文件夹？

拖动⠿图标可更改同一级别内的顺序。对于一页，在其设置中打开“移动页面”。文件夹旁边的图标可打开父部分的选择。选择不同的分区或根文件夹，然后单击移动文件夹。该文件夹与所有附加的页面和文件一起传输。检查指向旧地址的链接和 [include]。

### 为什么页面更改不能立即可见？

在编辑器中单击“保存”。然后使用“打开页面”或“前往”链接。如果链接消失，请检查页面是否已发布。对于子域的更改，请检查地址栏中的域。

## 设计和子域

### 在哪里可以更改标题、页脚、徽标和图标？

打开设置 → 常规。页脚文本字段支持当前年份的 [year]。在“徽标和站点图标”块中，您可以上传图像或单击“从徽标创建网站图标”。加载和转换需要PHP GD。

### 如何更改主题或字体然后返回到旧的？

在设置 → 主题和颜色中，选择模式和调色板。将当前调色板保存在列表中，以便稍后使用。“用作默认值”按钮会记住“将主题恢复为默认值”命令的调色板。可以在“库和字体”部分更改字体。列表中的名称和示例以适当的字体显示。值“System”返回正常字体。

### 在哪里更改标题以及在哪里插入计数器、CSS 或 JavaScript？

公共块标题、移动菜单、菜单和页脚在“设计模板”选项卡中编辑。在同一位置，“服务标头”将 HTML 插入到 head 中或结束 body 标记之前。对于常规 CSS 和 JavaScript，有一个单独的“CSS 和 JS”选项卡。一页的代码将添加到其编辑器中。

### 如何为子域设置不同的电话号码和标头？

在“域”部分添加子域。然后通过选择所需的域在“子模板”部分中设置单独的子模板值。使用域旁边的“模板”按钮更改标题和其他块。域版本优先于通用版本。 DNS 和 Web 服务器必须将子域指向该站点的目录。

### 在哪里可以更改社交网络的链接及其旁边的标题？

打开“设置→联系人和社交网络”。填写地址、签名和电话号码。代码 [soc-icons] 显示所有已配置网络的图标。对于单个链接，请使用 [tg] 或 [vk] 等。

## 表格和申请

### 如何向页面添加表单？

打开表单，配置字段、必填字段、最大长度和按钮文本。保存表单并将其代码（例如 [form1]）粘贴到页面的 HTML 中。

### 如果我没有收到电子邮件通知，我可以在哪里查看申请？

打开消息。成功提交表格后，申请将保存在那里。对于通知，请检查表单邮件模板中“收件人”字段中的地址以及主机上 mail() 功能的功能。

### 如何写信并发送副本？

打开所需的表单并找到“邮件模板”块。在“收件人”和“副本（抄送）”字段中输入地址，以逗号分隔。在主题和正文中，使用大括号中的字段键，例如 Hello {name}！文本下方的按钮插入选定的变量。空白主题或文本使用标准通知。

### 为什么表单拒绝该消息或询问“我不是机器人”？

检查必填字段、长度、电话和电子邮件格式。免费输入字段使用纯文本，不含 HTML 或网站地址。禁止词语和 IP 列表位于反垃圾邮件部分。“使用验证码”复选框需要所需域的站点密钥和 Google reCAPTCHA v2 密钥。

### 在哪里可以看到回电请求？

在“回调”部分。该组件将添加到页面，代码为 [callback] 或 [callback=Вызвать мастера]。如果选择“否”提供商，应用程序将保存在管理面板中。配置电话后，可以使用手动或自动传输。

## 信息块和组件

### 如何创建信息块并显示在页面上？

在“信息块”部分中，单击“新建信息块”，配置列并添加行。在信息块名称和列键中，使用 A–Z、a–z、0–9、连字符或下划线，不带空格。保存并复制信息块编辑器中的嵌入代码。如需电话列表，请使用电话模板。

### 如何复制或替换信息块的所有行？

打开信息块并单击“编辑为文本”。CSV 使用 |分隔符。前三行包含列的键、名称和类型。接下来是数据。将带有分隔符、引号或换行符的字段括在双引号和双内引号中。

### 如果图库或文件列表为空，如何检查？

检查组件代码中的路径与服务器上的文件夹。例如，[fotos]/images/myfotos/[/fotos] 使用 images/myfotos/ 或 templates/images/myfotos/. 中的照片对于 [files]，检查文件扩展名。可以在组件帮助中找到支持的扩展和参数的列表。

### 为什么使用 ?ajax=1 的请求返回 403？

页面片段需要同一站点上的有效公共会话和令牌。要在站点内部加载，请使用 window.siteFetchContent()，它会传输令牌。对于正常的转换，打开不带ajax参数的页面地址。

## 更新和备份

### 如何更新已安装站点的引擎？

在“设置”→“更新”中，将安装的版本与 GitHub 中的最新版本进行比较，然后单击“更新引擎”。如果 GitHub 不可用，管理面板将显示上次检查的版本。要手动更新，请将 php-site-update.zip 存档传递给 php 命令 update.php。更新包替换了引擎文件和标准模板。将您的 PHP 模板存储在 templates/local/. 中

### 在升级或迁移之前我应该​​复制什么？

复制整个站点目录以及隐藏文件。页面位于根及其目录，data/中的信息块，admin/.中的设置和帐户文件还可以保存您的模板、上传的图像、消息和应用程序。该副本包含配置机密，因此请将其保存在公共目录之外。

### 如果管理面板无法保存更改，应该检查什么？

首先阅读表格旁边的消息。如果更改发生冲突，请复制您的编辑内容并再次打开编辑器。如果出现写入错误，请要求您的主机检查所需文件夹和文件 admin/write-lock.php. 中 PHP 进程的写入权限如果更新失败，请检查服务器对 GitHub 的访问以及 PHP Zip 和 OpenSSL 的可用性。

## PHP 信息

“维护”中的 phpinfo() 仅向已登录的管理员显示 PHP 版本、模块和配置，隐藏环境变量和请求变量。在“设置 → 常规”中可设置 error_reporting，默认采用服务器设置。

## 在地图上选点

在 Yandex Maps 控制台为 JavaScript API 产品创建密钥，并通过 HTTP Referer 限制访问域名。在页面的地图标签中选择地点并应用坐标。 本地测试时在 HTTP Referer 中填写不带端口的 localhost。密钥激活后，使用 localhost 打开后台。

## 网站副标题

在常规设置中填写的副标题以小字号显示在页眉的网站名称下方。手机端的网站名称也采用较小字号。

## 城市

在“城市”中可绑定已注册的域名并设置最多五个电话号码。电话字段支持 [tel] 等短代码。[cities] 显示城市选择器，[phones] 显示已填写的号码，[tel]、[tel2]–[tel5] 显示各个号码。浏览器会记住选择，无需重新加载页面即可更新号码。

`[cities]` · `[phones]` · `[tel]`

## 滚动动画

在基本设置中选择滚动时内容区块的出现效果。动画默认关闭，并遵循设备的减少动态效果设置。

## 页面模板

创建页面时选择模板，可预填内容和 SEO 字段，之后仍可编辑。在“页面模板”中可以添加自定义模板。地图、表单和购买功能采用相应组件的设置。

模板的 CSS 和 JavaScript 会复制到页面字段。可在 HTML 中添加自定义类，并在模板 CSS 中定义样式。

### 通用样式类

布局容器、响应式网格、重点区域、卡片和突出显示的价格。

`.page-preset` · `.page-preset-grid` · `.page-preset-hero` · `.page-preset-card` · `.page-preset-price`

布局模板默认折叠。点击标题可打开单个模板，也可点击“全部展开”。再次点击可收起列表。

要调整整个横幅轮播的宽度，请开启编辑模式，点击横幅旁的“编辑组件”，然后选择区块宽度。
