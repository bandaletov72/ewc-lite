# Українська · 1.6.1

## Пошук

В основних налаштуваннях можна вимкнути пошук або вибрати лупу чи розгорнуте поле. У шапці адмінки є пошук налаштувань. Індекс оновлюється після правок; для FTP доступний розклад. Індексуються вкладені сторінки й інфоблоки; PHP-модулі не запускаються.

## Модулі PHP

Розкрийте модуль, щоб переглянути налаштування та сторінки, де його вставлено. Створіть модуль, вкажіть ім’я файлу та тіло функції. Зміна імені файлу зберігає код [php]id[/php]. Підсвічування CodeMirror вмикається у бібліотеках.

## Шаблони й переклади

Можна скасувати до восьми змін кожного шаблону та відновити початковий PHP. Історія окрема для кожного домену. Власний HTML редагується в адмінці, PHP можна розмістити в templates/local/. Перемикач мов доступний під час створення перекладу. Переклади переносяться разом зі сторінкою.

## Інтеграції й обслуговування

Посилання в налаштуваннях ведуть до ключів CAPTCHA, карт, телефонії й аналітики. URL і токен HTTP API задаються в адмінці. Значення зареєстрованого піддомену діють після переходу на основний домен. Заплануйте php update.php --scheduled кожні 15 хвилин.

# Українська · 1.6.0

## Пошук і кеш

Після публікації або редагування через адмінку чи FTP перебудуйте текстовий індекс в «Обслуговуванні». Підказки враховують мову відвідувача та відкриті сторінки. Кеш вимкнено за замовчуванням, його можна ввімкнути й очистити там само. Форми й динамічні блоки обробляються для кожного запиту.

## Редагування на сайті

Після входу над шапкою доступна панель. Правий перемикач діє на весь сайт і додає кнопки правки біля вставок. CSS та JS поточної сторінки відкриваються в модальному вікні. У редакторі адмінки є HTML, візуальний режим, вставлення кодів і масове AJAX-завантаження та сортування медіа й файлів.

## Компоненти й навігація

Вставки без параметрів використовують загальні налаштування. width приймає 100, 50, 33 або 25, можна зі знаком %. На телефоні блоки стають в одну колонку. numbers=off прибирає номер слайда, гортання пальцем працює. Мобільне меню виїжджає справа. Навігаційний ланцюжок вимикається в основних налаштуваннях.

```text
[gal width=50 numbers=off arrows=on fit=cover]/images/myfotos/[/gal]
[fotos width=50% columns=3 captions=on]/images/myfotos/[/fotos]
[files width=33 icons=off size=on download=on]/files/myfiles/[/files]
```

## Мови, оформлення та ціни

У регіональних налаштуваннях задайте мови сайту й адміністратора, часовий пояс, валюту та формати. index_en.php біля index.php додає переклад; без нього відкривається основний текст. Поле ціни використовує обрану валюту. Можна переглянути палітру, змінити режим теми одразу, завантажити світлий і темний логотипи та перевірити Roboto Condensed зі своєю фразою.

```text
/contacts/index.php → /contacts/index_en.php
```

## Форми, заявки й інтеграції

Спільні ключі Google reCAPTCHA v2 і загальне ввімкнення є в налаштуваннях CAPTCHA, окремі параметри — у формах. Повідомлення й дзвінки показуються по 20, непрочитані першими. Інтеграції охоплюють Zadarma, Telegram, аналітику та карти Google або Яндекса з кластеризацією. Тест бібліотеки й код вставлення відкриваються в модальному вікні. CodeMirror має режими «Авто», HTML, CSS, JS, PHP і RAW.

```text
[map lat=55.7558 lng=37.6173 title="Office" zoom=13 provider=yandex url="/contacts/" button="Open"]
```

```text
[callback button="Call me" title="Callback" submit="Send" placeholder="+7(900)123-45-67"]
```

## Модулі PHP

У списку модулів PHP задайте назву, опис і дозвіл на вставлення. server-date показує дату в регіональному форматі. Виконувані файли встановлюються розробником у захищену теку.

```text
[php]server-date[/php]
```
