# Шаблони та компоненти

## Шаблони оформлення

### Шапка, меню та підвал

Повна сторінка автоматично підключає ці блоки. Загальні версії редагуються в «Шаблони оформлення», а для окремого домену – у розділі «Домени».

```text
[header]
[mobile-menu]
[menu]
[footer]
```

### Вставка іншої сторінки

Вставляє вміст опублікованої сторінки. Максимальна вкладеність – десять рівнів. Повторення сторінки в одному ланцюжку пропускається.

```text
[include]/contacts/[/include]
```

### Посилання в меню

Галочка «Показувати в меню» додає посилання до штатного меню. При порожній назві береться заголовок. Якщо відключити галочку сторінки папки, її вкладені сторінки теж зникнуть з меню.

```text
MenuVisible: 1
Menu: Контакти
```

### CSS та JavaScript

Загальний код редагується у вкладці CSS та JS. Код сторінки редагується в блоці CSS і JavaScript сторінки і підключається після загального. У поля вставте вміст CSS та JavaScript.

```text
.page-content { max-width: 72rem; }
```

```text
document.documentElement.classList.add('custom-script-loaded');
```

### Службові заголовки

У розділі «Шаблони оформлення → Службові заголовки» можна вставити загальні метатеги та коди лічильників усередину head або перед закриваючим body. Canonical автоматично додається на повних сторінках.

```text
<meta name="theme-color" content="#065f63">
```

### Іконки Font Awesome

Підключено Font Awesome Free 7.3.1. Короткий код працює в контенті та HTML блоків оформлення. Доступні стилі solid, regular та brands. Додайте поряд із іконкою текст, якщо вона позначає дію.

```text
[fa-icon=house] [fa-icon=regular:envelope] [fa-icon=brands:github]
```

```text
<i class="fa-icon fa-solid fa-phone" aria-hidden="true"></i> Зв'язатися
```

### Бібліотеки та шрифти

З'єднання керуються в «Параметри → Бібліотеки та шрифти». Для Material UI використовуйте модуль JavaScript. Вибраний шрифт Google замінює системний шрифт сайту.

```text
<script type="module">import { Button } from "@mui/material";</script>
```

```text
GLightbox({selector: ".glightbox"});
```

## Змінні, підшаблони та дата

### Змінні сайту

Додайте записи до «Установки → Основні». Вставляйте ключ у текст, заголовок, назву сайту або підвал.

```text
[city] = Москва
[spb] = Санкт-Петербург
```

```text
Сервіс у місті [city]
```

### Підшаблони

У розділі «Підшаблони» вкажіть ім'я, опис та значення. Для домену спочатку береться значення, потім загальне. Підшаблон може містити HTML. У заголовках розмітка забирається.

```text
[tel]
```

```text
[title]
```

### Дата та час

Часовий пояс береться з PHP. [year] – рік, [month] – місяць, [day] – день місяця, [time] – години та хвилини, [dmY] та [date] – дата ДД.ММ.ГГГГ, [datetime] – дата

```text
© [year] [city]
Дата [dmY], час [time]
```

### Назва CMS та автор

Код [author] виводить Eurowebcart CMS Light, ім'я автора Бандалетов Павел та посилання на GitHub. У стандартному підвалі підпис з'являється автоматично. У свій HTML підвалу вставте код в потрібне місце.

```text
[author]
```

### Шаблон головної та політика

[page-content] вставляє вміст головної в [home]. Відкрийте /privacy/ у розділі «Сторінки», щоб змінити політику. [site-name] і [site-url] беруться з основних налаштувань.

```text
[page-content]
```

```text
[site-name] · [site-url]
```

### Посилання та налаштування у підвалі

[privacy] веде на /privacy/, [top] прокручує сторінку вгору, а [cookies] відкриває налаштування згоди.

```text
[privacy]
[cookies]
[top]
```

### Загальні функції PHP

У розділі Шаблони оформлення → Опції відредагуйте functions.php. У PHP-коді translit() або ew_call() викликає зареєстровану функцію. Короткий код [func=translit] доступний у вмісті та в полі «Свій HTML».

```text
[func=translit value="Москва и München"]
```

```text
$var = translit("Москва");
```

```text
echo ew_escape(ew_call("translit", "München"));
```

## Карусель, фотогалерея та файли

### Карусель [gal]

Показує фотографії з папки. arrows і numbers приймають on або off, effect - slide, fade або none, fit - contain або cover.

```text
[gal]/images/myfotos/[/gal]
```

```text
[gal arrows=on numbers=off effect=fade fit=cover width=50]/images/myfotos/[/gal]
```

### Фотогалерея [fotos]

Показує адаптивну сітку. columns - auto або число від 1 до 6, ratio - 4x3, 1x1, 16x9 або original, fit - cover або contain. captions та links включаються через on або off.

```text
[fotos]/images/myfotos/[/fotos]
```

```text
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off width=50%]/images/myfotos/[/fotos]
```

### Список файлів [files]

Виводить файли, що підтримуються. icons, size та download приймають on або off, order - asc або desc. Дозволено zip, pdf, xls, xlsx, doc, docx, png, gif, jpg, jpeg, mp4, mov та mp3.

```text
[files]/files/myfiles/[/files]
```

```text
[files icons=on size=on order=desc download=on width=33]/files/myfiles/[/files]
```

## Форми та зворотній дзвінок

### Форма [formN]

У розділі «Форми» налаштуйте поля, їх максимальну довжину, текст кнопки та одержувача. "Використовувати CAPTCHA" включає віджет Google reCAPTCHA v2 з перевіркою відповіді на сервері. Заявки надсилаються через AJAX і можна знайти в розділі «Повідомлення».

```text
[form1]
[form2]
```

### Поштовий шаблон форми

Тема та текст зберігаються окремо для кожної форми. У поштовому шаблоні вставляйте ключі полів у фігурні дужки. Списки одержувачів та копій поділяються комами.

```text
Привіт {name}!
Телефон: {phone}
Повідомлення: {message}
```

### Зворотній дзвінок [callback]

Відкриває форму телефону. Заявка зберігається у розділі «Зворотні дзвінки». Підпис кнопки можна встановити в коді. З провайдером «Ні» відправлення до телефонії вимкнено.

```text
[callback]
[callback=Вызвать мастера]
```

## Інфоблоки

### Таблиця та список телефонів

Створіть набір даних у розділі «Інфоблоки». У імені інфоблоку та ключах стовпців дозволено A–Z, a–z, 0–9, дефіс та підкреслення. Прогалини заборонені. Шаблон таблиці показує таблицю, телефони виводить телефонні стовпці з посиланнями для дзвінка. Підтримуються коди [iblock] та [/iblock].

```text
[iblock=table]/data/myiblock.txt[iblock]
[iblock=phones]/data/myiblock.txt[/iblock]
```

## Контакти й соцмережі

### Загальний блок та іконки

[contacts] виводить блок контактів, [phones] показує телефони, [soc-icons] збирає іконки всіх соціальних мереж з налаштованими посиланнями.

```text
[contacts]
[phones]
[soc-icons]
```

### Окремі соцмережі

Кожен код виводить посилання на свою соцмережу. Адреси та підписи задаються в «Налаштування → Контакти та соцмережі».

```text
[tg] [vk] [whatsapp] [youtube] [instagram] [max]
```

```text
[wa] [yt] [ig]
```

## Кнопки в шапці адмінпанелі · 1.6.4

Глобус відкриває сайт, стрілка завершує сеанс адміністратора. На телефоні видно лише іконки. Підказки з’являються при наведенні або фокусі з клавіатури.

«Вміст», «Форми й заявки» та «Сайт і сервіси» відкриваються відразу. Під головним меню відображаються вкладки вибраного розділу.

Вставте [bread-crumbs] або [search] в HTML головної сторінки (index.php) чи шаблону. Блок з’явиться один раз у вказаному місці. Налаштування навігаційного ланцюжка й пошуку діють для тегів. [privacy] веде на /privacy/. Текст політики редагується в розділі «Сторінки».

```text
[bread-crumbs]
[search]
[privacy]
```

## Службові файли, карти й шаблони · 1.6.5

Відкрийте «Обслуговування → Службові файли» для редагування .htaccess, robots.txt і sitemap.xml. До XML-карти потрапляють опубліковані сторінки з відповідною позначкою. Попередню версію .htaccess можна відновити.

Задайте широту й довготу. [map] показує точку сторінки, а [maps] — точки всіх опублікованих сторінок. center і zoom задають центр і масштаб. Провайдер вибирається в інтеграціях.

[main-menu] — меню під шапкою з розкривними підрозділами. У шаблонах оформлення створюйте власні й задавайте видимість на мобільних та комп’ютерах. У підшаблонах кнопка додавання домену відкриває форму. Для посилання на політику використовуйте [privacy].

В «Інтеграціях» вкажіть ID JivoSite, Microsoft Clarity й Umami Cloud, код Botfaqtor або вебхук Slack. Інструкції поруч із полями. У Zadarma можна перевірити баланс, надіслати тестове SMS або здійснити дзвінок. SMS і дзвінок можуть тарифікуватися. Для [payment] вставте посилання ЮMoney, PayPal і СБП. Статус перевіряйте в кабінеті провайдера.

У HTML і візуальному редакторі значки форматують текст, додають H1–H5 і списки. Поставте курсор і виберіть шаблон, компонент, зображення або іконку. Доступні збережені форми та параметри компонентів. Іконки Font Awesome доступні, коли бібліотека увімкнена.

Натисніть назву папки, щоб керувати розділом праворуч. Там можна вибрати батьківський розділ, налаштувати звичайне й мобільне меню та вказати URL переходу. Порожня сторінка показує підрозділи. В «Обслуговуванні» задавайте правила /contact.html => /contacts/ і редагуйте сторінки помилок у /error/. Мова й пошук доступні через іконки.

```text
[map]
[map center="55.7558,37.6173" zoom=14]
[maps center="55.7558,37.6173" zoom=11]
[main-menu]
[lang]
[privacy]
[payment]
```

```php
$var = translit("Москва"); // Moskva
```

## Редагування даних на сторінці · 1.6.6

У режимі редагування інфоблоки, форми [formX], підшаблон [tel] та інші компоненти з редактором даних мають дії «Дані» й «На весь екран». Список виду інфоблоку містить зареєстровані шаблони. «Коренева папка» переносить розділ на верхній рівень. Використовуйте [list-pages] для списку опублікованих сторінок розділу та підпапок. Меню мов закривається клацанням поза списком або клавішею Escape.

## Налаштування сторінки · 1.6.8

Пишіть вміст у вкладці «Редагування». Адресу, меню й розклад публікації задавайте в налаштуваннях сторінки. Заголовки, метаопис, ключові слова й додавання до sitemap містяться в SEO. Координати та приклади тегів є в карти.

Порожні дати знімають обмеження. Діє часовий пояс сайту. Приховану сторінку потрібно окремо опублікувати.

- `[map]` — карта з точкою поточної сторінки.
- `[maps]` — карта з точками всіх опублікованих сторінок.

## Банери та редактор зображень · 1.6.8

Керуйте наборами й кадрами в «Компонентах». Беріть фото з папки, задавайте підпис і кнопку з посиланням, формою або зворотним дзвінком та встановлюйте час показу. У режимі редагування доступні дії кадру. Вибір зображень дає змогу переглядати папки, завантажувати, видаляти й створювати повернуті або масштабовані копії за допомогою GD. Значки Font Awesome можна знайти за назвою.

```text
[banners]
[banners set=summer arrows=on numbers=off]
[banners]/images/myfotos/[/banners]
```

## Мови · 1.6.9

На вкладці «Мови» перелічено мови сторінки. «Відкрити» веде до збереженої версії, а «Створити переклад» відкриває редактор нового перекладу.

Підрозділ створюється всередині поточного розділу, сусідній — поруч із ним, а кореневий — на верхньому рівні сайту.

## Сумісність PHP і навігація · 1.6.10

Мінімальна версія PHP — 7.2. Сайт і панель адміністратора підтримують PHP 8.6. Для власних модулів і шаблонів використовуйте синтаксис версії, встановленої на сервері.

Поточний пункт [bread-crumbs] розкриває опубліковані розділи того самого рівня, які є в головному меню. URL із налаштувань сторінки використовується в меню, списках розділів, навігаційному ланцюжку, результатах і підказках пошуку.

Кошик видаляє рядок у редакторі інфоблоку. Видалення стовпця прибирає всі його значення. Зміни записуються при збереженні, зокрема й при автозбереженні після перетягування.

### Резервні копії сайту

Приватний ZIP містить сторінки, медіа, інфоблоки, налаштування, власні шаблони й PHP-модулі. Обліковий запис і вхідні заявки зберігаються окремо. Потрібне розширення PHP Zip.

Замінити вміст і налаштування. Спочатку буде створено копію поточного стану.

### Очищення невикористаних файлів

Пошук знаходить медіа без посилань у збереженому вмісті. Перегляньте список і виберіть файли. Спочатку створюється резервна копія. Видалення коду компонента залишає папку та файли на місці.

### Вибір точки на карті

У кабінеті Яндекс Карт створіть ключ продукту «JavaScript API» та обмежте його доменом через HTTP Referer. У вкладці «Карти» сторінки виберіть точку й застосуйте координати.

Виділіть текст для вирівнювання чи очищення форматування. Клацніть зображення, щоб відкрити параметри. Змініть розмір за кут або перетягніть зображення в тексті. Посилання підтримують URL, email, телефон і якір. Кнопка відкриває URL, форму, зворотний дзвінок або оплату за посиланням провайдера.

Вкладки HTML і «Візуальний редактор» перемикають режими. SUP, SUB та «Параграф» вставляють відповідні елементи. Біля назв компонентів показано коди. Папки створюються під час вставлення. Назви папок містять латинські літери, цифри, дефіс і підкреслення. Вкладка «Мови» веде до налаштувань мов сайту.

```text
[button action="url" label="Contacts" url="/contacts/"]
[button action="form" label="Write to us" form="form1"]
[button action="callback" label="Call me"]
[button action="payment" label="Pay" amount="1250.00" currency="RUB" yoomoney="410010000000000"]
[map]
[maps]
```

## Продаж · 1.6.11

Задайте ціну й спосіб оплати у вкладці «Продаж». Для мов можна вказати окремі ціни. Вставте [item-price] і [item-buy-button]. Замовлення реєструється до оплати. Статуси можуть надсилатися через email і Zadarma SMS.

Заявку прийнято · Оплату прийнято · Відправлено · Замовлення закрито · Скасовано

```text
[item-price]
[item-buy-button]
```

Виберіть файл або URL для вставлення зображення. Натисніть картинку для налаштування розміру, вирівнювання, чотирьох відступів і CSS. Вирівнювання зображення незалежне від тексту. У режимі HTML блоки подано по рядках. [list-pages] є в списку компонентів. Логотип CMS використовує кольори теми.

## Діаграма з інфоблоку

У редакторі сторінки відкрийте «Вставити компонент» і виберіть таблицю чи діаграму. Для діаграм увімкніть Chart.js, виберіть стовпець підписів і стовпці типу «Число» або «Ціна». Кругова, кільцева і полярна діаграми використовують один ряд невід’ємних значень. Без бібліотеки відображається таблиця.

Збережені форми, шаблони, підшаблони й зареєстровані компоненти з’являються після повторного відкриття редактора. ID нового набору банерів допускає A–Z, a–z, дефіс і підкреслення. Після завантаження зображень до папки [banners] біля кожного файлу є посилання «Редагувати кадр». У режимі редагування вікно відкриває вибраний кадр, а окреме посилання веде до типових налаштувань. Біля збереження каруселі, галереї та списку файлів є файловий менеджер для завантаження, видалення, сортування та підпапок (A–Z, a–z, 0–9, - і _). Кольори кадру показано квадратними зразками.

```text
[iblock=table]/data/myiblock.txt[/iblock]
[iblock=charts type=line labels=month values=sales,orders]/data/myiblock.txt[/iblock]
[banners set=summer-promo]
```

## Шаблони сторінок

Шаблони оформлення спочатку згорнуті. Відкрийте потрібний шаблон за заголовком або натисніть «Розгорнути всі». Повторне натискання згортає список.

Щоб змінити ширину всієї каруселі банерів, увімкніть режим редагування, натисніть «Редагувати компонент» і виберіть ширину блока.

## Міста · Телефон · 1.6.18

Обов’язкова лише назва міста. Домен і телефони можна залишити порожніми. Номер має містити «+» і код країни, наприклад +7 (900) 000-00-00. Замість номера можна вказати підшаблон [tel].

Порядок вибору: збережене місто, місто домену, потім перше місто списку. Якщо список порожній, показуються загальні телефони.

Форми, зворотні дзвінки й нові замовлення надходять на E-Mail міста або на загальну адресу. Якщо обидва поля порожні, форми використовують власні адреси. Порожні посилання соцмереж успадковуються від сайту.

У режимі редагування наведіть вказівник на шаблон і натисніть «Редагувати шаблон». Для будь-якого встановленого [php] відкрийте код і налаштування кнопкою «Редагувати модуль». Редактор кадру показує назву та код форми. [banners width=100] заповнює ширину вікна як окремий блок на сторінці без бічної колонки. Редактор шаблону відкривається в модальному вікні сайту.

Менеджер файлів перевіряє папку та її файли перед видаленням. Для непорожньої папки створюється резервна копія. Кадр банера може мати заголовок і підзаголовок.

Телефон перевіряється під час введення. Російський номер, що починається з 8, перетворюється на +7. Після надсилання форма ховається, а при повторному відкритті видно підтвердження.

До номера без «+» додається код вибраної країни. Номер з «+» зберігає введений міжнародний код.

## Теми дизайну

Скопіюйте файл у тему й збережіть його. Відсутні файли беруться зі штатної поставки. Зміни, нові шорткоди, історія та доменні налаштування оформлення діють лише в активній темі. Додаткові стилі та скрипти можна зберегти в css/theme.css і js/theme.js.

`templates/themes/demo/header.php` · `templates/themes/demo/components/banners.php`

Мови розташовані внизу мобільного меню. На комп’ютері перемикач із глобусом поруч із пошуком у меню під шапкою.

Галереї, банери й списки шукають папки в активній темі, а за їх відсутності використовують спільні файли. Нові папки, завантаження, логотипи й favicon записуються в тему. Резервна копія включає тему та її налаштування.

Виберіть ширину вікна (width=page), вмісту (width=content) або батьківського блока (width=parent). height задає висоту на комп’ютері, mobile-height — на телефоні. auto зберігає природний розмір.

`[banners width=page height=520 mobile-height=240]` · `[form1 width=parent]`

Остання хлібна крихта показує опубліковані сусідні розділи, зокрема прибрані з головного меню. Для посилання використовується вказаний URL.

## Анонс

Анонс відображається у списках сторінок і результатах пошуку. У списках зображення має пріоритет над іконкою. У меню іконка стоїть перед назвою сторінки.

У редакторі натисніть «Вставити список…». Виберіть поточний розділ для `[list-pages]` або натисніть «Вставити» біля потрібної папки. `[dir]/sample/[/dir]` показує опубліковані сторінки розділу /sample/ та його підрозділів. `[dir]/[/dir]` починає список з кореня.


Введіть назву в полі вибору іконок. Наприклад, home знаходить іконки з house у назві.

Відкрийте «Компоненти сторінки» → [banners] → «Кадри банера», щоб додати, змінити або переставити кадри набору. «Редагувати компонент» відкриває параметри блока.

## Карта сторінок розділу · `[maplist]`

Виберіть «Карта сторінок розділу» в меню компонентів або вставте `[maplist]`. Карта показує опубліковані сторінки з координатами в поточному розділі та його підрозділах. На головній охоплює весь сайт. У вікні точки є назва, іконка, зображення на всю ширину, текст анонсу та кнопка переходу. Підключіть карту в інтеграціях.

`[maplist]/sample/[/maplist]` відображає карту вибраного розділу. `[points]/sample/[/points]` показує список сторінок з координатами. Картка містить назву, фото, текст анонсу та кнопку переходу.

Прапорець «Показувати в карті сайту» є у вкладці SEO й враховується під час створення sitemap.xml. У налаштуваннях сторінки увімкніть «Розгортати гілку меню». Видимі підрозділи відкриються при наведенні або натисканні на стрілку на телефоні.

Вставте `[route]` на сторінці з координатами. Кнопка відкриє сервіс, вибраний в інтеграціях. provider=yandex або provider=google задає сервіс явно. Якщо карти вимкнено, використовується Яндекс.
