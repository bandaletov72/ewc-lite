[Довідка за актуальною версією десятьма мовами](../README.md) описує пошук, редагування на сайті, локалізацію та обслуговування. [Admin FAQ in English](../en/faq.md).

Для планового обслуговування додайте команду `php update.php --scheduled` до планувальника хостингу з періодом 15 хвилин. У розділі «Обслуговування» можна незалежно увімкнути переіндексацію та встановити інтервал перевірки підписаних оновлень GitHub.

## Локальний запуск

Перейдіть до каталогу `php-site` та запустіть вбудований сервер PHP.

```sh
php -S 127.0.0.1:8000 router.php
```

Сайт відкриється за адресою `http://127.0.0.1:8000/`, адмінка знаходиться за адресою `http://127.0.0.1:8000/admin/`.

## Встановлення та перший вхід

На локальному сервері відкрийте `/admin/` та створіть обліковий запис. На другому кроці задайте назву сайту, метаопис, текст підвалу, палітру та режим теми. Логотип можна завантажити за наявності PHP GD. Майстер створить із нього favicon. Натисніть «Зберегти та відкрити адмінку» або продовжіть поточні налаштування. Якщо вийти з майстра, він продовжиться під час наступного входу.

На хостингу виконайте з каталогу проекту `php admin/setup.php` та введіть одноразовий код на першому кроці майстра. Код погашається під час створення облікового запису. Повторний запуск команди до встановлення замінює попередній код. Інсталяція оновлення зберігає попередній обліковий запис та налаштування. Якщо версія до оновлення використовувала `SITE_ADMIN_PASSWORD_HASH`, вхід зберігається з логіном `admin` та колишнім паролем.

Для роботи програми потрібні PHP-сесії та права запису в `admin/`, `admin/write-lock.php`, `admin/inbox/`, `data/` та каталоги сторінок, що редагуються. Щоб створювати сторінки та каталоги в корені, дайте процесу PHP право запису в корінь проекту. Використовуйте веб-сервер з HTTPS, обробкою `.php` та `index.php` у списку індексних файлів. Вимкніть листинг каталогів. При HTTPS за зворотним проксі передайте PHP ознаку `HTTPS` через довірену конфігурацію сервера.

## Сторінки та меню

В адмінці головна вказана як `/`, решта сторінок у папках — як `/contacts/`. Для створення вкладеної сторінки вкажіть, наприклад, `/Services-1/Repair/`. Адмінка сама створить каталоги та `index.php`. Для окремого файлу вкажіть адресу типу `/Services-1/About_2.php`. В іменах файлів та папок дозволено `A–Z`, `a–z`, `0–9`, дефіс та підкреслення. Імена вводяться без пробілів. Докорінно дозволена лише головна сторінка. Службові каталоги, включаючи `data`, `admin`, `templates`, `css` та `js`, зарезервовані.

У списку сторінок папки можна розкрити. Галочка "У меню", приховування, публікація та видалення зберігаються через AJAX. Приховування, публікація та видалення потребують підтвердження. Перетягуйте ⠿ для сортування сусідніх сторінок. Прихована сторінка перестає відкриватися та зникає з меню до публікації.

У редакторі сторінки відкрийте блок «Перемістити сторінку» та вкажіть папку призначення. Наприклад, при перенесенні `/contacts/` до `/company/` нова адреса буде `/company/contacts/`. Вкладені сторінки залишаються за попередніми адресами. Оновіть власні посилання та коди `[include]`, які ведуть до перенесеної сторінки.

Перетягніть значок ⠿, щоб змінити порядок на одному рівні. Одну сторінку можна перемістити в її налаштуваннях. Значок поруч із папкою відкриває вибір батьківського розділу. Виберіть інший розділ або корінь і натисніть «Перемістити папку». Папка переміщується з усіма сторінками й файлами. Перевірте посилання та [include] зі старими адресами.

Контент можна редагувати в текстовому редакторі та додавати через FTP або SFTP. Файл має бути у UTF-8 без BOM. Збережіть службовий PHP блок до рядка `__halt_compiler();`. У файлі нової сторінки вставте цей блок із прикладу потрібної глибини та перевірте відносний шлях до кореневого `index.php`. Далі йдуть заголовки, один порожній рядок і HTML-фрагмент сторінки.

```php
<?php
$pageFile = __FILE__;
require __DIR__ . '/../index.php';
__halt_compiler();
Title: Контакты
Heading: Как с нами связаться
Description: Контактная информация
Menu: Контакты
MenuVisible: 1
Order: 20

<p>Укажите здесь контактную информацию.</p>
```

Обов'язковий `Title`. Порожній `Heading` береться із `Title`. `Description` заповнює метаопис сторінки. `MenuVisible: 1` показує посилання в меню, `MenuVisible: 0` приховує його. Для папки `index.php` вимкнення галочки також приховує з меню всі вкладені сторінки. Якщо `MenuVisible` відсутній, галочка успадковує колишнє правило і вважається включеною при заповненому `Menu`. При увімкненій галочці порожнє поле `Menu` замінюється заголовком `Title`. `Order` задає послідовність у межах одного рівня і за умовчанням дорівнює 100.

Вкладка CSS та JS зберігає загальний CSS та JavaScript для публічних сторінок. У редакторі сторінки є окремий блок CSS і JavaScript сторінки. Код завантажується після загального. Вказуйте лише вміст файлів без тегів `<style>` та `<script>`. Допустимий розмір кожного поля - до 64 КіБ. Для посилань на зображення із CSS можна використовувати шляхи від кореня сайту. Вкладка «Допомога» містить приклади доступних шаблонів та компонентів.

У розділі «Шаблони оформлення» можна переглянути вихідні дані `header.php`, `footer.php`, `menu.php` та `mobile-menu.php` та задати для кожного загальний HTML. "Службові заголовки" вставляють загальні метатеги, коди лічильників і скрипти в `<head>` або перед `</body>`. На кожній опублікованій повній сторінці `rel="canonical"` формується з звичайної адреси без параметрів запиту.

## Налаштування, підшаблони та домени

У розділі «Налаштування» задаються назва сайту, метаопис за замовчуванням, текст підвалу та змінні. У тексті підвалу `[year]` автоматично виводить поточний рік. Змінні записуються по одному на рядок, наприклад `[city] = Москва` та `[spb] = Санкт-Петербург`. Щоб вивести значення в назві сайту, вмісті сторінки, заголовку або підвалі, вставте `[city]`. У PHP-шаблонах можна використовувати `site_escape($settings['variables']['city'] ?? '')`.

Системні підстановки включають `[year]`, `[month]`, `[day]`, `[time]` (години й хвилини), `[dmY]` і `[date]` (дата ДД.ММ.РРРР), `[datetime]` (дата й час). Використовується часовий пояс PHP.

У «Основні → Логотипи та іконки сайту» можна завантажити PNG, JPEG, GIF або WebP. Завантаження обробляє PHP GD. Кнопка створення favicon робить прозорий PNG 64×64 з вибраного або збереженого логотипу. Зображення зберігаються у `templates/images/branding/` та `templates/icons/branding/`.

Підшаблони зберігає ім'я, опис і значення кожного коду. Для телефону створіть `[tel]`. Щоб встановити заголовок вкладки через підшаблон, створіть `[title]` і вкажіть його в полі `Title` сторінки. Після заголовка вкладки виводиться назва сайту. Підстановки працюють у тексті сторінки та текстових метаданих. Для посилання вставте весь тег `<a>` як значення підшаблону та розмістіть код у тексті між тегами. У метаданих HTML значення перетворюється на текст.

Додайте піддомени у розділі «Домени». У однойменній адмінці піддомену виберіть «Поточний домен» або відкрийте потрібний домен із загального списку. Локальне значення має пріоритет над загальним. Публічна сторінка вибирає значення домену у своїй адресі, а внутрішні посилання зберігають його. Щоб підключити піддомен, настройте DNS і веб-сервер на хостингу, щоб домен обслуговував той же каталог проекту.

Кнопка «Шаблони» поруч із доменом відкриває редактор `[header]`, `[mobile-menu]`, `[menu]` та `[footer]`. Для кожного блоку можна задати HTML або використовувати загальну версію. Загальні шаблони налаштовуються у тому самому розділі.

## Компоненти в HTML

| Код | Результат |
| --- | --- |
| `[gal]/images/myfotos/[/gal]` | Карусель фотографій з плавною прокруткою, стрілками та свайпом |
| `[fotos]/images/myfotos/[/fotos]` | Фотогалерея з посиланнями на оригінали |
| `[files]/files/myfiles[/files]` | Список файлів з іконками розширення |
| `[include]/contacts/[/include]` | HTML іншої сторінки з її підшаблонами та компонентами |
| `[form1]` | Форма, налаштована у розділі «Форми» |
| `[callback=Вызвать мастера]` | Кнопка та форма запиту зворотного дзвінка |
| `[iblock=table]/data/myiblock.txt[iblock]` | Таблиця інфоблоку |
| `[iblock=phones]/data/myiblock.txt[iblock]` | Список телефонів інфоблоку |
| `[phones]`, `[contacts]` | Телефони або весь налаштований блок контактів |
| `[soc-icons]` | Іконки всіх соцмереж з налаштованими посиланнями |
| `[tg]`, `[vk]`, `[whatsapp]`, `[youtube]`, `[instagram]`, `[max]` | Посилання на соцмережу з іконкою та підписом |

Розмістіть фотографії у `templates/images/myfotos/` або `images/myfotos/`. Список файлів показує `zip`, `pdf`, `xls`, `xlsx`, `doc`, `docx`, `png`, `gif`, `jpg`, `jpeg`, `mp4`, `mov` та `mp3`. Для `[include]` підтримується до десяти рівнів вкладення. Повтор сторінки в поточному ланцюжку пропускається. Розміщуйте коди компонентів в окремому рядку між блоками HTML.

У «Параметри → Контакти та соцмережі» вкажіть посилання, номери, підписи та заголовок блоку. У «Параметри → Тема та кольори» доступні системні, темні та світлі режими та окремі палітри. У «Параметри → Компоненти» встановлюються загальні параметри каруселі та фотогалереї. Під налаштуваннями є приклади вставки з вибраними значеннями. Параметри коду сторінки перевизначають загальні значення.

У темі та кольорах можна зберегти копію вибраних налаштувань під назвою або залишити автоматичну назву. "Застосувати" змінює поточне оформлення. "Використовувати за замовчуванням" застосовує збережену тему та запам'ятовує її для команди "Повернути тему за замовчуванням". Видалення зі списку зберігає поточне оформлення сайту.

```text
[gal arrows=off numbers=off effect=fade fit=cover]/images/myfotos/[/gal]
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off]/images/myfotos/[/fotos]
[files icons=on size=on order=desc download=on]/files/myfiles/[/files]
```

У `[fotos]` число колонок можна встановити вручну для широкого екрану або залишити автоматичний підбір. На вузьких екранах сітка скорочує кількість колонок. Доступні пропорції 4:3, 1:1, 16:9 та вихідні, режими `cover` та `contain`, підписи з імен файлів та посилання на оригінали.

## Форми та антиспам

У розділі «Форми» можна редагувати `[form1]`, створювати `[form2]` та наступні форми. Для форми задаються адреса одержувача, підпис кнопки та поля. У полі можна вказати максимальну довжину. Порожнє значення використовує стандартну межу для типу поля. Під час введення `89031234567` поле телефону форматує його як `+7(903)123-45-67`. Сервер перевіряє довжину, тип, допустимі варіанти вибору та обмежує сумарний розмір запиту. Поля вільного введення приймають текст. HTML у повідомленнях екранується під час виведення, а HTML-теги у нових повідомленнях відхиляються.

Галочка "Використовувати CAPTCHA" включає Google reCAPTCHA v2 з перевіркою "Я не робот" для вибраної форми. Введіть ключ сайту та секретний ключ для домену. Секрет зберігається у захищеному файлі налаштувань і використовується лише для серверної перевірки. [Документація з серверної перевірки](https://developers.google.com/recaptcha/docs/verify).

Форми надсилаються через AJAX. Заявки зберігаються у розділі «Повідомлення». Якщо вказано одержувача, для повідомлень використовується `mail()`, якому потрібна налаштована пошта на хостингу. У розділі «Антиспам» можна редагувати списки слів, виразів, IPv4 та IPv6-адрес. Посилання блокуються на сервері. Адреса відправника береться із `REMOTE_ADDR`. За зворотним проксі настройте відновлення вихідного IP у веб-сервері для довірених проксі.

Для кожної форми є "Поштовий шаблон" з полями "Кому", "Копії (Cc)", "Тема листа" та "Текст листа". Адреси вказуються через кому. Копії надсилаються, якщо вказано хоча б один основний одержувач. Ключі полів вставляються у тему та текст у фігурних дужках, наприклад `Привет {name}!`. Порожнє значення поля підставляється як порожній рядок, невідомий ключ залишається у листі. Під час порожньої теми або тексту використовується відповідна частина стандартного листа.

## Зворотні дзвінки

Вставте `[callback]` або `[callback=Вызвать мастера]` у HTML сторінці. Кнопка відкриє форму телефону. Запити зберігаються у розділі «Зворотні дзвінки». Там же задаються підписи кнопок та режим передачі заявки до телефонії. За промовчанням обрано провайдера «Ні», і заявки лише зберігаються. Телефон можна ввімкнути для ручного надсилання зі списку або для надсилання відразу після прийому номера.

- **Zadarma.** Задайте номер, SIP або додатковий оператора в адмінці, а ключі передайте PHP через `SITE_ZADARMA_KEY` та `SITE_ZADARMA_SECRET`. [Документація Zadarma API](https://zadarma.com/en/support/api/)
- **HTTP API.** Задайте `SITE_CALLBACK_WEBHOOK_URL` з HTTPS-адресою та за необхідності `SITE_CALLBACK_WEBHOOK_TOKEN`. Сайт відправляє POST з JSON-полями `id`, `phone`, `host`, `page`, `requested_at` та заголовком `Idempotency-Key`. Токен передається як Bearer. Код відповіді 2xx переказує заявку в статус «Прийнята телефонією».

Додайте PHP право запису в `admin/callbacks/`. Заявки використовують параметри антиспаму форм. Повтор на той же номер обмежений однією хвилиною, IP приймається до трьох заявок за 15 хвилин.

## Інфоблоки та закрита папка даних

У розділі «Інфоблоки» можна створювати набори даних, редагувати та перетягувати рядки. У імені інфоблоку та ключах стовпців дозволено `A–Z`, `a–z`, `0–9`, дефіс та підкреслення. Імена та ключі вводяться без пробілів. Назви стовпців і значення осередків можна писати російською мовою. Контроли відповідають типу стовпців, а збереження йде через AJAX. Кнопка ☰ «Правити як текст» перемикає весь інфоблок на CSV із роздільником `|` та кнопкою копіювання. Перші три рядки містять ключі, назви та типи стовпців. Потім йдуть рядки даних. Дата CSV має вигляд `ГГГГ-ММ-ДД`, «так/ні» зберігається як `1` або `0`.

```text
name|phone|is_open
Название|Телефон|Открыто
text|tel|bool
Справочная|+7(903)123-45-67|1
```

Шаблон `phones` використовує стовпці типу `tel` та текстовий стовпець з назвою. Свій шаблон можна розмістити в `templates/local/iblock/имя.php`, де доступні `$block['columns']` та `$block['rows']`.

Шлях `/data/myiblock.txt` всередині коду відповідає файлу `data/myiblock.txt.php`. Це текст UTF‑8 з PHP-заглушкою, яка повертає 404 під час прямого виклику. `router.php` закриває всю папку під час локального запуску. У `data/` є правила для Apache та IIS. Для Apache дозвольте застосування `data/.htaccess`. На Nginx налаштуйте закриття папки в конфігурації сайту, з урахуванням префікса при встановленні в підкаталог.

```nginx
location = /data { return 404; }
location ^~ /data/ { return 404; }
```

Після встановлення перевірте, чи прямий запит до `/data/` та файлу інфоблоку отримує 403 або 404.

## Завантаження HTML-фрагментів

Звичайна адреса `/contacts/` відкриває повну сторінку. Запит `?ajax=1` повертає `<main>` з H1 та обробленим вмістом за наявності ключа сесії у заголовку `X-Site-Fragment`. Фрагменти прив'язані до поточного origin. Сторінки та фрагменти з ключами видаються без кешування.

У JavaScript на сторінці сайту використовуйте вбудовану функцію.

```js
const html = await window.siteFetchContent('/contacts/');
document.getElementById('content').outerHTML = html;
```

Під час встановлення в підкаталог передавайте URL із префіксом сайту. Скрипт та стилі беруться зі сторінки, яка вставляє фрагмент. Громадські сторінки залишаються доступними за звичайними адресами.

## Оновлення двигуна

Повний архів необхідний нової установки. Для працюючого сайту використовуйте `php-site-update.zip`. У ньому тільки двигун і штатні шаблони. Збережені сторінки, інфоблоки, налаштування, паролі, повідомлення та розширення користувача до архіву не входять.

Натисніть «Оновити двигун» у «Параметри → Оновлення» або запустіть ту ж саму перевірку з планувальника хостингу.

```sh
php update.php --github
```

Джерело за замовчуванням - `bandaletov72/php-site-updates`. Для свого репозиторію задайте `SITE_GITHUB_REPO`. У громадському репозиторії токен непотрібен. Для закритого репозиторію передайте PHP змінну `SITE_GITHUB_TOKEN` з правом читання вмісту. На сервері потрібні PHP-розширення Zip та OpenSSL та можливість HTTPS-запитів до GitHub.

Для ручного встановлення використовуйте ZIP.

```sh
php update.php /path/to/php-site-update.zip
```

На старій версії без `update.php` спочатку розпакуйте пакет поверх проекту, зберігши існуючі `.htaccess` та файли з `maintenance/`, якщо вони є. Якщо ви керували штатними шаблонами, перенесіть зміни до `templates/local/` до оновлення. Інсталятор перевіряє список і контрольні суми файлів, а для GitHub також перевіряє підпис довіреним відкритим ключем `maintenance/release-public.pem`.

Для наступного випуску змініть версію `app/version.php` і зберіть пакет через `php update.php --build php-site-update.zip`. Підпишіть ZIP своїм закритим RSA-ключом із SHA‑256, зберігайте закритий ключ окремо від сайту. Потім розмістіть ZIP та `.sig` у GitHub Release з тегом `vX.Y.Z` або у `updates/vX.Y.Z/` та оновіть `updates/latest.json` до `{"version":"X.Y.Z"}`.

## Розширення

Модулі двигуна можна додавати до `app/extensions/` разом з оновленнями. Власні модулі зберігайте в `extensions/` поза пакетом оновлення. PHP файл повертає масив визначень. У одиночного компонента `kind` дорівнює `single`, у компонента з аргументом - `wrapped`. Двигун розпізнає нові коди на існуючих сторінках. Компонент може оголосити меню параметрів `settings`, задавши для кожного параметра `label`, `default` і масив `options`. Значення надходять у `$context['settings']`.

```php
<?php
if (!defined('SITE_ROOT')) {
    http_response_code(404);
    exit;
}

return ['notice' => [
    'kind' => 'wrapped',
    'render' => static function (string $text, array $context): string {
        return '<strong>' . site_escape($text) . '</strong>';
    },
]];
```

Компонент із прикладу вставляється як `[notice]Важное сообщение[/notice]`.

## Міста · Телефон · 1.6.18

Обов’язкова лише назва міста. Домен і телефони можна залишити порожніми. Номер має містити «+» і код країни, наприклад +7 (900) 000-00-00. Замість номера можна вказати підшаблон [tel].

Порядок вибору: збережене місто, місто домену, потім перше місто списку. Якщо список порожній, показуються загальні телефони.

Форми, зворотні дзвінки й нові замовлення надходять на E-Mail міста або на загальну адресу. Якщо обидва поля порожні, форми використовують власні адреси. Порожні посилання соцмереж успадковуються від сайту.

У режимі редагування наведіть вказівник на шаблон і натисніть «Редагувати шаблон». Для будь-якого встановленого [php] відкрийте код і налаштування кнопкою «Редагувати модуль». Редактор кадру показує назву та код форми. [banners width=100] заповнює ширину вікна як окремий блок на сторінці без бічної колонки. Редактор шаблону відкривається в модальному вікні сайту.

Менеджер файлів перевіряє папку та її файли перед видаленням. Для непорожньої папки створюється резервна копія. Кадр банера може мати заголовок і підзаголовок.

Телефон перевіряється під час введення. Російський номер, що починається з 8, перетворюється на +7. Після надсилання форма ховається, а при повторному відкритті видно підтвердження.

До номера без «+» додається код вибраної країни. Номер з «+» зберігає введений міжнародний код.

## Теми дизайну

Скопіюйте файл у тему й збережіть його. Відсутні файли беруться зі штатної поставки. Зміни, нові шорткоди, історія та доменні налаштування оформлення діють лише в активній темі. Додаткові стилі та скрипти можна зберегти в css/theme.css і js/theme.js.

`templates/themes/demo/header.php` · `templates/themes/demo/components/banners.php`

Мови розташовані внизу мобільного меню. На комп’ютері перемикач із глобусом поруч із пошуком у меню під шапкою.

Галереї, банери й списки шукають папки в активній темі, а за їх відсутності використовують спільні файли. Нові папки, завантаження, логотипи й favicon записуються в тему. Резервна копія включає тему та її налаштування.

Виберіть ширину вікна (width=page), вмісту (width=content) або батьківського блока (width=parent). height задає висоту на комп’ютері, mobile-height — на телефоні. auto зберігає природний розмір.

`[banners width=page height=520 mobile-height=240]` · `[form1 width=parent]`

Остання хлібна крихта показує опубліковані сусідні розділи, зокрема прибрані з головного меню. Для посилання використовується вказаний URL.
