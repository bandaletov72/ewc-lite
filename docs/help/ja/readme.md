# Eurowebcart CMS Light

作者 - Бандалетов Павел。 [オリジナルプロジェクトとアップデート](https://github.com/bandaletov72/php-site-updates)。

PHP の最低バージョンは 7.2 です。サイトと管理画面は PHP 8.6 に対応しています。独自のモジュールやテンプレートでは、サーバーの PHP バージョンに対応する構文を使用してください。

[管理者向けよくある質問](faq.md) は「ヘルプ」タブにもあります。

[現在のバージョンのヘルプを 10 か国語で表示](../README.md) では、検索、サイト編集、ローカリゼーション、およびメンテナンスについて説明します。 [Admin FAQ in English](../en/faq.md)。

定期メンテナンスの場合は、コマンド `php update.php --scheduled` を 15 分間の間隔でホスティング スケジューラに追加します。 「メンテナンス」セクションでは、個別にインデックスの再作成を有効にし、署名された GitHub 更新のチェック間隔を設定できます。

## ローカルでの起動

`php-site` ディレクトリに移動し、組み込みの PHP サーバーを起動します。

```sh
php -S 127.0.0.1:8000 router.php
```

サイトはアドレス `http://127.0.0.1:8000/` で開き、管理パネルは `http://127.0.0.1:8000/admin/` にあります。

## インストールと初回ログイン

ローカル サーバーで `/admin/` を開いてアカウントを作成します。 2 番目のステップでは、サイト名、メタディスクリプション、フッターテキスト、パレット、テーマモードを設定します。 PHP GD をお持ちの場合は、ロゴをすぐにダウンロードできます。ウィザードはそこからファビコンを作成します。 「保存して管理画面を開く」をクリックするか、現在の設定を続行します。ウィザードを終了すると、次回ログインしたときにウィザードが続行されます。

ホスティング上で、プロジェクト ディレクトリから `php admin/setup.php` を実行し、ウィザードの最初のステップでワンタイム コードを入力します。コードはアカウントを作成するときに引き換えられます。インストール前にコマンドを再度実行すると、前のコードが置き換えられます。アップデートをインストールすると、以前のアカウントと設定が保持されます。更新前のバージョンで `SITE_ADMIN_PASSWORD_HASH` が使用されていた場合、ログインはログイン `admin` と以前のパスワードで保存されます。

アプリケーションが動作するには、PHP セッションと、`admin/`、`admin/write-lock.php`、`admin/inbox/`、`data/`、および編集可能なページのディレクトリへの書き込み権限が必要です。ルートにページとディレクトリを作成するには、PHP プロセスにプロジェクト ルートへの書き込みアクセスを与えます。 HTTPS で Web サーバーを使用し、インデックス ファイル リストの `.php` および `index.php` を処理します。ディレクトリのリストを無効にします。リバース プロキシの背後にある HTTPS の場合は、信頼されたサーバー構成を通じて PHP 属性 `HTTPS` を渡します。

## ページとメニュー

管理パネルでは、メイン ページは `/` としてリストされ、フォルダー内の残りのページは `/contacts/` としてリストされます。サブページを作成するには、たとえば、`/Services-1/Repair/` と入力します。管理パネルはカタログと `index.php` 自体を作成します。別のファイルの場合は、`/Services-1/About_2.php` のようなアドレスを入力します。ファイル名とフォルダー名には、`A–Z`、`a–z`、`0–9`、ハイフン、アンダースコアを使用できます。名前はスペースなしで入力されます。ルートでは、メイン ページのみが許可されます。 `data`、`admin`、`templates`、`css`、`js` などのサービス ディレクトリは予約されています。

ページ一覧ではフォルダを展開することができます。 [メニュー] チェックボックスでは、非表示、公開、削除が AJAX 経由で保存されます。非表示、公開、削除には確認が必要です。 ⠿ アイコンをドラッグして、隣接するページを並べ替えます。非表示のページは開かなくなり、公開前にメニューから消えます。

ページエディターで「ページの移動」ブロックを開き、移動先フォルダーを指定します。たとえば、`/contacts/` を `/company/` に転送すると、新しいアドレスは `/company/contacts/` になります。ネストされたページは同じアドレスに残ります。移行されたページにつながる独自のリンクとコード `[include]` を更新します。

⠿ ハンドルをドラッグすると同階層のページを並べ替えられます。単一のページはページ設定で移動します。フォルダー横のアイコンで親セクションを選べます。移動先またはルートを選び、「フォルダーを移動」を押すとページとファイルも移動します。旧 URL のリンクと [include] を確認してください。

コンテンツはテキスト エディタで編集し、FTP または SFTP 経由で追加できます。ファイルは BOM なしの UTF-8 である必要があります。 PHP サービス ブロックを `__halt_compiler();` 行まで保存します。新しいページ ファイルで、例のこのブロックを目的の深さに挿入し、ルート `index.php` への相対パスを確認します。次に、ヘッダー、1 つの空行、およびページの HTML フラグメントが続きます。

```php
<?php
$pageFile = __FILE__;
require __DIR__ . '/../index.php';
__halt_compiler();
Title: Контакты
Heading: Как с нами связаться
Description: Контактная информация
Menu: Контакты
MenuVisible: 1
Order: 20

<p>Укажите здесь контактную информацию.</p>
```

`Title` は必須です。空の `Heading` は `Title` から取得されます。 `Description` はページのメタディスクリプションを入力します。 `MenuVisible: 1` はメニュー内のリンクを表示し、`MenuVisible: 0` はメニューにリンクを非表示にします。 `index.php` フォルダーの場合、チェックボックスをオフにすると、メニューからすべてのサブページが非表示になります。 `MenuVisible` が欠落している場合、チェックボックスは前のルールを継承し、`Menu` が入力されると有効になっているとみなされます。チェックボックスを有効にすると、空のフィールド `Menu` がヘッダー `Title` に置き換えられます。 `Order` は 1 レベル内のシーケンスを指定し、デフォルトは 100 です。

[CSS と JS] タブには、公開ページの共通 CSS と JavaScript が保存されます。ページ エディターには別のブロック「CSS および JavaScript ページ」があります。ページ コードは、一般的なコードの後に​​読み込まれます。 `<style>` および `<script>` タグを付けずに、ファイルの内容のみを指定します。各フィールドの許容サイズは最大 64 KiB です。 CSS から画像にリンクするには、サイト ルートからのパスを使用できます。 [ヘルプ] タブには、使用可能なテンプレートとコンポーネントの例が含まれています。

「デザイン テンプレート」セクションでは、`header.php`、`footer.php`、`menu.php`、`mobile-menu.php` のソースを表示し、それぞれに共通の HTML を設定できます。 「サービス ヘッダー」は、共通のメタ タグ、カウンター コード、およびスクリプトを `<head>` または `</body>` の前に挿入します。パブリッシュされた各フル ページでは、`rel="canonical"` はクエリ パラメーターなしの通常のアドレスから形成されます。

## 設定、サブテンプレート、ドメイン

「設定」セクションでは、サイト名、デフォルトのメタディスクリプション、フッターテキスト、変数を設定します。フッター テキストでは、`[year]` によって現在の年が自動的に表示されます。変数は、`[city] = Москва` や `[spb] = Санкт-Петербург` のように、1 行に 1 つずつ書き込まれます。サイト タイトル、ページ コンテンツ、ヘッダー、またはフッターに値を表示するには、`[city]` を挿入します。 PHP テンプレートでは、`site_escape($settings['variables']['city'] ?? '')` を使用できます。

システム置換には、`[year]`、`[month]`、`[day]`、`[time]` (時と分)、`[dmY]` および `[date]` (日付 DD.MM.YYYY)、`[datetime]` (日付と時刻) が含まれます。 PHP タイムゾーンが使用されます。

「基本 → サイトのロゴとアイコン」で、PNG、JPEG、GIF、または WebP をアップロードできます。ダウンロードは PHP GD によって処理されます。ファビコンの作成ボタンは、選択または保存したロゴから透明な 64×64 PNG を作成します。画像は `templates/images/branding/` と `templates/icons/branding/` に保存されます。

「サブテンプレート」には、各コードの名前、説明、意味が保存されます。電話機の場合は、`[tel]` を作成します。サブテンプレートを使用してタブ タイトルを設定するには、`[title]` を作成し、ページの `Title` フィールドに指定します。タブタイトルの後にサイト名が表示されます。置換はページ テキストとテキスト メタデータで機能します。リンクの場合、`<a>` タグ全体をサブテンプレート値として挿入し、タグ間のテキストにコードを配置します。メタデータでは、HTML が値からテキストに変換されます。

「ドメイン」セクションにサブドメインを追加します。同じ名前のサブドメインの管理パネルで、「現在のドメイン」を選択するか、一般リストから目的のドメインを開きます。ローカルな意味は一般的な意味より優先されます。公開ページはアドレスのドメインごとに値を選択し、内部リンクがそれを保存します。サブドメインに接続するには、ドメインが同じプロジェクト ディレクトリを提供するように、ホスティング上で DNS と Web サーバーを構成します。

ドメインの横にある [テンプレート] ボタンをクリックすると、`[header]`、`[mobile-menu]`、`[menu]`、`[footer]` エディターが開きます。ブロックごとに、独自の HTML を設定することも、一般バージョンを使用することもできます。一般的なテンプレートは同じセクションで設定されます。

## HTMLのコンポーネント

| コード | 結果 |
| --- | --- |
| `[gal]/images/myfotos/[/gal]` | スムーズなスクロール、矢印、スワイプを備えた写真カルーセル |
| `[fotos]/images/myfotos/[/fotos]` | オリジナルへのリンクを含むフォトギャラリー |
| `[files]/files/myfiles[/files]` | 拡張子別のアイコンを持つファイルのリスト |
| `[include]/contacts/[/include]` | 別のページの HTML とそのサブテンプレートおよびコンポーネント |
| `[form1]` | 「フォーム」セクションで構成されたフォーム |
| `[callback=折り返しを依頼]` | コールバックリクエストボタンとフォーム |
| `[iblock=table]/data/myiblock.txt[iblock]` | 情報ブロックテーブル |
| `[iblock=phones]/data/myiblock.txt[iblock]` | 情報ブロック電話機一覧 |
| `[phones]`, `[contacts]` | 電話または設定された連絡先ブロック全体 |
| `[soc-icons]` | カスタマイズされたリンクを含むすべてのソーシャル ネットワークのアイコン |
| `[tg]`, `[vk]`, `[whatsapp]`, `[youtube]`, `[instagram]`, `[max]` | アイコンと署名付きのソーシャル ネットワーク リンク |

写真を `templates/images/myfotos/` または `images/myfotos/` に配置します。ファイルリストには、`zip`、`pdf`、`xls`、`xlsx`、`doc`、`docx`、`png`、`gif`、`jpg`、`jpeg`、`mp4`、`mov`、および`mp3`。 `[include]` の場合、最大 10 個のネスト レベルがサポートされます。現在のスレッドのページ繰り返しはスキップされます。コンポーネント コードは、ページの本文の HTML ブロック間の別の行に配置します。

「設定→連絡先とソーシャルネットワーク」で、リンク、番号、署名、ブロックタイトルを設定します。 「設定 → テーマと色」では、システム、ダークモード、ライトモード、および個別のパレットが利用可能です。 「設定 → コンポーネント」で、カルーセルとフォトギャラリーの一般パラメータを設定します。設定の下に、選択した値を使用して挿入する例があります。ページ コード内のパラメータは共通の値をオーバーライドします。

テーマと色では、選択した設定のコピーを自分の名前で保存することも、名前を自動のままにすることもできます。 「適用」すると現在のデザインが変更されます。 [デフォルトを使用] では、保存されたテーマが適用され、テーマをデフォルトにリセット コマンド用に記憶されます。リストから削除すると、サイトの現在のデザインが保持されます。

```text
[gal arrows=off numbers=off effect=fade fit=cover]/images/myfotos/[/gal]
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off]/images/myfotos/[/fotos]
[files icons=on size=on order=desc download=on]/files/myfiles/[/files]
```

`[fotos]` の場合、列数はワイド画面用に手動で設定することも、自動的に選択されたままにすることもできます。狭い画面では、グリッドにより列の数が減ります。利用可能なアスペクト比は、4:3、1:1、16:9、オリジナル、`cover` および `contain` モード、ファイル名からの署名、およびオリジナルへのリンクです。

## フォームとスパム対策

「フォーム」セクションでは、`[form1]` を編集し、`[form2]` および以下のフォームを作成できます。フォームには、受信者のアドレス、ボタンの署名、およびフィールドが指定されます。フィールドには最大長を指定できます。値が空の場合は、フィールド タイプのデフォルトの制限が使用されます。 `89031234567` と入力すると、電話フィールドは `+7(903)123-45-67` としてフォーマットされます。サーバーは長さ、タイプ、有効な選択肢をチェックし、リクエストの合計サイズを制限します。自由入力フィールドにはプレーンテキストを受け入れます。メッセージ内の HTML は出力時にエスケープされ、新しいメッセージ内の HTML タグは拒否されます。

[Use CAPTCHA] チェックボックスをオンにすると、選択したフォームに対して [I'm not a robot] チェックを付けた Google reCAPTCHA v2 が有効になります。ドメインのサイトキーと秘密キーを入力します。シークレットは保護された設定ファイルに保存され、サーバーの検証にのみ使用されます。 [サーバー検証ドキュメント](https://developers.google.com/recaptcha/docs/verify)。

フォームは AJAX 経由で送信されます。アプリケーションは「メッセージ」セクションに保存されます。受信者が指定されている場合は、通知に `mail()` が使用されます。これには、ホスティング上でメールを構成する必要があります。 [スパム対策] セクションでは、単語、表現、IPv4 および IPv6 アドレスのリストを編集できます。リンクはサーバー上でブロックされています。送信者のアドレスは `REMOTE_ADDR` から取得されます。リバース プロキシの背後で、信頼されたプロキシの Web サーバーで元の IP の回復を構成します。

各フォームには、「To」、「Cc (Cc)」、「メールの件名」、「メール本文」のフィールドを含む「メール テンプレート」があります。アドレスはカンマ区切りで指定します。少なくとも 1 人の主受信者が指定されている場合、コピーが送信されます。フィールド キーは、中括弧で囲まれた件名とテキストに挿入されます (例: `Привет {name}!`)。空のフィールド値は空の文字列として置換され、不明なキーは文字内に残ります。件名またはテキストが空の場合は、標準レターの対応する部分が使用されます。

## 折り返し電話の依頼

`[callback]` または `[callback=Вызвать мастера]` を HTML ページに挿入します。ボタンをクリックすると、電話番号を入力するフォームが開きます。リクエストは「コールバック」セクションに保存されます。ボタンの署名と、要求を電話に転送するためのモードもここで設定されます。デフォルトでは、「なし」プロバイダーが選択され、リクエストは保存のみされます。テレフォニーは、リストから手動で送信することも、番号を受信した直後に送信することもできます。

- **Zadarma.** 管理画面で電話番号、SIP、または担当者の内線を設定します。PHP に `SITE_ZADARMA_KEY` と `SITE_ZADARMA_SECRET` を渡します。[ザダルマ API ドキュメント](https://zadarma.com/en/support/api/)
- **HTTP API.** HTTPS アドレスで `SITE_CALLBACK_WEBHOOK_URL` を指定し、オプションで `SITE_CALLBACK_WEBHOOK_TOKEN` を指定します。サイトは、JSON フィールド `id`、`phone`、`host`、`page`、`requested_at` およびヘッダー `Idempotency-Key` を含む POST を送信します。トークンはBearerとして転送されます。応答コード 2xx により、リクエストは「テレフォニーで受理されました」ステータスに移行します。

PHP プロセスに `admin/callbacks/` への書き込み権限を与えます。アプリケーションはフォームのスパム対策設定を使用します。同じ番号の繰り返しは 1 分間に制限されます。 IP 経由では、15 分あたり最大 3 つのリクエストが受け入れられます。

## 情報ブロックとクローズドデータフォルダー

「情報ブロック」セクションでは、データセットを作成し、行を編集およびドラッグできます。情報ブロック名と列キーには、`A–Z`、`a–z`、`0–9`、ハイフン、アンダースコアを使用できます。名前とキーはスペースを入れずに入力します。列名とセル値はロシア語で記述できます。コントロールは列の型に対応しており、保存は AJAX 経由で行われます。 ☰ 「テキストとして編集」ボタンは、区切り文字 `|` とコピー ボタンを使用して、情報ブロック全体を CSV に切り替えます。最初の 3 行には、列のキー、名前、タイプが含まれています。次にデータ行があります。 CSV の日付は `ГГГГ-ММ-ДД` で、はい/いいえは `1` または `0` として保存されます。

```text
name|phone|is_open
Название|Телефон|Открыто
text|tel|bool
Справочная|+7(903)123-45-67|1
```

`phones` テンプレートは、`tel` 型の列とタイトル付きのテキスト列を使用します。テンプレートは `templates/local/iblock/имя.php` に配置できます。`$block['columns']` と `$block['rows']` が使用可能です。

コード内のパス `/data/myiblock.txt` は、ファイル `data/myiblock.txt.php` に対応します。これは、直接呼び出すと 404 を返す PHP スタブを含む UTF-8 テキストです。 `router.php` は、ローカルで実行するとフォルダー全体を閉じます。 `data/` には、Apache と IIS のルールがあります。 Apache の場合は、`data/.htaccess` を有効にします。 Nginx では、サブディレクトリにインストールするときのプレフィックスを考慮して、サイト構成でフォルダーが閉じるように構成します。

```nginx
location = /data { return 404; }
location ^~ /data/ { return 404; }
```

インストール後、`/data/` への直接リクエストと情報ブロック ファイルが 403 または 404 を受信することを確認します。

## HTML フラグメントの読み込み

通常のアドレス `/contacts/` は完全なページを開きます。 `X-Site-Fragment` ヘッダーにセッション キーがある場合、リクエスト `?ajax=1` は H1 と処理されたコンテンツを含む `<main>` を返します。フラグメントは現在の原点にリンクされます。キーを含むページとフラグメントはキャッシュせずに提供されます。

サイト ページの JavaScript では、組み込み関数を使用します。

```js
const html = await window.siteFetchContent('/contacts/');
document.getElementById('content').outerHTML = html;
```

サブディレクトリにインストールする場合は、サイトのプレフィックスを付けて URL を渡します。スクリプトとスタイルは、フラグメントを挿入するページから取得されます。公開ページには通常のアドレスから引き続きアクセスできます。

## テンプレートとリソース

「設定 → ライブラリとフォント」では、jQuery、Bootstrap、Font Awesome、マテリアル UI、Alpine.js、htmx、Chart.js、GLightbox が個別に有効になります。 Font Awesome はローカルに保存されます。残りのライブラリは、有効にするとブラウザによって CDN からダウンロードされます。マテリアル UI は、スクリプト `type="module"` から `import { Button } from '@mui/material'` で使用できます。アイコンの場合は、`[fa-icon=house]` または通常のマークアップ `<i class="fa-solid fa-house"></i>` が適しています。

## エンジンのアップデート

新規インストールには完全なアーカイブが必要です。ライブ サイトの場合は、`php-site-update.zip` を使用します。エンジンと標準テンプレートのみが含まれています。保存されたページ、情報ブロック、設定、パスワード、メッセージ、およびユーザー拡張子はアーカイブには含まれません。

「設定 → アップデート」の「アップデート エンジン」をクリックするか、ホスティング スケジューラから同じチェックを実行します。

```sh
php update.php --github
```

デフォルトのソースは `bandaletov72/php-site-updates` です。独自のリポジトリの場合は、`SITE_GITHUB_REPO` に設定します。パブリック リポジトリにはトークンは必要ありません。プライベート リポジトリの場合は、コンテンツへの読み取りアクセス権を持つ変数 `SITE_GITHUB_TOKEN` を PHP プロセスに渡します。サーバーには、Zip および OpenSSL PHP 拡張機能と、GitHub への HTTPS リクエストを行う機能が必要です。

手動インストールの場合は、ZIP を使用します。

```sh
php update.php /path/to/php-site-update.zip
```

`update.php` のない古いバージョンでは、まずプロジェクトの上でパッケージを解凍し、既存の `.htaccess` と `maintenance/` のファイル (存在する場合) を保持します。標準テンプレートを編集した場合は、更新する前に編集内容を `templates/local/` に転送します。インストーラーはファイルのリストとチェックサムを検証し、GitHub の場合は信頼された公開キー `maintenance/release-public.pem` による署名も検証します。

次のリリースでは、バージョンを `app/version.php` に変更し、`php update.php --build php-site-update.zip` 経由でパッケージをビルドします。 SHA‑256 を使用して RSA 秘密キーを使用して ZIP に署名し、秘密キーをサイトとは別に保管します。次に、ZIP と `.sig` をタグ `vX.Y.Z` で GitHub リリースまたは `updates/vX.Y.Z/` にプッシュし、`updates/latest.json` を `{"version":"X.Y.Z"}` に更新します。

## 拡張機能

エンジン モジュールはアップデートとともに `app/extensions/` に追加できます。独自のモジュールを更新パッケージの外の `extensions/` に保存します。 PHP ファイルは定義の配列を返します。単一コンポーネントの `kind` は `single` に等しく、引数を持つコンポーネントの `wrapped` は同じです。エンジンは既存のページ上の新しいコードを認識します。コンポーネントは、`settings` でオプションのメニューを宣言し、各オプションを `label`、`default`、および配列 `options` に設定できます。値は`$context['settings']`で受け取ります。

```php
<?php
if (!defined('SITE_ROOT')) {
    http_response_code(404);
    exit;
}

return ['notice' => [
    'kind' => 'wrapped',
    'render' => static function (string $text, array $context): string {
        return '<strong>' . site_escape($text) . '</strong>';
    },
]];
```

サンプル コンポーネントは `[notice]Важное сообщение[/notice]` として挿入されます。
