# テンプレートとコンポーネント

## レイアウトテンプレート

### ヘッダー、メニュー、フッター

ページ全体では、これらのブロックが自動的に接続されます。一般バージョンは「デザイン テンプレート」で編集し、個々のドメインの場合は「ドメイン」セクションで編集します。

```text
[header]
[mobile-menu]
[menu]
[footer]
```

### 別のページを挿入する

公開されたページのコンテンツを挿入します。最大ネストは 10 レベルです。同じチェーン内のページを繰り返すとスキップされます。

```text
[include]/contacts/[/include]
```

### メニュー内のリンク

「メニューに表示」チェックボックスをオンにすると、標準メニューへのリンクが追加されます。名前が空の場合は、タイトルが使用されます。フォルダー ページのチェックボックスをオフにすると、そのサブページもメニューから消えます。

```text
メニュー表示: 1
メニュー: 連絡先
```

### CSSとJavaScript

一般的なコードは「CSSとJS」タブで編集します。ページ コードは「CSS および JavaScript ページ」ブロックで編集され、一般的なコードの後に​​組み込まれます。 CSS および JavaScript コンテンツをフィールドに貼り付けます。

```text
.page-content { max-width: 72rem; }
```

```text
document.documentElement.classList.add('custom-script-loaded');
```

### サービスヘッダー

「デザインテンプレート→サービスヘッダー」セクションでは、ヘッド内または終了本文の前に一般的なメタタグとカウンターコードを挿入できます。 Canonical はページ全体に自動的に追加されます。

```text
<meta name="theme-color" content="#065f63">
```

### 素晴らしいフォントのアイコン

Font Awesome Free 7.3.1 が接続されました。短いコードは、コンテンツおよび HTML デザイン ブロックで機能します。ソリッド、レギュラー、ブランドスタイルをご用意しております。アクションを表す場合は、アイコンの横にテキストを追加します。

```text
[fa-icon=house] [fa-icon=regular:envelope] [fa-icon=brands:github]
```

```text
<i class="fa-icon fa-solid fa-phone" aria-hidden="true"></i> 連絡先
```

### ライブラリとフォント

接続は「設定 → ライブラリとフォント」で管理します。マテリアル UI には、モジュール型 JavaScript を使用します。選択した Google フォントは、サイトのシステム フォントを置き換えます。

```text
<script type="module">import { Button } from "@mui/material";</script>
```

```text
GLightbox({selector: ".glightbox"});
```

## 変数、サブテンプレート、日付

### サイト変数

「設定→一般」にエントリを追加します。テキスト、ヘッダー、サイトのタイトル、またはフッターにキーを挿入します。

```text
[city] = モスクワ
[spb] = サンクトペテルブルク
```

```text
市内のサービス[city]
```

### スニペット

[サブテンプレート] セクションで、名前、説明、値を指定します。ドメインの場合、最初にその値が取得され、次に一般的な値が取得されます。サブテンプレートには HTML が含まれる場合があります。ヘッダー内のマークアップは削除されます。

```text
[tel]
```

```text
[title]
```

### 日時

タイムゾーンはPHPから取得されます。 [year] - 年、[month] - 月、[day] - 日、[time] - 時と分、[dmY] および [date] - 日付 DD.MM.YYYY、[datetime] - 日付と時刻。

```text
© [year] [city]
日付 [dmY]、時刻 [time]
```

### CMS 名と作成者

コード [author] は、Eurowebcart CMS Light、作成者名 Бандалетов Павел、および GitHub へのリンクを出力します。標準のフッターでは、署名は自動的に表示されます。独自の HTML フッター内の、必要な場所にコードを貼り付けます。

```text
[author]
```

### ホームテンプレートとポリシー

[page-content] はホームページの内容を [home] に挿入します。ポリシーは「ページ」の /privacy/ で編集できます。[site-name] と [site-url] は基本設定から取得します。

```text
[page-content]
```

```text
[site-name] · [site-url]
```

### フッターのリンクと設定

[privacy] は /privacy/ へのリンク、[top] は先頭へのスクロール、[cookies] は同意設定を開きます。

```text
[privacy]
[cookies]
[top]
```

### 一般的な PHP 関数

「デザイン テンプレート → 関数」セクションで、functions.php を編集します。 PHP コードでは、translit() または ew_call() は登録された関数を呼び出します。ショート コード [func=translit] は、コンテンツと [カスタム HTML] フィールドで使用できます。

```text
[func=translit value="Москва и München"]
```

```text
$var = translit("モスクワ");
```

```text
echo ew_escape(ew_call("translit", "München"));
```

## カルーセル、フォトギャラリー、ファイル

### カルーセル [gal]

フォルダー内の写真を表示します。矢印と数字はオンまたはオフ、効果 - スライド、フェードまたはなし、フィット - 含むかカバーを受け入れます。

```text
[gal]/images/myfotos/[/gal]
```

```text
[gal arrows=on numbers=off effect=fade fit=cover width=50]/images/myfotos/[/gal]
```

### フォトギャラリー [fotos]

レスポンシブなグリッドを表示します。列 - 自動または 1 ～ 6 の数値、比率 - 4x3、1x1、16x9 またはオリジナル、フィット - カバーまたは含む。キャプションとリンクはオンまたはオフで有効になります。

```text
[fotos]/images/myfotos/[/fotos]
```

```text
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off width=50%]/images/myfotos/[/fotos]
```

### ファイルのリスト [files]

サポートされているファイルをリストします。アイコン、サイズ、ダウンロードのオンまたはオフ、順序 (昇順または降順) を選択します。 Zip、pdf、xls、xlsx、doc、docx、png、gif、jpg、jpeg、mp4、mov、mp3 が使用できます。

```text
[files]/files/myfiles/[/files]
```

```text
[files icons=on size=on order=desc download=on width=33]/files/myfiles/[/files]
```

## フォームとコールバック

### フォーム[formN]

「フォーム」セクションで、フィールド、その最大長、ボタンのテキスト、受信者を設定します。 「Use CAPTCHA」は、サーバー上で応答検証を行う Google reCAPTCHA v2 ウィジェットを有効にします。リクエストは AJAX 経由で送信され、[メッセージ] セクションに表示されます。

```text
[form1]
[form2]
```

### メールフォームテンプレート

件名とテキストはフォームごとに個別に保存されます。電子メール テンプレートで、中括弧内にフィールド キーを挿入します。受信者とコピーのリストはカンマで区切られます。

```text
{name}さん、こんにちは！
電話番号: {phone}
メッセージ: {message}
```

### [callback] に折り返し電話してください

電話番号を入力したフォームを開きます。アプリケーションは「コールバック」セクションに保存されます。ボタンのラベルはコードで設定できます。 「いいえ」プロバイダーを使用すると、テレフォニーへの送信は無効になります。

```text
[callback]
[callback=折り返しを依頼]
```

## データブロック

### 電話機の表とリスト

「情報ブロック」セクションでデータセットを作成します。情報ブロック名と列キーには、A ～ Z、a ～ z、0 ～ 9、ハイフン、およびアンダースコアを使用できます。スペースは使用できません。テーブル テンプレートにはテーブルが表示され、電話には通話へのリンクを含む電話列が表示されます。終了コード [iblock] および [/iblock] がサポートされています。

```text
[iblock=table]/data/myiblock.txt[iblock]
[iblock=phones]/data/myiblock.txt[/iblock]
```


### 個人のソーシャルネットワーク

各コードには、そのソーシャル ネットワークへのリンクが表示されます。アドレスと署名は「設定→連絡先とソーシャルネットワーク」で設定します。

```text
[tg] [vk] [whatsapp] [youtube] [instagram] [max]
```

```text
[wa] [yt] [ig]
```

地球のアイコンでサイトを開き、矢印のアイコンでログアウトします。スマートフォンではアイコンのみ表示されます。マウスを乗せるか、キーボードでフォーカスするとラベルを確認できます。

「コンテンツ」「フォームとリクエスト」「サイトとサービス」を選ぶと、各セクションが直接開きます。メインメニューの下に選択したセクションのタブが表示されます。

ホームページ（index.php）またはテンプレートのHTMLに [bread-crumbs] や [search] を追加すると、指定した位置に一度だけ表示されます。パンくずリストと検索の設定も適用されます。[privacy] は /privacy/ へのリンクです。ポリシーは「ページ」で編集できます。

## 設定ファイル、地図、テンプレート · 1.6.5

メンテナンスの設定ファイルで .htaccess、robots.txt、sitemap.xml を編集できます。生成時にはサイトマップに含める設定の公開ページが対象となります。.htaccess の前の版を復元できます。

ページに緯度と経度を入力します。[map] はそのページの地点を表示し、[maps] は座標のある公開ページ全体を表示します。center と zoom で中心と倍率を指定し、連携設定で地図サービスを選びます。

[main-menu] はヘッダー直下のドロップダウンメニューです。独自テンプレートを追加し、端末別の表示を設定できます。スニペット画面からドメイン追加フォームを開けます。ポリシーへのリンクは [privacy] です。

連携設定で JivoSite、Microsoft Clarity、Umami Cloud の ID、Botfaqtor のコード、Slack の受信用 Webhook を設定できます。各欄の案内を参照してください。Zadarma では残高照会、SMS と通話のテストができます。テストの際に料金が発生する場合があります。[payment] には YooMoney、PayPal、SBP の決済リンクを設定し、支払い状況はサービス側で確認します。

HTML とビジュアル編集の各アイコンで文字装飾、見出し H1〜H5、リストを追加できます。カーソル位置を決め、テンプレート、コンポーネント、画像、アイコンを選びます。フォーム一覧とコンポーネントの設定が表示されます。Font Awesome はライブラリ有効時に使えます。

フォルダー名を選ぶと右側でセクションを管理できます。親セクション、モバイルと通常のメニュー、転送先 URL を設定できます。空のページには子セクションが表示されます。メンテナンスで /contact.html => /contacts/ のようなルールを追加し、/error/ のページを編集できます。モバイルの言語選択と検索はヘッダーのアイコンにあります。

```text
[map]
[map center="55.7558,37.6173" zoom=14]
[maps center="55.7558,37.6173" zoom=11]
[main-menu]
[lang]
[privacy]
[payment]
```

## ページ上でデータを編集 · 1.6.6

編集モードでは情報ブロック、[formX]、[tel] などのデータをダイアログや全画面で編集できます。表示形式の一覧には登録済みのテンプレートが表示されます。ルートフォルダーを選ぶと、セクションが最上位に移動します。 [list-pages] はセクションと子フォルダーの公開ページを一覧にします。言語メニューは外側をクリックするか Escape で閉じます。

## ページ設定 · 1.6.8

コンテンツは「編集」で作成します。URL、メニュー、公開期間は「ページ設定」で指定します。SEO にはタイトル、説明、キーワード、サイトマップへの掲載設定があります。「地図」には座標とタグ例があります。

日時を空欄にすると期間の制限はありません。サイトのタイムゾーンが適用されます。非表示のページは別途公開してください。

- `[map]` — 現在のページの地点を表示します。
- `[maps]` — 公開ページすべての地点を表示します。

コンポーネントでセットとスライドを管理します。フォルダーの写真、キャプション、リンク・フォーム・折り返し電話のボタン、表示期間を設定できます。編集モードではスライドの操作が表示されます。画像選択ではフォルダーの閲覧、アップロード、削除、GD を使った回転・サイズ変更済みのコピーの作成が可能です。Font Awesome のアイコンは名前で検索できます。


サブセクションは現在のセクション内に、同階層のセクションはその隣に、ルートセクションはサイトの最上位に作成されます。

## PHP の互換性とナビゲーション · 1.6.10

PHP の最低バージョンは 7.2 です。サイトと管理画面は PHP 8.6 に対応しています。独自のモジュールやテンプレートでは、サーバーの PHP バージョンに対応する構文を使用してください。

[bread-crumbs] の現在の項目を展開すると、メインメニューにある同じ階層の公開セクションが表示されます。設定した URL はメニュー、セクション一覧、パンくずリスト、検索結果と候補に使われます。

ごみ箱でインフォブロックの編集画面から行を削除できます。列を削除すると、その列の値もすべて消えます。変更は保存時に記録され、並べ替え後の自動保存も含まれます。

テキストを選択して揃え方を変えたり、書式を消したりできます。画像をクリックすると設定が開きます。ドラッグで移動し、角をドラッグするとサイズを変更できます。リンクは URL、メール、電話、アンカーに対応します。ボタンは URL、フォーム、折り返し電話、決済リンクを開けます。

HTML タブとビジュアルエディタータブでモードを切り替えます。SUP、SUB、段落ボタンは対応する要素を挿入します。コンポーネント名の横にコードが表示されます。挿入時に存在しないフォルダーを作成します。フォルダー名には英字、数字、ハイフン、アンダースコアを使用できます。「言語」タブから言語設定に移動できます。

## メニューの検索 · 1.6.16

## メニューの検索 · 1.6.17

[search] はデスクトップの [main-menu] のリンク横と、モバイルの [mobile-menu] 内に表示されます。基本設定で検索形式を変更できます。ページ本文の [search] が優先されます。 モバイルメニューでは検索欄が最初から表示されます。[lang] はモバイルメニュー内とデスクトップのヘッダーに言語を表示します。

`[search]` · `[lang]`

モバイルメニューの下部に、設定した連絡先と SNS が表示されます。

## サイトのサブタイトル

基本設定のサブタイトルは、ヘッダーのサイト名の下に小さく表示されます。スマートフォンではサイト名も小さく表示されます。

## 都市

「都市」で登録済みドメインを割り当て、電話番号を5件まで設定できます。電話番号欄では [tel] などのコードも使えます。[cities] は都市選択、[phones] は登録済みの番号一覧、[tel]、[tel2]–[tel5] は個別の番号を表示します。選択はブラウザーに保存され、番号は再読み込みなしで更新されます。

`[cities]` · `[phones]` · `[tel]`

## スクロール時のアニメーション

基本設定で、スクロール時のコンテンツ表示効果を選べます。既定はオフで、端末の視覚効果を減らす設定が優先されます。

## ページテンプレート

ページ作成時にテンプレートを選ぶと、編集可能な本文と SEO 項目が入力されます。独自のテンプレートは「ページテンプレート」で追加できます。地図、フォーム、購入は各コンポーネントの設定を使用します。

テンプレートの CSS と JavaScript はページの欄にコピーされます。HTML に独自のクラスを追加し CSS で設定できます。

### 共通クラス

コンテナー、レスポンシブグリッド、強調セクション、カード、価格表示。

`.page-preset` · `.page-preset-grid` · `.page-preset-hero` · `.page-preset-card` · `.page-preset-price`

レイアウトテンプレートは折りたたまれています。見出しを選ぶか「すべて展開」を押してください。もう一度押すと折りたたまれます。

バナーカルーセル全体の幅を変えるには、編集モードでバナー横のコンポーネント編集を開き、ブロック幅を選びます。

## 都市 · 電話番号 · 1.6.18

必須は都市名のみです。ドメインと電話番号は任意です。電話番号は + と国番号付き（例：+7 (900) 000-00-00）で入力します。[tel] などのコードも使用できます。

保存済みの選択、ドメインに割り当てた都市、一覧の先頭の順に使用します。都市がなければ共通の電話番号を表示します。

フォーム、折り返し電話、新規注文は都市のメールに送信されます。空欄の場合はサイト共通のメールを使用し、両方が空欄ならフォーム固有の宛先を使用します。SNS の空欄はサイト共通設定を継承します。

編集モードでテンプレートにカーソルを合わせると編集リンクが表示されます。登録済みの [php] モジュールはダイアログでソースと設定を開けます。スライド編集画面にはフォーム名とコードが表示されます。サイドバーのないページの独立した [banners width=100] は画面幅に広がります。 テンプレートエディターはサイト内のダイアログで開きます。

ファイルマネージャーは削除前に参照を確認し、空でないフォルダーをバックアップします。バナーにはタイトルとサブタイトルを設定できます。

電話番号は入力中に検証します。8 で始まるロシアの番号は +7 に変わります。送信後はフォームが非表示になり、開き直すと確認が表示されます。

+ がない番号には選択国の国番号が付きます。+ がある番号は入力した国番号を保持します。

## デザインテーマ

ファイルをテーマにコピーして保存します。未定義のファイルには標準版を使います。レイアウトの変更、新規コード、履歴とドメイン設定は有効なテーマ内に保存されます。css/theme.css と js/theme.js で追加のスタイルとスクリプトを設定できます。

`templates/themes/demo/header.php` · `templates/themes/demo/components/banners.php`

モバイルではメニュー下部に言語が表示されます。デスクトップではヘッダー下のメニューで検索の横に地球アイコンがあります。

ギャラリー、バナー、ファイル一覧は有効なテーマ内を優先します。フォルダーがなければ共通のファイルを使います。新規フォルダー、アップロード、ロゴ、favicon はテーマ内に保存されます。バックアップにテーマと設定が含まれます。

画面全体（width=page）、コンテンツ（width=content）、親要素（width=parent）の幅を選べます。height はデスクトップ、mobile-height はスマートフォン用です。auto は自然な寸法です。

`[banners width=page height=520 mobile-height=240]` · `[form1 width=parent]`

最後のパンくずにはメインメニューにない公開済みの同階層セクションも表示されます。URL が設定されている場合はそのリンクを使います。

## 概要

概要はページ一覧と検索結果に表示されます。一覧では設定された画像が優先されます。メニューではアイコンがページ名の前に表示されます。

エディターで「ページ一覧を挿入…」を選択します。現在のセクションなら `[list-pages]` を挿入し、別のセクションならフォルダーの横の「挿入」を押します。`[dir]/sample/[/dir]` は /sample/ と下位セクションの公開ページを一覧表示します。`[dir]/[/dir]` はルートから一覧表示します。


アイコン選択欄に名前を入力します。たとえば home と入力すると、house を含む名前のアイコンも表示されます。

ページのコンポーネント → [banners] → バナースライドで、そのセットのスライドを追加・編集・並べ替えできます。コンポーネント編集ではブロックの設定を開きます。

表のフィールドは上揃えです。複数行の入力欄の角をドラッグすると幅と高さを変えられます。

列幅を変えるには、見出しの右端をドラッグするか、左右の矢印キーを使います。

## セクションのページ地図 · `[maplist]`

コンポーネント一覧から「セクションのページ地図」を選ぶか、`[maplist]` を挿入します。現在のセクションと下位セクションにある座標付きの公開ページを表示します。ホームではサイト全体が対象です。吹き出しにはタイトル、アイコン、幅いっぱいの画像、概要、ページへのボタンが表示されます。連携設定で地図を有効にしてください。

`[maplist]/sample/[/maplist]` は選んだセクションの地図を表示します。`[points]/sample/[/points]` は座標があるページの一覧を表示し、行を押すとその地点の地図が行の下に開きます。`[points display=modal]/sample/[/points]` はモーダルで開きます。

SEO タブで sitemap.xml への掲載を設定できます。ページ設定で「メニューの枝を展開」を有効にすると、メニュー表示対象の下位ページがマウスオーバーまたはスマートフォンで矢印をタップすると開きます。

座標のあるページに `[route]` を挿入します。連携設定で選んだ地図サービスで経路を開きます。provider=yandex または provider=google で明示的に選択できます。地図を無効にした場合は Yandex を使います。
