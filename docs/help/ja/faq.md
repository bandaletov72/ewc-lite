# 管理者向けよくある質問

## インストールとログイン

### Web サイトを起動して管理パネルを開くにはどうすればよいですか?

ローカルで起動するには、プロジェクト ディレクトリでコマンド php -S 127.0.0.1:8000 router.php を実行し、http://127.0.0.1:8000/admin/. を開きます。ホスティング上で、まず php admin/setup.php を実行し、ウィザードの最初のステップで受信したワンタイム コードを /admin/. に入力します。

### 最初の起動時に何を設定できますか?

まずユーザー名とパスワードを作成します。 2 番目のステップでは、サイト名、デフォルトのメタディスクリプション、フッターテキスト、パレット、テーマモードを設定します。 PHP GD をお持ちの場合は、ロゴをすぐにダウンロードして、そこからファビコンを作成できます。 2 番目の手順をスキップすることも、次回ログイン時に続行することもできます。

## ページとメニュー

### ページの作成方法と入力するアドレスは何ですか?

「ページ」→「新しいページ」に移動します。 /Services-1/Repair/ または /Services-1/Price_2.php などのアドレスを入力し、タイトルを入力して保存します。フォルダー アドレスの場合、エンジン自体がディレクトリと index.php を作成します。名前には、A ～ Z、a ～ z、0 ～ 9、ハイフン、アンダースコアを使用できます。メイン ページはルートに予約されており、サービス ディレクトリでのページの作成は閉じられます。

### 「メニュー内」チェックボックスと「非表示」ボタンの違いは何ですか?

「メニュー内」ボックスのチェックを外すと、直接アドレスへのアクセスを維持したまま、通常のメニューからリンクが削除されます。フォルダー アドレスのあるページでは、チェックボックスはサブページの項目も制御します。 「非表示」ボタンをクリックすると、リンクが削除され、再度公開されるまでページのパブリック アドレスが閉じられます。

### ページの順序を変更したり、フォルダー全体を移動したりするにはどうすればよいですか?

⠿アイコンをドラッグすると、同じ階層内のページを並べ替えることができます。 1 ページを移動するには、エディターで「ページの移動」を開きます。フォルダーを添付のページやファイルとともに転送するには、フォルダー名の横にある ↪ をクリックします。転送後、古いアドレスを指している手動リンクと [include] コードを確認してください。

### ページの変更がすぐに表示されないのはなぜですか?

エディターで「保存」をクリックします。次に、「ページを開く」または「移動」リンクを使用します。リンクが消えている場合はページが公開されているか確認してください。サブドメインの変更については、アドレス バーでドメインを確認してください。

## デザインとサブドメイン

### タイトル、フッター、ロゴ、ファビコンはどこで変更できますか?

「設定」→「一般」を開きます。フッター テキスト フィールドは、今年の [year] をサポートします。 「ロゴとサイトアイコン」ブロックでは、画像をアップロードするか、「ロゴからファビコンを作成」をクリックします。読み込みと変換には PHP GD が必要です。

### テーマやフォントを変更してから古いものに戻すにはどうすればよいですか?

「設定」→「テーマと色」で、モードとパレットを選択します。現在のパレットをリストに保存して、後で使用できるようにします。 「デフォルトとして使用」ボタンは、「テーマをデフォルトに戻す」コマンドのパレットを記憶します。フォントは「ライブラリとフォント」セクションで変更できます。リスト内の名前とサンプルは、適切なフォントで表示されます。値「System」は通常のフォントを返します。

### ヘッダーを変更する場所とカウンター、CSS、または JavaScript を挿入する場所はどこですか?

共通ブロックのヘッダー、モバイルメニュー、メニュー、フッターは「デザインテンプレート」タブで編集します。同じ場所で、「サービスヘッダー」は HTML を head または body 終了タグの前に挿入します。通常の CSS と JavaScript の場合は、別の「CSS と JS」タブがあります。 1 ページのコードがエディターに追加されます。

### サブドメインに異なる電話番号とヘッダーを設定するにはどうすればよいですか?

「ドメイン」セクションにサブドメインを追加します。次に、必要なドメインを選択して、[サブテンプレート] セクションで別のサブテンプレート値を設定します。ドメインの横にある「テンプレート」ボタンを使用して、ヘッダーとその他のブロックを変更します。ドメイン バージョンは一般バージョンより優先されます。 DNS および Web サーバーは、サブドメインがそのサイトのディレクトリを指すようにする必要があります。

### ソーシャル ネットワークへのリンクとその隣のキャプションはどこで変更できますか?

「設定→連絡先とソーシャルネットワーク」を開きます。住所、署名、電話番号を記入します。コード [soc-icons] は、構成されているすべてのネットワークのアイコンを表示します。単一リンクの場合は、たとえば [tg] または [vk] を使用します。

## フォームと申請書

### ページにフォームを追加するにはどうすればよいですか?

フォームを開き、フィールド、必須、最大長、ボタンのテキストを設定します。フォームを保存し、そのコード ([form1] など) をページの HTML に貼り付けます。

### 電子メールによる通知を受け取っていない場合、どこでアプリケーションを確認できますか?

メッセージを開きます。フォームが正常に送信された後、アプリケーションはそこに保存されます。通知については、フォーム メール テンプレートの [宛先] フィールドのアドレスと、ホスティング上の mail() 関数の機能を確認してください。

### レターを設定してコピーを送信するにはどうすればよいですか?

目的のフォームを開き、「メール テンプレート」ブロックを見つけます。 「To」フィールドと「Copies (Cc)」フィールドにアドレスをカンマで区切って入力します。件名と本文では、中括弧で囲んだフィールド キーを使用します (例: Hello {name}!)。テキストの下のボタンは、選択した変数を挿入します。空白の件名またはテキストは標準の通知を使用します。

### フォームがメッセージを拒否したり、「私はロボットではありません」と尋ねたりしたのはなぜですか?

必須フィールド、長さ、電話番号と電子メールの形式を確認してください。自由入力フィールドでは、HTML や Web サイトのアドレスを含まないプレーン テキストが使用されます。禁止されている単語と IP のリストは、「スパム対策」セクションにあります。 [Use CAPTCHA] チェックボックスには、目的のドメインのサイト キーと Google reCAPTCHA v2 秘密キーが必要です。

### コールバックリクエストはどこで確認できますか?

「コールバック」セクション。コンポーネントはコード [callback] または [callback=Вызвать мастера] でページに追加されます。 「いいえ」プロバイダーを使用すると、アプリケーションは管理パネルに保存されます。電話が設定されている場合、手動または自動送信が利用可能です。

## 情報ブロックとコンポーネント

### 情報ブロックを作成してページに表示するにはどうすればよいですか?

「情報ブロック」セクションで「新しい情報ブロック」をクリックし、列を設定して行を追加します。情報ブロック名と列キーには、スペースを含まない A ～ Z、a ～ z、0 ～ 9、ハイフン、またはアンダースコアを使用します。インフォブロックエディターから埋め込みコードを保存してコピーします。電話機のリストについては、電話機テンプレートを使用します。

### 情報ブロックのすべての行をコピーまたは置換するにはどうすればよいですか?

情報ブロックを開き、「テキストとして編集」をクリックします。 CSV は | を使用します。デリミタ。最初の 3 行には、列のキー、名前、タイプが含まれています。次にデータです。フィールドは、区切り文字、引用符、または二重引用符で囲まれた改行と内部二重引用符で囲みます。

### ギャラリーまたはファイルリストが空かどうかを確認するにはどうすればよいですか?

コンポーネント コード内のパスとサーバー上のフォルダーを確認してください。たとえば、[fotos]/images/myfotos/[/fotos] では、images/myfotos/ または templates/images/myfotos/. の写真が使用されます。[files] の場合は、ファイル拡張子を確認してください。サポートされている拡張機能とパラメーターのリストは、コンポーネントのヘルプにあります。

### ?ajax=1 を指定したリクエストが 403 を返すのはなぜですか?

ページ フラグメントには、同じサイト上の有効なパブリック セッションとトークンが必要です。サイト内で読み込むには、トークンを転送する window.siteFetchContent() を使用します。通常の遷移では、ajax パラメータを指定せずにページ アドレスを開きます。

## アップデートとバックアップ

### インストールされているサイトのエンジンを更新するにはどうすればよいですか?

「設定」→「アップデート」で、インストールされているバージョンと GitHub の最新バージョンを比較し、「アップデート エンジン」をクリックします。 GitHub が利用できない場合、管理パネルには最後にチェックされたバージョンが表示されます。手動で更新するには、php-site-update.zip アーカイブを PHP コマンド update.php に渡します。更新パッケージは、エンジン ファイルと標準テンプレートを置き換えます。 PHP テンプレートを templates/local/. に保存します

### アップグレードまたは移行する前に何をコピーすればよいですか?

サイト ディレクトリ全体と隠しファイルのコピーを作成します。ページはルートとそのディレクトリにあり、情報ブロックは data/ に、設定ファイルとアカウント ファイルは admin/. にあります。テンプレート、アップロードした画像、メッセージ、リクエストも保存します。コピーには構成の秘密が含まれるため、パブリック ディレクトリの外に保管してください。

### 管理パネルで変更を保存できない場合は何を確認すればよいですか?

まず、フォームの横にあるメッセージをお読みください。変更内容が競合する場合は、編集内容をコピーしてエディターを再度開きます。書き込みエラーがある場合は、ホスティングに、目的のフォルダーとファイル admin/write-lock.php. 内の PHP プロセスの書き込み権限を確認するように依頼します。更新に失敗した場合は、サーバーの GitHub へのアクセスと、PHP Zip および OpenSSL の可用性を確認します。
