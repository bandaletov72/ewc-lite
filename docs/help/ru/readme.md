# Eurowebcart CMS Light

Автор — Бандалетов Павел. [Исходный проект и обновления](https://github.com/bandaletov72/php-site-updates).

Минимальная версия PHP — 7.2. Сайт и админка поддерживают PHP 8.6. Для своих PHP-модулей и шаблонов используйте синтаксис версии, установленной на сервере.

[FAQ по админке](faq.md) доступен также во вкладке «Помощь».

[Справка по актуальной версии на десяти языках](../README.md) описывает поиск, правку на сайте, локализацию и обслуживание. [Admin FAQ in English](../en/faq.md).

Для планового обслуживания добавьте команду `php update.php --scheduled` в планировщик хостинга с периодом 15 минут. В разделе «Обслуживание» можно независимо включить переиндексацию и установить интервал проверки подписанных обновлений GitHub.

## Локальный запуск

Перейдите в каталог `php-site` и запустите встроенный сервер PHP.

```sh
php -S 127.0.0.1:8000 router.php
```

Сайт откроется по адресу `http://127.0.0.1:8000/`, админка находится по адресу `http://127.0.0.1:8000/admin/`.

## Установка и первый вход

На локальном сервере откройте `/admin/` и создайте учётную запись. На втором шаге задайте название сайта, метаописание, текст подвала, палитру и режим темы. Логотип можно загрузить сразу при наличии PHP GD. Мастер создаст из него favicon. Нажмите «Сохранить и открыть админку» или продолжите с текущими настройками. Если выйти из мастера, он продолжится при следующем входе.

На хостинге выполните из каталога проекта `php admin/setup.php` и введите одноразовый код на первом шаге мастера. Код погашается при создании учётной записи. Повторный запуск команды до установки заменяет предыдущий код. Установка обновления сохраняет прежнюю учётную запись и настройки. Если версия до обновления использовала `SITE_ADMIN_PASSWORD_HASH`, вход сохраняется с логином `admin` и прежним паролем.

Для работы приложения нужны PHP-сессии и права записи в `admin/`, `admin/write-lock.php`, `admin/inbox/`, `data/` и каталоги редактируемых страниц. Чтобы создавать страницы и каталоги в корне, дайте процессу PHP право записи в корень проекта. Используйте веб-сервер с HTTPS, обработкой `.php` и `index.php` в списке индексных файлов. Отключите листинг каталогов. При HTTPS за обратным прокси передайте PHP признак `HTTPS` через доверенную конфигурацию сервера.

## Страницы и меню

В админке главная указана как `/`, остальные страницы в папках — как `/contacts/`. Для создания вложенной страницы укажите, например, `/Services-1/Repair/`. Админка сама создаст каталоги и `index.php`. Для отдельного файла укажите адрес вида `/Services-1/About_2.php`. В именах файлов и папок разрешены `A–Z`, `a–z`, `0–9`, дефис и подчёркивание. Имена вводятся без пробелов. В корне разрешена только главная страница. Служебные каталоги, включая `data`, `admin`, `templates`, `css` и `js`, зарезервированы.

В списке страниц папки можно раскрыть. Галочка «В меню», скрытие, публикация и удаление сохраняются через AJAX. Скрытие, публикация и удаление требуют подтверждения. Перетаскивайте за значок ⠿ для сортировки соседних страниц. Скрытая страница перестаёт открываться и исчезает из меню до публикации.

В редакторе страницы откройте блок «Переместить страницу» и укажите папку назначения. Например, при переносе `/contacts/` в `/company/` новый адрес будет `/company/contacts/`. Вложенные страницы остаются по прежним адресам. Обновите собственные ссылки и коды `[include]`, ведущие на перенесённую страницу.

Перетащите за значок ⠿, чтобы изменить порядок на одном уровне. Для одной страницы откройте «Переместить страницу» в её настройках. Значок рядом с папкой открывает выбор родительского раздела. Выберите другой раздел или корневую папку и нажмите «Переместить папку». Папка переносится со всеми вложенными страницами и файлами. Проверьте ссылки и [include], указывавшие на старые адреса.

Контент можно править в текстовом редакторе и добавлять через FTP или SFTP. Файл должен быть в UTF-8 без BOM. Сохраните служебный PHP-блок до строки `__halt_compiler();`. В файле новой страницы вставьте этот блок из примера нужной глубины и проверьте относительный путь к корневому `index.php`. Следом идут заголовки, одна пустая строка и HTML-фрагмент страницы.

```php
<?php
$pageFile = __FILE__;
require __DIR__ . '/../index.php';
__halt_compiler();
Title: Контакты
Heading: Как с нами связаться
Description: Контактная информация
Menu: Контакты
MenuVisible: 1
Order: 20

<p>Укажите здесь контактную информацию.</p>
```

Обязателен `Title`. Пустой `Heading` берётся из `Title`. `Description` заполняет метаописание страницы. `MenuVisible: 1` показывает ссылку в меню, `MenuVisible: 0` скрывает её. Для `index.php` папки отключение галочки также скрывает из меню все вложенные страницы. Если `MenuVisible` отсутствует, галочка наследует прежнее правило и считается включённой при заполненном `Menu`. При включённой галочке пустое поле `Menu` заменяется заголовком `Title`. `Order` задаёт последовательность в пределах одного уровня и по умолчанию равен 100.

Вкладка «CSS и JS» хранит общий CSS и JavaScript для публичных страниц. В редакторе страницы есть отдельный блок «CSS и JavaScript страницы». Код страницы загружается после общего. Указывайте только содержимое файлов, без тегов `<style>` и `<script>`. Допустимый размер каждого поля — до 64 КиБ. Для ссылок на изображения из CSS можно использовать пути от корня сайта. Вкладка «Помощь» содержит примеры доступных шаблонов и компонентов.

В разделе «Шаблоны оформления» можно просмотреть исходники `header.php`, `footer.php`, `menu.php` и `mobile-menu.php` и задать для каждого общий HTML. «Служебные заголовки» вставляют общие метатеги, коды счётчиков и скрипты в `<head>` или перед `</body>`. На каждой опубликованной полной странице `rel="canonical"` формируется из её обычного адреса без параметров запроса.

## Настройки, подшаблоны и домены

В разделе «Настройки» задаются название сайта, метаописание по умолчанию, текст подвала и переменные. В тексте подвала `[year]` автоматически выводит текущий год. Переменные записываются по одной на строку, например `[city] = Москва` и `[spb] = Санкт-Петербург`. Чтобы вывести значение в названии сайта, содержимом страницы, заголовке или подвале, вставьте `[city]`. В PHP-шаблонах можно использовать `site_escape($settings['variables']['city'] ?? '')`.

Системные подстановки включают `[year]`, `[month]`, `[day]`, `[time]` (часы и минуты), `[dmY]` и `[date]` (дата ДД.ММ.ГГГГ), `[datetime]` (дата и время). Используется часовой пояс PHP.

В «Основные → Логотипы и иконки сайта» можно загрузить PNG, JPEG, GIF или WebP. Загрузки обрабатывает PHP GD. Кнопка создания favicon делает прозрачный PNG 64 × 64 из выбранного или сохранённого логотипа. Изображения хранятся в `templates/images/branding/` и `templates/icons/branding/`.

«Подшаблоны» хранит имя, описание и значение каждого кода. Для телефона создайте `[tel]`. Чтобы задать заголовок вкладки через подшаблон, создайте `[title]` и укажите его в поле `Title` страницы. После заголовка вкладки выводится название сайта. Подстановки работают в тексте страницы и текстовых метаданных. Для ссылки вставьте весь тег `<a>` как значение подшаблона и разместите код в тексте между тегами. В метаданных HTML из значения преобразуется в текст.

Добавляйте поддомены в разделе «Домены». В одноимённой админке поддомена выберите «Текущий домен», либо откройте нужный домен из общего списка. Локальное значение имеет приоритет над общим. Публичная страница выбирает значения по домену в своём адресе, а внутренние ссылки сохраняют его. Для подключения поддомена настройте DNS и веб-сервер на хостинге, чтобы домен обслуживал тот же каталог проекта.

Кнопка «Шаблоны» рядом с доменом открывает редактор `[header]`, `[mobile-menu]`, `[menu]` и `[footer]`. Для каждого блока можно задать свой HTML или использовать общую версию. Общие шаблоны настраиваются в том же разделе.

## Компоненты в HTML

| Код | Результат |
| --- | --- |
| `[gal]/images/myfotos/[/gal]` | Карусель фотографий с плавной прокруткой, стрелками и свайпом |
| `[fotos]/images/myfotos/[/fotos]` | Фотогалерея со ссылками на оригиналы |
| `[files]/files/myfiles[/files]` | Список файлов с иконками по расширению |
| `[include]/contacts/[/include]` | HTML другой страницы с её подшаблонами и компонентами |
| `[form1]` | Форма, настроенная в разделе «Формы» |
| `[callback=Вызвать мастера]` | Кнопка и форма запроса обратного звонка |
| `[iblock=table]/data/myiblock.txt[iblock]` | Таблица инфоблока |
| `[iblock=phones]/data/myiblock.txt[iblock]` | Список телефонов инфоблока |
| `[phones]`, `[contacts]` | Телефоны или весь настроенный блок контактов |
| `[soc-icons]` | Иконки всех соцсетей с настроенными ссылками |
| `[tg]`, `[vk]`, `[whatsapp]`, `[youtube]`, `[instagram]`, `[max]` | Ссылка на соцсеть с иконкой и подписью |

Поместите фотографии в `templates/images/myfotos/` или `images/myfotos/`. Список файлов показывает `zip`, `pdf`, `xls`, `xlsx`, `doc`, `docx`, `png`, `gif`, `jpg`, `jpeg`, `mp4`, `mov` и `mp3`. Для `[include]` поддерживается до десяти уровней вложенности. Повтор страницы в текущей цепочке пропускается. Коды компонентов размещайте в теле страницы, отдельной строкой между HTML-блоками.

В «Настройки → Контакты и соцсети» задайте ссылки, номера, подписи и заголовок блока. В «Настройки → Тема и цвета» доступны системный, тёмный и светлый режимы и отдельные палитры. В «Настройки → Компоненты» задаются общие параметры карусели и фотогалереи. Под настройками есть примеры вставки с выбранными значениями. Параметры в коде страницы переопределяют общие значения.

В «Тема и цвета» можно сохранить копию выбранных настроек под своим названием или оставить автоматическое название. «Применить» меняет текущее оформление. «Использовать по умолчанию» применяет сохранённую тему и запоминает её для команды «Вернуть тему по умолчанию». Удаление из списка сохраняет текущее оформление сайта.

```text
[gal arrows=off numbers=off effect=fade fit=cover]/images/myfotos/[/gal]
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off]/images/myfotos/[/fotos]
[files icons=on size=on order=desc download=on]/files/myfiles/[/files]
```

У `[fotos]` число колонок можно задать вручную для широкого экрана или оставить автоматический подбор. На узких экранах сетка сокращает число колонок. Доступны пропорции 4:3, 1:1, 16:9 и исходные, режимы `cover` и `contain`, подписи из имён файлов и ссылки на оригиналы.

## Формы и антиспам

В разделе «Формы» можно редактировать `[form1]`, создавать `[form2]` и следующие формы. Для формы задаются адрес получателя, подпись кнопки и поля. У поля можно указать максимальную длину. Пустое значение использует предел по умолчанию для типа поля. При вводе `89031234567` поле телефона форматирует его как `+7(903)123-45-67`. Сервер проверяет длину, тип, допустимые варианты выбора и ограничивает суммарный размер запроса. Поля свободного ввода принимают обычный текст. HTML в сообщениях экранируется при выводе, а HTML-теги в новых сообщениях отклоняются.

Галочка «Использовать CAPTCHA» включает Google reCAPTCHA v2 с проверкой «Я не робот» для выбранной формы. Введите ключ сайта и секретный ключ для домена. Секрет хранится в защищённом файле настроек и используется только для серверной проверки. [Документация по серверной проверке](https://developers.google.com/recaptcha/docs/verify).

Формы отправляются через AJAX. Заявки сохраняются в разделе «Сообщения». Если указан получатель, для уведомлений используется `mail()`, которому нужна настроенная почта на хостинге. В разделе «Антиспам» можно редактировать списки слов, выражений, IPv4- и IPv6-адресов. Ссылки блокируются на сервере. Адрес отправителя берётся из `REMOTE_ADDR`. За обратным прокси настройте восстановление исходного IP в веб-сервере для доверенных прокси.

Для каждой формы есть «Почтовый шаблон» с полями «Кому», «Копии (Cc)», «Тема письма» и «Текст письма». Адреса указываются через запятую. Копии отправляются, если указан хотя бы один основной получатель. Ключи полей вставляются в тему и текст в фигурных скобках, например `Привет {name}!`. Пустое значение поля подставляется как пустая строка, неизвестный ключ остаётся в письме. При пустой теме или тексте используется соответствующая часть стандартного письма.

## Обратные звонки

Вставьте `[callback]` или `[callback=Вызвать мастера]` в HTML страницы. Кнопка откроет форму с телефоном. Запросы сохраняются в разделе «Обратные звонки». Там же задаются подписи кнопок и режим передачи заявки в телефонию. По умолчанию выбран провайдер «Нет», и заявки только сохраняются. Телефонию можно включить для ручной отправки из списка или для отправки сразу после приёма номера.

- **Zadarma.** Задайте номер, SIP или добавочный оператора в админке, а ключи передайте PHP через `SITE_ZADARMA_KEY` и `SITE_ZADARMA_SECRET`. [Документация Zadarma API](https://zadarma.com/en/support/api/)
- **HTTP API.** Задайте `SITE_CALLBACK_WEBHOOK_URL` с HTTPS-адресом и при необходимости `SITE_CALLBACK_WEBHOOK_TOKEN`. Сайт отправляет POST с JSON-полями `id`, `phone`, `host`, `page`, `requested_at` и заголовком `Idempotency-Key`. Токен передаётся как Bearer. Код ответа 2xx переводит заявку в статус «Принята телефонией».

Добавьте процессу PHP право записи в `admin/callbacks/`. Заявки используют настройки антиспама форм. Повтор на тот же номер ограничен одной минутой, по IP принимается до трёх заявок за 15 минут.

## Инфоблоки и закрытая папка данных

В разделе «Инфоблоки» можно создавать наборы данных, редактировать и перетаскивать строки. В имени инфоблока и ключах столбцов разрешены `A–Z`, `a–z`, `0–9`, дефис и подчёркивание. Имена и ключи вводятся без пробелов. Названия столбцов и значения ячеек можно писать по-русски. Контролы соответствуют типам столбцов, а сохранение идёт через AJAX. Кнопка ☰ «Править как текст» переключает весь инфоблок на CSV с разделителем `|` и кнопкой копирования. Первые три строки содержат ключи, названия и типы столбцов. Затем идут строки данных. Дата в CSV имеет вид `ГГГГ-ММ-ДД`, «да/нет» хранится как `1` или `0`.

```text
name|phone|is_open
Название|Телефон|Открыто
text|tel|bool
Справочная|+7(903)123-45-67|1
```

Шаблон `phones` использует столбцы типа `tel` и текстовый столбец с названием. Свой шаблон можно разместить в `templates/local/iblock/имя.php`, где доступны `$block['columns']` и `$block['rows']`.

Путь `/data/myiblock.txt` внутри кода соответствует файлу `data/myiblock.txt.php`. Это текст UTF‑8 с PHP-заглушкой, которая возвращает 404 при прямом вызове. `router.php` закрывает всю папку при локальном запуске. В `data/` есть правила для Apache и IIS. Для Apache разрешите применение `data/.htaccess`. На Nginx настройте закрытие папки в конфигурации сайта, с учётом префикса при установке в подкаталог.

```nginx
location = /data { return 404; }
location ^~ /data/ { return 404; }
```

После установки проверьте, что прямой запрос к `/data/` и файлу инфоблока получает 403 или 404.

## Загрузка HTML-фрагментов

Обычный адрес `/contacts/` открывает полную страницу. Запрос `?ajax=1` возвращает `<main>` с H1 и обработанным содержимым при наличии ключа сессии в заголовке `X-Site-Fragment`. Фрагменты привязаны к текущему origin. Страницы и фрагменты с ключами выдаются без кэширования.

В JavaScript на странице сайта используйте встроенную функцию.

```js
const html = await window.siteFetchContent('/contacts/');
document.getElementById('content').outerHTML = html;
```

При установке в подкаталог передавайте URL с префиксом сайта. Скрипт и стили берутся со страницы, которая вставляет фрагмент. Публичные страницы остаются доступны по обычным адресам.

## Шаблоны и ресурсы

В «Настройки → Библиотеки и шрифты» по отдельности подключаются jQuery, Bootstrap, Font Awesome, Material UI, Alpine.js, htmx, Chart.js и GLightbox. Font Awesome хранится локально. Остальные библиотеки загружаются браузером с CDN при включении. Material UI доступен в скриптах `type="module"` через `import { Button } from '@mui/material'`. Для иконок подойдёт `[fa-icon=house]` или обычная разметка `<i class="fa-solid fa-house"></i>`.

Доступны 10 шрифтов Google с кириллицей. Выбор заменяет системный шрифт сайта. Значение «Системный» возвращает прежнее оформление. В «Настройки → Тема и цвета → Сохранённые темы» есть пять готовых палитр со светлым и тёмным вариантами.

| Путь | Назначение |
| --- | --- |
| `index.php` | Главная страница и общая точка входа |
| `contacts/index.php` | Пример страницы в отдельном каталоге |
| `admin/` | Вход и редактор страниц |

## Обновление движка

Полный архив нужен для новой установки. Для работающего сайта используйте `php-site-update.zip`. В нём только движок и штатные шаблоны. Сохранённые страницы, инфоблоки, настройки, пароли, сообщения и пользовательские расширения в архив не входят.

Нажмите «Обновить движок» в «Настройки → Обновления» или запустите ту же проверку из планировщика хостинга.

```sh
php update.php --github
```

Источник по умолчанию — `bandaletov72/php-site-updates`. Для собственного репозитория задайте `SITE_GITHUB_REPO`. В публичном репозитории токен не требуется. Для закрытого репозитория передайте процессу PHP переменную `SITE_GITHUB_TOKEN` с правом чтения содержимого. На сервере нужны PHP-расширения Zip и OpenSSL и возможность HTTPS-запросов к GitHub.

Для ручной установки используйте ZIP.

```sh
php update.php /path/to/php-site-update.zip
```

На старой версии без `update.php` сначала распакуйте пакет поверх проекта, сохранив существующие `.htaccess` и файлы из `maintenance/`, если они есть. Если вы правили штатные шаблоны, перенесите правки в `templates/local/` до обновления. Установщик проверяет список и контрольные суммы файлов, а для GitHub также проверяет подпись доверенным открытым ключом `maintenance/release-public.pem`.

Для следующего выпуска измените версию в `app/version.php` и соберите пакет через `php update.php --build php-site-update.zip`. Подпишите ZIP своим закрытым RSA-ключом с SHA‑256, храните закрытый ключ отдельно от сайта. Затем разместите ZIP и `.sig` в GitHub Release с тегом `vX.Y.Z` или в `updates/vX.Y.Z/` и обновите `updates/latest.json` до `{"version":"X.Y.Z"}`.

## Расширения

Модули движка можно добавлять в `app/extensions/` вместе с обновлениями. Собственные модули храните в `extensions/`, вне пакета обновления. PHP-файл возвращает массив определений. У одиночного компонента `kind` равен `single`, у компонента с аргументом — `wrapped`. Движок распознаёт новые коды на существующих страницах. Компонент может объявить меню параметров в `settings`, задав для каждого параметра `label`, `default` и массив `options`. Значения поступают в `$context['settings']`.

```php
<?php
if (!defined('SITE_ROOT')) {
    http_response_code(404);
    exit;
}

return ['notice' => [
    'kind' => 'wrapped',
    'render' => static function (string $text, array $context): string {
        return '<strong>' . site_escape($text) . '</strong>';
    },
]];
```

Компонент из примера вставляется как `[notice]Важное сообщение[/notice]`.
