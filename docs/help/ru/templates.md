# Шаблоны и компоненты

## Шаблоны оформления

### Шапка, меню и подвал

Полная страница подключает эти блоки автоматически. Общие версии редактируются в «Шаблоны оформления», а для отдельного домена — в разделе «Домены».

```text
[header]
[mobile-menu]
[menu]
[footer]
```

### Вставка другой страницы

Вставляет содержимое опубликованной страницы. Максимальная вложенность — десять уровней. Повтор страницы в одной цепочке пропускается.

```text
[include]/contacts/[/include]
```

### Ссылки в меню

Галочка «Показывать в меню» добавляет ссылку в штатные меню. При пустом названии берётся заголовок. Если отключить галочку у страницы папки, её вложенные страницы тоже исчезнут из меню.

```text
MenuVisible: 1
Menu: Контакты
```

### CSS и JavaScript

Общий код редактируется во вкладке «CSS и JS». Код страницы редактируется в блоке «CSS и JavaScript страницы» и подключается после общего. В поля вставьте содержимое CSS и JavaScript.

```text
.page-content { max-width: 72rem; }
```

```text
document.documentElement.classList.add('custom-script-loaded');
```

### Служебные заголовки

В разделе «Шаблоны оформления → Служебные заголовки» можно вставить общие метатеги и коды счётчиков внутрь head или перед закрывающим body. Canonical добавляется автоматически на полных страницах.

```text
<meta name="theme-color" content="#065f63">
```

### Иконки Font Awesome

Подключён Font Awesome Free 7.3.1. Короткий код работает в контенте и HTML блоков оформления. Доступны стили solid, regular и brands. Добавьте рядом с иконкой текст, если она обозначает действие.

```text
[fa-icon=house] [fa-icon=regular:envelope] [fa-icon=brands:github]
```

```text
<i class="fa-icon fa-solid fa-phone" aria-hidden="true"></i> Связаться
```

### Библиотеки и шрифты

Подключения управляются в «Настройки → Библиотеки и шрифты». Для Material UI используйте модульный JavaScript. Выбранный шрифт Google заменяет системный шрифт сайта.

```text
<script type="module">import { Button } from "@mui/material";</script>
```

```text
GLightbox({selector: ".glightbox"});
```

## Переменные, подшаблоны и дата

### Переменные сайта

Добавьте записи в «Настройки → Основные». Вставляйте ключ в текст, заголовок, название сайта или подвал.

```text
[city] = Москва
[spb] = Санкт-Петербург
```

```text
Сервис в городе [city]
```

### Подшаблоны

В разделе «Подшаблоны» задайте имя, описание и значение. Для домена сначала берётся его значение, затем общее. Подшаблон может содержать HTML. В заголовках разметка убирается.

```text
[tel]
```

```text
[title]
```

### Дата и время

Часовой пояс берётся из PHP. [year] — год, [month] — месяц, [day] — день месяца, [time] — часы и минуты, [dmY] и [date] — дата ДД.ММ.ГГГГ, [datetime] — дата и время.

```text
© [year] [city]
Дата [dmY], время [time]
```

### Название CMS и автор

Код [author] выводит Eurowebcart CMS Light, имя автора Бандалетов Павел и ссылку на GitHub. В стандартном подвале подпись появляется автоматически. В собственный HTML подвала вставьте код в нужное место.

```text
[author]
```

### Шаблон главной и политика

Код [page-content] вставляет текст главной в шаблон [home]. В «Страницах» откройте /privacy/, чтобы изменить текст политики. Подстановки [site-name] и [site-url] берутся из основных настроек.

```text
[page-content]
```

```text
[site-name] · [site-url]
```

### Ссылки и настройки в подвале

Код [privacy] выводит ссылку на /privacy/, [top] прокручивает страницу вверх, [cookies] открывает настройки согласия.

```text
[privacy]
[cookies]
[top]
```

### Общие функции PHP

В разделе «Шаблоны оформления → Функции» отредактируйте functions.php. В PHP-коде translit() или ew_call() вызывает зарегистрированную функцию. Короткий код [func=translit] доступен в содержимом и в поле «Свой HTML».

```text
[func=translit value="Москва и München"]
```

```text
$var = translit("Москва");
```

```text
echo ew_escape(ew_call("translit", "München"));
```

## Карусель, фотогалерея и файлы

### Карусель [gal]

Показывает фотографии из папки. arrows и numbers принимают on или off, effect — slide, fade или none, fit — contain или cover.

```text
[gal]/images/myfotos/[/gal]
```

```text
[gal arrows=on numbers=off effect=fade fit=cover width=50]/images/myfotos/[/gal]
```

### Фотогалерея [fotos]

Показывает адаптивную сетку. columns — auto или число от 1 до 6, ratio — 4x3, 1x1, 16x9 или original, fit — cover или contain. captions и links включаются через on или off.

```text
[fotos]/images/myfotos/[/fotos]
```

```text
[fotos columns=4 ratio=1x1 fit=cover captions=on links=off width=50%]/images/myfotos/[/fotos]
```

### Список файлов [files]

Выводит поддерживаемые файлы. icons, size и download принимают on или off, order — asc или desc. Разрешены zip, pdf, xls, xlsx, doc, docx, png, gif, jpg, jpeg, mp4, mov и mp3.

```text
[files]/files/myfiles/[/files]
```

```text
[files icons=on size=on order=desc download=on width=33]/files/myfiles/[/files]
```

## Формы и обратный звонок

### Форма [formN]

В разделе «Формы» настройте поля, их максимальную длину, текст кнопки и получателя. «Использовать CAPTCHA» включает виджет Google reCAPTCHA v2 с проверкой ответа на сервере. Заявки отправляются через AJAX и видны в разделе «Сообщения».

```text
[form1]
[form2]
```

### Почтовый шаблон формы

Тема и текст хранятся отдельно для каждой формы. В почтовом шаблоне вставляйте ключи полей в фигурных скобках. Списки получателей и копий разделяются запятыми.

```text
Привет {name}!
Телефон: {phone}
Сообщение: {message}
```

### Обратный звонок [callback]

Открывает форму с телефоном. Заявка сохраняется в разделе «Обратные звонки». Подпись кнопки можно задать в коде. С провайдером «Нет» отправка в телефонию выключена.

```text
[callback]
[callback=Вызвать мастера]
```

## Инфоблоки

### Таблица и список телефонов

Создайте набор данных в разделе «Инфоблоки». В имени инфоблока и ключах столбцов разрешены A–Z, a–z, 0–9, дефис и подчёркивание. Пробелы запрещены. Шаблон table показывает таблицу, phones выводит телефонные столбцы со ссылками для звонка. Поддерживаются закрывающие коды [iblock] и [/iblock].

```text
[iblock=table]/data/myiblock.txt[iblock]
[iblock=phones]/data/myiblock.txt[/iblock]
```

## Контакты и соцсети

### Общий блок и иконки

[contacts] выводит блок контактов, [phones] показывает телефоны, [soc-icons] собирает иконки всех соцсетей с настроенными ссылками.

```text
[contacts]
[phones]
[soc-icons]
```

### Отдельные соцсети

Каждый код выводит ссылку своей соцсети. Адреса и подписи задаются в «Настройки → Контакты и соцсети».

```text
[tg] [vk] [whatsapp] [youtube] [instagram] [max]
```

```text
[wa] [yt] [ig]
```

## Кнопки в шапке админки · 1.6.4

Глобус открывает сайт, стрелка завершает сеанс администратора. На телефоне видны только иконки. Подсказки появляются при наведении или фокусе с клавиатуры.

«Содержимое», «Формы и заявки» и «Сайт и сервисы» открываются сразу. Под шапкой выбранного раздела доступны его вкладки.

Вставьте [bread-crumbs] или [search] в HTML главной страницы (index.php) или шаблона. Блок появится в указанном месте один раз. Галочка хлебных крошек и режим поиска действуют и для вставленных тегов. [privacy] выводит ссылку на /privacy/. Текст политики редактируется в разделе «Страницы».

```text
[bread-crumbs]
[search]
[privacy]
```

## Служебные файлы, карты и шаблоны · 1.6.5

Откройте «Обслуживание → Служебные файлы». Здесь редактируются .htaccess, robots.txt и sitemap.xml. Генерация sitemap.xml берёт опубликованные страницы с галочкой «Показывать в карте сайта». Для .htaccess доступна предыдущая версия.

Заполните широту и долготу на странице. [map] покажет её точку, [maps] соберёт точки опубликованных страниц. В обоих тегах center задаёт центр, а zoom — масштаб. Интерактивная карта использует провайдера из «Интеграций».

Под шапкой выводится [main-menu] с выпадающими подразделами. В «Шаблонах оформления» создайте свой шаблон и настройте видимость на мобильных и компьютерах. В «Подшаблонах» кнопка «+ Добавить домен» ведёт к форме добавления. Для ссылки на политику используйте [privacy].

В «Интеграциях» укажите ID JivoSite, Microsoft Clarity и Umami Cloud, код Botfaqtor или входящий вебхук Slack. Ссылки на инструкции находятся рядом с полями. В Zadarma проверьте баланс, отправьте тестовое SMS или закажите тестовый звонок по международному номеру. SMS и звонок могут тарифицироваться. Для [payment] вставьте готовые платёжные ссылки ЮMoney, PayPal и СБП. Статус оплаты проверяется в кабинете провайдера.

В HTML и визуальном редакторе значки форматируют текст, добавляют H1–H5 и списки. Установите курсор и выберите отдельно шаблон, компонент, изображение или иконку. Для форм доступны сохранённые коды, а для компонентов — их параметры. Вставка Font Awesome доступна при включённой библиотеке.

Нажмите имя папки слева, чтобы управлять разделом справа. Там можно выбрать родительский раздел, настроить обычное и мобильное меню или указать URL перехода. Пустая страница раздела показывает подразделы. В «Обслуживании» задайте правила вида /contact.html => /contacts/ и редактируйте страницы ошибок в /error/. Поиск и язык на телефоне доступны через иконки в шапке.

```text
[map]
[map center="55.7558,37.6173" zoom=14]
[maps center="55.7558,37.6173" zoom=11]
[main-menu]
[lang]
[privacy]
[payment]
```

```php
$var = translit("Москва"); // Moskva
```

## Редактирование данных на странице · 1.6.6

В режиме правки у инфоблока, формы [formX], подшаблона [tel] и других компонентов с отдельными данными есть действия «Данные» и «На весь экран». «Вид инфоблока» перечисляет зарегистрированные шаблоны вывода. В списке родительских разделов «Корневая папка» переносит раздел на верхний уровень. Используйте [list-pages] для списка опубликованных страниц раздела и его подпапок. Меню языков в админке закрывается по клику вне списка или по Escape.
