## ページ上でデータを編集 · 1.6.6

編集モードでは情報ブロック、[formX]、[tel] などのデータをダイアログや全画面で編集できます。表示形式の一覧には登録済みのテンプレートが表示されます。ルートフォルダーを選ぶと、セクションが最上位に移動します。 [list-pages] はセクションと子フォルダーの公開ページを一覧にします。言語メニューは外側をクリックするか Escape で閉じます。


## 設定ファイル、地図、テンプレート · 1.6.5

メンテナンスの設定ファイルで .htaccess、robots.txt、sitemap.xml を編集できます。生成時にはサイトマップに含める設定の公開ページが対象となります。.htaccess の前の版を復元できます。

ページに緯度と経度を入力します。[map] はそのページの地点を表示し、[maps] は座標のある公開ページ全体を表示します。center と zoom で中心と倍率を指定し、連携設定で地図サービスを選びます。

[main-menu] はヘッダー直下のドロップダウンメニューです。独自テンプレートを追加し、端末別の表示を設定できます。スニペット画面からドメイン追加フォームを開けます。ポリシーへのリンクは [privacy] です。

連携設定で JivoSite、Microsoft Clarity、Umami Cloud の ID、Botfaqtor のコード、Slack の受信用 Webhook を設定できます。各欄の案内を参照してください。Zadarma では残高照会、SMS と通話のテストができます。テストの際に料金が発生する場合があります。[payment] には YooMoney、PayPal、SBP の決済リンクを設定し、支払い状況はサービス側で確認します。

HTML とビジュアル編集の各アイコンで文字装飾、見出し H1〜H5、リストを追加できます。カーソル位置を決め、テンプレート、コンポーネント、画像、アイコンを選びます。フォーム一覧とコンポーネントの設定が表示されます。Font Awesome はライブラリ有効時に使えます。

フォルダー名を選ぶと右側でセクションを管理できます。親セクション、モバイルと通常のメニュー、転送先 URL を設定できます。空のページには子セクションが表示されます。メンテナンスで /contact.html => /contacts/ のようなルールを追加し、/error/ のページを編集できます。モバイルの言語選択と検索はヘッダーのアイコンにあります。

```text
[map]
[map center="55.7558,37.6173" zoom=14]
[maps center="55.7558,37.6173" zoom=11]
[main-menu]
[lang]
[privacy]
[payment]
```

## 管理画面のヘッダーボタン · 1.6.4

地球のアイコンでサイトを開き、矢印のアイコンでログアウトします。スマートフォンではアイコンのみ表示されます。マウスを乗せるか、キーボードでフォーカスするとラベルを確認できます。

「コンテンツ」「フォームとリクエスト」「サイトとサービス」を選ぶと、各セクションが直接開きます。メインメニューの下に選択したセクションのタブが表示されます。

ホームページ（index.php）またはテンプレートのHTMLに [bread-crumbs] や [search] を追加すると、指定した位置に一度だけ表示されます。パンくずリストと検索の設定も適用されます。[privacy] は /privacy/ へのリンクです。ポリシーは「ページ」で編集できます。

```text
[bread-crumbs]
[search]
[privacy]
```


## バージョン 1.6.3 の新機能

### ホームとプライバシーポリシー

「デザイン テンプレート」を開いて、ホームページと /privacy.php ページを編集します。コード [page-content] は、メイン ページのコンテンツを表示します。ポリシー [site-name] および [site-url] では、「設定 → 一般」から名前とパブリック アドレスを取得します。最初のテキストにサイトとデータ処理に関する情報を入力します。

### クッキーを入れてトップに戻る

フッターで、[conf-policy] はポリシーへのリンクを提供し、[cookies] は設定を開き、[top] はページの先頭までスクロールします。分析と組み込み CMS マップは合意を待っています。テンプレートまたはサービス ヘッダーに手動で追加されたスクリプトには、独自の構成が必要です。

### 編集者functions.php

「サービスヘッダー」タブの後に「デザインテンプレート→関数」を開きます。返された配列にクロージャーを追加します。 PHP テンプレートで、`translit("Москва")` または `ew_call("translit", "München")` を呼び出します。 HTML に [func=translit value="Москва и München"] を挿入します。この例では、`Moskva i Muenchen` が生成されます。

### 標準テンプレートの編集

「デザイン テンプレート」フィールドには、強調表示された PHP および HTML ソース コードがすでに含まれています。標準テンプレートを編集する場合は「カスタムPHP」を選択します。保存するとカスタム バージョンが作成されます。テンプレートの横にあるボタンを使用すると、最後の編集を元に戻したり、元の編集を復元したりできます。

### 保存前のPHPチェック

デザイン テンプレート、モジュール、および functions.php エディターは、`php -l` コマンドを使用して構文をチェックします。エラーが発生した場合は、以前のバージョンが残ります。サーバー上の PHP CLI を選択するには、`SITE_PHP_LINT_BINARY` 変数を使用します。

### バックライトとコンパクトな検索

CodeMirror は、新規インストールではデフォルトで有効になります。設定は「ライブラリとフォント」にあります。コンパクト検索では、フィールドが左に拡張され、十字キーで行がクリアされ、Enter キーで検索が開始されます。

### 管理者メニューと編集パネル

管理パネルのヘッ​​ダーの下のメニューとサイトの編集パネルには、キャプション付きのアイコンが表示されます。アイコンは狭い画面に残ります。ホバーするとツールチップが開き、狭い画面ではキーボードがフォーカスされます。 「非表示」はページの残りのアクションの隣にあります。編集モードスイッチは右側にあります。

### PHPモジュールの説明とコード

「PHP モジュール」では、短い説明はプレーン テキスト用です。関数の本体を別のフィールド「ソースコード・PHP」に貼り付けます。

## バージョン 1.6.2 の新機能

### 管理者とヘルプの言語

地域設定で、希望の言語を有効にします。ヘッダーの言語選択メニューにより、現在のセクションを維持したまま、インターフェイスとヘルプが変更されます。ページのテキストと設定の値は、元の形式で保存されます。

### 地下室の装飾

コード [author] には、署名 Eurowebcart CMS Light、作成者名 Бандалетов Павел、および GitHub へのリンクが表示されます。カスタム HTML フッター内の署名を配置する場所を選択するには、適切な行に [author] を貼り付けます。

### 編集モードのバックライト

[コンポーネントの編集] リンクの上にマウスを置くか、キーボード フォーカスをそれに設定します。フレームは、この特定の挿入の出力を強調表示します。

### 検索を変更する場所

「設定→一般」で検索タイプを選択します。 「メンテナンス」では、ページのインデックスを再作成でき、管理ヘッダーのフィールドは設定によって検索されます。

### 検索結果と候補

検索結果には1ページあたり20件を表示し、通し番号を付けます。コンパクト検索は虫眼鏡の左に広がり、入力欄に Enter アイコンが表示されます。管理画面の検索候補は設定に直接リンクします。

## バージョン 1.6.1 の新機能

### 検索

基本設定で無効・虫眼鏡・展開を選べます。管理画面の上部でも設定を検索できます。管理画面での編集後は自動で索引を更新し、FTP での変更は定期実行で反映します。インクルードやデータブロックも検索対象になり、PHP モジュールは実行しません。

### PHP モジュール

モジュールを開くと設定と使用ページが表示されます。ID、ファイル名、関数の本体を入力して作成します。ファイル名を変えても [php]id[/php] は共通です。ライブラリで CodeMirror を有効にできます。

### テンプレートと翻訳

テンプレートごとに８件の変更を元に戻せます。既定の PHP に復元することもできます。ドメインごとに履歴があり、管理画面ではカスタム HTML、ファイルは templates/local/ を使います。翻訳の作成中も言語を切り替えられ、ページ移動では翻訳も移ります。

### 連携とメンテナンス

CAPTCHA、地図、電話、分析の設定に公式案内へのリンクを追加しました。コールバックの URL とトークンを入力できます。登録したサブドメインの設定はメインドメインへの遷移後も適用されます。php update.php --scheduled を15分おきに実行します。

## バージョン 1.6.0 の新機能

### 検索とキャッシュ

公開後や管理画面・FTP で更新した後は、メンテナンスで検索インデックスを再作成します。入力候補には閲覧者の言語で公開ページが表示されます。キャッシュは初期状態で無効です。フォームや動的処理はリクエストごとに実行します。

### サイト上での編集

ログイン後、ヘッダー上部の右端のスイッチでサイト全体の編集モードを切り替えます。コンポーネントの近くに編集リンクが表示されます。ページの CSS・JS はライトボックスで開きます。管理画面では HTML 編集、ビジュアル編集、コード挿入、AJAX による一括アップロードと並べ替えが使えます。

### コンポーネントとナビゲーション

指定のない値には共通設定を使用します。width は 100・50・33・25 に対応し、% も付けられます。スマートフォンでは一列になります。numbers=off でスライド番号を非表示にできます。左右のスワイプに対応し、モバイルメニューは右から開きます。パンくずリストは基本設定で無効にできます。

```text
[gal width=50 numbers=off arrows=on fit=cover]/images/myfotos/[/gal]
[fotos width=50% columns=3 captions=on]/images/myfotos/[/fotos]
[files width=33 icons=off size=on download=on]/files/myfiles/[/files]
```

### 言語・外観・価格

地域設定では管理画面とサイトの言語、通貨、数値・日付・時刻の形式、タイムゾーンを選べます。翻訳は index.php の隣に index_en.php として保存し、翻訳がない場合は元の内容が開きます。価格は選択した通貨で表示されます。テーマの配色とモードをプレビューし、明暗別のロゴや Roboto Condensed の例文を設定できます。

```text
/contacts/index.php → /contacts/index_en.php
```

### フォーム・依頼・連携

CAPTCHA の共通設定に Google reCAPTCHA v2 のキーを入力します。フォームごとの設定も可能です。メッセージと折り返し依頼は未読順で一ページに20件表示されます。連携では Zadarma、Telegram、分析、Google または Yandex の地図とクラスタリングを設定できます。ライブラリはライトボックスでテストし、挿入コードを確認できます。CodeMirror は自動、HTML、CSS、JS、PHP、RAW に対応します。

```text
[map lat=55.7558 lng=37.6173 title="Office" zoom=13 provider=yandex url="/contacts/" button="Open"]
```

```text
[callback button="Call me" title="Callback" submit="Send" placeholder="+7(900)123-45-67"]
```

### PHP モジュール

PHP モジュールの名前、説明、有効状態を管理し、ページに挿入します。server-date は地域設定の日付形式を使います。実行ファイルは開発者が保護されたディレクトリに配置します。

```text
[php]server-date[/php]
```

## ページ設定 · 1.6.8

コンテンツは「編集」で作成します。URL、メニュー、公開期間は「ページ設定」で指定します。SEO にはタイトル、説明、キーワード、サイトマップへの掲載設定があります。「地図」には座標とタグ例があります。

日時を空欄にすると期間の制限はありません。サイトのタイムゾーンが適用されます。非表示のページは別途公開してください。

- `[map]` — 現在のページの地点を表示します。
- `[maps]` — 公開ページすべての地点を表示します。

## バナーと画像エディター · 1.6.8

コンポーネントでセットとスライドを管理します。フォルダーの写真、キャプション、リンク・フォーム・折り返し電話のボタン、表示期間を設定できます。編集モードではスライドの操作が表示されます。画像選択ではフォルダーの閲覧、アップロード、削除、GD を使った回転・サイズ変更済みのコピーの作成が可能です。Font Awesome のアイコンは名前で検索できます。

```text
[banners]
[banners set=summer arrows=on numbers=off]
[banners]/images/myfotos/[/banners]
```

## 言語 · 1.6.9

「言語」タブにページの言語が表示されます。「開く」で保存済みの翻訳を編集し、「翻訳を作成」で空のエディターを開きます。

サブセクションは現在のセクション内に、同階層のセクションはその隣に、ルートセクションはサイトの最上位に作成されます。

## PHP の互換性とナビゲーション · 1.6.10

PHP の最低バージョンは 7.2 です。サイトと管理画面は PHP 8.6 に対応しています。独自のモジュールやテンプレートでは、サーバーの PHP バージョンに対応する構文を使用してください。

[bread-crumbs] の現在の項目を展開すると、メインメニューにある同じ階層の公開セクションが表示されます。設定した URL はメニュー、セクション一覧、パンくずリスト、検索結果と候補に使われます。

ごみ箱でインフォブロックの編集画面から行を削除できます。列を削除すると、その列の値もすべて消えます。変更は保存時に記録され、並べ替え後の自動保存も含まれます。

### サイトのバックアップ

非公開の ZIP にページ、メディア、情報ブロック、設定、独自テンプレート、PHP モジュールが含まれます。管理者アカウントと依頼は別に保存されます。PHP Zip が必要です。

内容と設定を置き換えます。先に現在の状態をバックアップします。

### 未使用ファイルの整理

保存済みのコンテンツに参照がないメディアを検索します。一覧を確認してファイルを選びます。処理前にバックアップが作成されます。コンポーネントコードを削除してもフォルダーとファイルは残ります。

### 地図で地点を選択する

Yandex Maps のコンソールで「JavaScript API」のキーを作成し、HTTP Referer で制限してください。ページの「地図」タブで地点を選択し、座標を適用します。

テキストを選択して揃え方を変えたり、書式を消したりできます。画像をクリックすると設定が開きます。ドラッグで移動し、角をドラッグするとサイズを変更できます。リンクは URL、メール、電話、アンカーに対応します。ボタンは URL、フォーム、折り返し電話、決済リンクを開けます。

HTML タブとビジュアルエディタータブでモードを切り替えます。SUP、SUB、段落ボタンは対応する要素を挿入します。コンポーネント名の横にコードが表示されます。挿入時に存在しないフォルダーを作成します。フォルダー名には英字、数字、ハイフン、アンダースコアを使用できます。「言語」タブから言語設定に移動できます。

```text
[button action="url" label="Contacts" url="/contacts/"]
[button action="form" label="Write to us" form="form1"]
[button action="callback" label="Call me"]
[button action="payment" label="Pay" amount="1250.00" currency="RUB" yoomoney="410010000000000"]
[map]
[maps]
```
