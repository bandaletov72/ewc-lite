## ページ上でデータを編集 · 1.6.6

編集モードでは情報ブロック、[formX]、[tel] などのデータをダイアログや全画面で編集できます。表示形式の一覧には登録済みのテンプレートが表示されます。ルートフォルダーを選ぶと、セクションが最上位に移動します。 [list-pages] はセクションと子フォルダーの公開ページを一覧にします。言語メニューは外側をクリックするか Escape で閉じます。


## 設定ファイル、地図、テンプレート · 1.6.5

メンテナンスの設定ファイルで .htaccess、robots.txt、sitemap.xml を編集できます。生成時にはサイトマップに含める設定の公開ページが対象となります。.htaccess の前の版を復元できます。

ページに緯度と経度を入力します。[map] はそのページの地点を表示し、[maps] は座標のある公開ページ全体を表示します。center と zoom で中心と倍率を指定し、連携設定で地図サービスを選びます。

[main-menu] はヘッダー直下のドロップダウンメニューです。独自テンプレートを追加し、端末別の表示を設定できます。スニペット画面からドメイン追加フォームを開けます。ポリシーへのリンクは [privacy] です。

連携設定で JivoSite、Microsoft Clarity、Umami Cloud の ID、Botfaqtor のコード、Slack の受信用 Webhook を設定できます。各欄の案内を参照してください。Zadarma では残高照会、SMS と通話のテストができます。テストの際に料金が発生する場合があります。[payment] には YooMoney、PayPal、SBP の決済リンクを設定し、支払い状況はサービス側で確認します。

HTML とビジュアル編集の各アイコンで文字装飾、見出し H1〜H5、リストを追加できます。カーソル位置を決め、テンプレート、コンポーネント、画像、アイコンを選びます。フォーム一覧とコンポーネントの設定が表示されます。Font Awesome はライブラリ有効時に使えます。

フォルダー名を選ぶと右側でセクションを管理できます。親セクション、モバイルと通常のメニュー、転送先 URL を設定できます。空のページには子セクションが表示されます。メンテナンスで /contact.html => /contacts/ のようなルールを追加し、/error/ のページを編集できます。モバイルの言語選択と検索はヘッダーのアイコンにあります。

```text
[map]
[map center="55.7558,37.6173" zoom=14]
[maps center="55.7558,37.6173" zoom=11]
[main-menu]
[lang]
[privacy]
[payment]
```

## バージョン 1.6.3 の新機能

### ホームとプライバシーポリシー

「デザイン テンプレート」を開いて、ホームページと /privacy.php ページを編集します。コード [page-content] は、メイン ページのコンテンツを表示します。ポリシー [site-name] および [site-url] では、「設定 → 一般」から名前とパブリック アドレスを取得します。最初のテキストにサイトとデータ処理に関する情報を入力します。

### クッキーを入れてトップに戻る

フッターで、[conf-policy] はポリシーへのリンクを提供し、[cookies] は設定を開き、[top] はページの先頭までスクロールします。分析と組み込み CMS マップは合意を待っています。テンプレートまたはサービス ヘッダーに手動で追加されたスクリプトには、独自の構成が必要です。

### 編集者functions.php

「サービスヘッダー」タブの後に「デザインテンプレート→関数」を開きます。返された配列にクロージャーを追加します。 PHP テンプレートで、`translit("Москва")` または `ew_call("translit", "München")` を呼び出します。 HTML に [func=translit value="Москва и München"] を挿入します。この例では、`Moskva i Muenchen` が生成されます。

### 標準テンプレートの編集

「デザイン テンプレート」フィールドには、強調表示された PHP および HTML ソース コードがすでに含まれています。標準テンプレートを編集する場合は「カスタムPHP」を選択します。保存するとカスタム バージョンが作成されます。テンプレートの横にあるボタンを使用すると、最後の編集を元に戻したり、元の編集を復元したりできます。

### 保存前のPHPチェック

デザイン テンプレート、モジュール、および functions.php エディターは、`php -l` コマンドを使用して構文をチェックします。エラーが発生した場合は、以前のバージョンが残ります。サーバー上の PHP CLI を選択するには、`SITE_PHP_LINT_BINARY` 変数を使用します。

### バックライトとコンパクトな検索

CodeMirror は、新規インストールではデフォルトで有効になります。設定は「ライブラリとフォント」にあります。コンパクト検索では、フィールドが左に拡張され、十字キーで行がクリアされ、Enter キーで検索が開始されます。

### 管理者メニューと編集パネル

管理パネルのヘッ​​ダーの下のメニューとサイトの編集パネルには、キャプション付きのアイコンが表示されます。アイコンは狭い画面に残ります。ホバーするとツールチップが開き、狭い画面ではキーボードがフォーカスされます。 「非表示」はページの残りのアクションの隣にあります。編集モードスイッチは右側にあります。

### PHPモジュールの説明とコード

「PHP モジュール」では、短い説明はプレーン テキスト用です。関数の本体を別のフィールド「ソースコード・PHP」に貼り付けます。

## バージョン 1.6.0 の新機能

### 検索とキャッシュ

公開後や管理画面・FTP で更新した後は、メンテナンスで検索インデックスを再作成します。入力候補には閲覧者の言語で公開ページが表示されます。キャッシュは初期状態で無効です。フォームや動的処理はリクエストごとに実行します。

### サイト上での編集

ログイン後、ヘッダー上部の右端のスイッチでサイト全体の編集モードを切り替えます。コンポーネントの近くに編集リンクが表示されます。ページの CSS・JS はライトボックスで開きます。管理画面では HTML 編集、ビジュアル編集、コード挿入、AJAX による一括アップロードと並べ替えが使えます。

### コンポーネントとナビゲーション

指定のない値には共通設定を使用します。width は 100・50・33・25 に対応し、% も付けられます。スマートフォンでは一列になります。numbers=off でスライド番号を非表示にできます。左右のスワイプに対応し、モバイルメニューは右から開きます。パンくずリストは基本設定で無効にできます。

```text
[files width=33 icons=off size=on download=on]/files/myfiles/[/files]
```

## データブロックのグラフ

ページエディターのコンポーネント挿入で、表またはグラフを選択します。グラフには Chart.js を有効にし、ラベル列と数値または価格の列を選択します。円・ドーナツ・極座標グラフには非負の値の列を一つ指定します。ライブラリが無効な場合は表を表示します。

エディターを開き直すと、保存したフォーム、テンプレート、スニペット、登録したコンポーネントが挿入一覧に表示されます。新しいバナーセット ID には A–Z、a–z、ハイフン、アンダースコアを使用できます。[banners] のフォルダーに画像をアップロードすると、各ファイルに編集リンクが表示されます。 編集モードでは選んだスライドがダイアログで開き、既定設定は別リンクから開けます。カルーセル、ギャラリー、ファイル一覧の保存ボタンの隣には、アップロード・削除・並べ替え・子フォルダー作成用のファイルマネージャーがあります（A–Z、a–z、0–9、-、_）。スライド色は四角い見本に表示されます。

```text
[iblock=table]/data/myiblock.txt[/iblock]
[iblock=charts type=line labels=month values=sales,orders]/data/myiblock.txt[/iblock]
[banners set=summer-promo]
```
