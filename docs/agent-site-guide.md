# Как агенту собрать сайт на Eurowebcart CMS Light

Руководство для создания тем и страниц на CMS версии [1.6.20](https://github.com/bandaletov72/php-site-updates/releases/tag/v1.6.20). Целевой результат — работающий сайт, который владелец может редактировать через админку. [КОНТУР](kontur.md) — пример готовой темы с портфолио, прейскурантом, формой, продажами и картой.

## 1. Определите, что должно переключаться вместе с темой

| Задача | Как устроить |
| --- | --- |
| Изменить оформление существующего сайта | Создайте тему в `templates/themes/<id>/`. Оставьте страницы в общих каталогах. |
| Поставить готовый сайт целиком | Добавьте в тему собственные `content/pages/`, `content/data/` и `content/settings/`. При активации CMS переключит оформление, страницы и данные этой темы. |
| Сделать заготовку для отдельных страниц | Используйте «Шаблоны страниц». Заготовка заполняет черновик страницы, в том числе SEO, CSS и JavaScript. |

На рабочем сайте сначала сделайте резервную копию через «Сайт и сервисы → Обслуживание». Собирайте и проверяйте новый дизайн в отдельной установке, а затем перенесите его на рабочий сайт. Для собственного комплекта страниц проверьте переключение на системную тему и обратно. Оба набора страниц должны открываться по своим обычным URL в соответствующей теме.

## 2. Запустите CMS и создайте тему

Возьмите полный архив из [релизов](https://github.com/bandaletov72/php-site-updates/releases). Из каталога с `index.php` запустите локальный сервер. Используйте PHP 7.2 или новее. Для создания сайта база данных, Composer и сборщик фронтенда не требуются.

```sh
php -S 127.0.0.1:8000 router.php
```

Откройте `http://127.0.0.1:8000/admin/` и пройдите мастер установки. На хостинге для первого входа одноразовый код выдаёт команда `php admin/setup.php`. Сведения о правах записи, расширениях PHP и сервере есть в [инструкции установки](../README.md).

В админке перейдите в «Шаблоны оформления → Темы дизайна → Создать тему». Для ручной установки создайте одноимённый каталог, например `templates/themes/atelier/`, и примените его в этом же разделе. В идентификаторе используйте строчные латинские буквы, цифры, дефис и подчёркивание. `system` зарезервирован.

Начинайте с `css/theme.css`. При необходимости добавьте `js/theme.js`. CMS подключает их автоматически через стандартный `templates/layout.php`. Чтобы поменять конкретный блок, откройте «Редактор файлов темы» и скопируйте нужный штатный файл. Для переопределения сохраните его имя и относительный путь. Например, `footer.php` заменяет подвал, `components/banners.php` — вид баннеров, `iblock/table.php` — вид таблиц. Отсутствующие файлы берутся из штатных шаблонов CMS. Галочка в списке означает, что у темы есть свой файл. Кнопка восстановления возвращает версию из комплекта темы или удаляет переопределение. После удаления снова используется штатный файл CMS, если он есть.

В PHP-шаблонах используйте `site_url($base, 'contacts/')` для внутренних ссылок, `site_design_asset($base, 'images/cover.jpg')` для ассетов темы и `site_escape()` для вывода динамических значений. Сохраняйте защиту `SITE_ROOT` из штатного шаблона. Для обычной страницы достаточно HTML и кодов вставки.

## 3. Создайте страницы и настройте навигацию

В разделе «Страницы» создайте нужные разделы и откройте вкладку «Правка». Для сайта компании можно начать с `/`, `/about/`, `/works/`, `/price/`, `/sales/` и `/contacts/`. Задайте каждой странице осмысленный `Title`, заголовок `Heading`, метаописание и подпись в меню. Проверьте галочки для основного и мобильного меню. Отключение родительского пункта исключает его дочерние ссылки из соответствующего меню. Порядок можно менять перетаскиванием. Для страницы с перенаправлением укажите URL в её настройках, чтобы CMS учитывала его в навигации.

Через SFTP или файловую систему размещайте страницы в UTF-8 без BOM. Главная хранится в `index.php`, раздел `/contacts/` — в `contacts/index.php`, вложенный раздел `/services/design/` — в `services/design/index.php`. Имена допускают латиницу, цифры, дефис и подчёркивание. Служебные каталоги зарезервированы. От сохранённого `.php` до публичного URL путь вычисляет CMS. При переносе разделов проверьте ссылки и добавьте редиректы для изменившихся адресов.

Файл страницы состоит из штатного PHP-блока до `__halt_compiler();`, заголовков, пустой строки и HTML-фрагмента. `Title` обязателен. Если `Heading` пустой, CMS берёт `Title`. Основное оформление, документ `<html>`, `<head>` и заголовок страницы уже выводят шаблоны. Для перевода положите рядом `index_en.php` и включите язык в региональных настройках. Выбор языка сохраняет обычный адрес страницы, а при отсутствии перевода остаётся основной текст.

## 4. Соберите минимальную тему со своими страницами

Ниже пример нового комплекта для сайта «Ателье». Пути указаны от корня CMS. Сначала создайте файлы, затем выберите `atelier` в «Темах дизайна». В комплекте должны существовать все три каталога `content/pages`, `content/data` и `content/settings` и файл `content/pages/index.php`. В админке эта тема появится с пометкой «Готовый сайт».

### `templates/themes/atelier/css/theme.css`

```css
.atelier-intro {
    max-width: 42rem;
    padding-block: clamp(1.5rem, 4vw, 4rem);
    border-bottom: 1px solid var(--line);
}

.atelier-intro h2 {
    font-size: clamp(1.5rem, 4vw, 3rem);
    color: var(--accent);
}
```

### `templates/themes/atelier/theme-info.php`

```php
<?php http_response_code(404); exit; __halt_compiler();
{"name":"Ателье"}
```

### `templates/themes/atelier/content/settings/site-settings.php`

```php
<?php http_response_code(404); exit; __halt_compiler();
{"name":"Ателье","subtitle":"Архитектура и интерьеры","description":"Консультации и дизайн интерьеров.","searchMode":"compact","scrollAnimation":"slide"}
```

### `templates/themes/atelier/content/pages/index.php`

```php
<?php
define('SITE_ROOT', __DIR__);
require SITE_ROOT . '/app/site.php';
site_render(isset($pageFile) ? $pageFile : __FILE__);
__halt_compiler();
Title: Главная
Heading: Архитектурное ателье
Description: Консультации и проектирование интерьеров.
Menu: Главная
MenuVisible: 1
MobileMenu: 1
Order: 10

<section class="atelier-intro">
    <h2>Спроектируем пространство под ваши задачи</h2>
    <p>Начните с консультации или разбора планировки.</p>
    <p><a href="/contacts/">Обсудить проект</a></p>
</section>
<h2>Услуги</h2>
[iblock=table]/data/services.txt[/iblock]
```

### `templates/themes/atelier/content/pages/contacts/index.php`

```php
<?php
$pageFile = __FILE__;
require __DIR__ . '/../index.php';
__halt_compiler();
Title: Контакты
Heading: Обсудить проект
Description: Связаться с архитектурным ателье.
Menu: Контакты
MenuVisible: 1
MobileMenu: 1
Order: 20

<p>Оставьте контакты и коротко опишите задачу.</p>
[phones]
[soc-icons]
[form1]
```

### `templates/themes/atelier/content/data/services.txt.php`

```text
<?php http_response_code(404); exit; __halt_compiler();
service|scope|price
Услуга|Что входит|Стоимость от
text|textarea|price
Консультация|Встреча с архитектором до 60 минут|18000
Разбор планировки|Анализ и два варианта зонирования|68000
```

Откройте `/` и `/contacts/`. Услуги появятся в таблице, а форма и контакты будут редактироваться в админке. Формат цены зависит от региональных настроек. Пример ссылки `/contacts/` рассчитан на установку в корне домена. При размещении в подкаталоге проверьте префикс у вручную заданных ссылок.

PHP-блоки файлов темы совпадают с обычными файлами страниц соответствующей глубины. CMS читает их как записи и публикует только по логическим адресам, например `/contacts/`. При выкладке закройте прямой веб-доступ к PHP-файлам и скрытым файлам `templates/themes/`, а также к `data/`. Для отсутствующих на диске адресов страниц настройте маршрутизацию к `app/page-route.php` согласно конфигурации сервера. Проверьте это на хостинге после переноса темы.

## 5. Добавляйте редактируемые блоки

| Если нужна возможность | Как добавить |
| --- | --- |
| Контакты и кнопки соцсетей | Заполните «Настройки → Контакты и соцсети», затем вставьте `[phones]`, `[contacts]` или `[soc-icons]`. |
| Повторяющийся текст или призыв | Создайте подшаблон, например `[project-brief]`, и вставляйте его в нужные страницы. |
| Галерея, карусель и файлы | Загрузите медиа в каталог темы и вставьте `[fotos]/images/projects/[/fotos]`, `[gal fit=cover numbers=off]/images/projects/[/gal]` или `[files]/files/catalog/[/files]`. |
| Баннер | Создайте набор в «Компоненты → Баннеры» и вставьте `[banners set=hero width=page height=520 mobile-height=320]`. В наборе задаются кадры, текст, изображение и действие кнопки. |
| Портфолио или прайс | Для портфолио вставьте `[iblock=portfolio]/data/works.txt[/iblock]` с полями `title`, `category`, `description`, `images`, `url`. Для прайса используйте таблицу с типом `price`. |
| Форма или обратный звонок | Создайте форму в разделе «Формы», настройте получателя, типы и обязательность полей. Вставьте её код, например `[form1]`, либо `[callback=Заказать звонок]`. Проверьте запись тестовой заявки в админке и доставку настроенному получателю. |
| Карта проезда | Заполните координаты страницы для `[map]` или создайте инфоблок с `title`, `lat`, `lng` и необязательными `url`, `button` для `[maps source=offices]`. Интерактивная карта требует провайдера, его ключа и разрешения посетителя. |
| Страница продажи | Настройте цену и платёжный способ на вкладке «Продажа». Вставьте `[item-price]` и `[item-buy-button]`. Проверьте сценарий на тестовых реквизитах провайдера. |

Параметры в коде переопределяют общие настройки поддерживаемых компонентов. Для ширины используйте `page`, `content` или `parent` по нужному контейнеру, для высоты — `height` и `mobile-height`. У инфоблока первые три строки содержат ключи, названия и типы столбцов. Затем идут строки данных. Разделитель — `|`. Поля с разделителем или переносами заключайте в кавычки. Управляйте блоками через «Содержимое → Инфоблоки», а исходные примеры сверяйте со [справочником шаблонов](templates.md).

## 6. Проверьте результат и передайте сайт

1. Откройте все публичные URL. Проверьте меню, хлебные крошки, редиректы, 404 и канонические адреса. Убедитесь, что ошибка возвращает статус 404.
2. Проверьте сайт на компьютере и телефоне. Откройте меню, галерею и диалоги. Прокрутите страницу и проверьте, что элементы доступны с клавиатуры.
3. Войдите в админку и внесите пробную правку страницы, контакта или инфоблока. Убедитесь, что правка попала в активную тему, видна на сайте и переживает переключение темы.
4. Проверьте, что служебные файлы закрыты, а запрос `?ajax=1` без необходимых данных текущего сеанса отклоняется. Если меняли PHP-шаблоны, проверьте синтаксис и совместимость с PHP 7.2.
5. Уберите демо-данные или явно обозначьте их. Настройте реальные контакты, политику конфиденциальности и нужные интеграции. Перестройте поиск через «Обслуживание», проверьте `sitemap.xml` и сделайте резервную копию.
6. Передайте владельцу ссылку на сайт, разделы админки для повседневных правок и перечень подключённых интеграций. В архив темы кладите шаблоны, контент, медиа и безопасные примеры настроек. Учётные данные, ключи сервисов и заявки передаются отдельно в рамках выбранного способа доступа.
