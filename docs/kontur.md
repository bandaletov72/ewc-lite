# КОНТУР для Eurowebcart CMS Light

Премиальная тема архитектурного бюро. В комплекте главная, «О компании», «Наши работы», «Прейскурант», «Продажи» и «Контакты». Изображения созданы в ImageGen для демонстрационной темы. Телефон, цены, проекты и точки на карте служат примерами.

## Установка

1. Установите Eurowebcart CMS Light 1.6.19 или обновите работающую установку до этой версии.
2. Откройте «Шаблоны оформления → Темы дизайна», выберите «КОНТУР · Готовый сайт» и нажмите «Применить». CMS развернёт комплект при первом включении. При возврате к «Системной» снова откроются общие страницы сайта.
3. В «Настройки → Основные» поменяйте название, подзаголовок и адрес получателя форм. Номера и соцсети меняются в «Настройки → Контакты и соцсети». Бриф редактируется в разделе «Формы» под кодом `[form84]`.
4. Для покупки откройте страницу «Продажи», вкладку «Продажа», и подключите свой платёжный реквизит. Для интерактивной карты выберите провайдера и сохраните API-ключ в интеграциях. Если посетитель ещё не разрешил встроенные карты, ему доступна кнопка «Разрешить и показать карту». В демонстрационном комплекте доступна запись через форму, а раздел карты содержит ссылки на десять точек.

Оформление и собственный сайт темы находятся в `templates/themes/kontur/`. `content/pages` хранит страницы, `content/data` — инфоблоки, `content/settings` — настройки контента. Учётная запись администратора, заявки и ключи внешних сервисов принадлежат всей установке. Резервная копия включает оба набора страниц и папки тем. При нестандартной конфигурации Apache или Nginx передавайте отсутствующие URL страниц в `app/page-route.php` и закрывайте прямые запросы к PHP-файлам и скрытым файлам внутри `templates/themes/`.

## Что редактировать

С версии 1.6.20 у «КОНТУР» свои светлый и тёмный логотипы и favicon. Файлы, загруженные для темы в «Настройки → Основные → Логотипы и иконки сайта», имеют приоритет.

Блоки «КОНТУР» плавно появляются со сдвигом при прокрутке. Эффект меняется в «Настройки → Основные → Анимация при прокрутке». Браузерная настройка уменьшения движения отключает анимацию.

| Блок | Где менять |
| --- | --- |
| Баннер на главной | Компоненты → Баннеры → `kontur-hero` |
| Портфолио | Содержимое → Инфоблоки → `kontur-works` |
| Прейскурант и карточки услуг | Инфоблоки `kontur-price` и `kontur-catalog` |
| Карта проезда | Инфоблок `kontur-map` |
| Приглашение заполнить бриф | Подшаблон `[kontur-brief]` |
| Цвета, гарнитуры и файлы дизайна | Шаблоны оформления → Цвета сайта / Шрифты / Темы дизайна |

В Портфолио первая фотография становится обложкой. Остальные открываются в том же окне просмотра. В столбце `images` указывайте имена файлов из `/images/projects/` или пути к изображениям через запятую. Разделы берутся из `category`, заголовок из `title`, описание из `description`, кнопка из `url`. Для ссылок подходят внутренний путь сайта и внешний адрес HTTP(S).

```text
[portfolio]
[iblock=portfolio]/data/kontur-works.txt[/iblock]
[iblock=portfolio limit=2]/data/kontur-works.txt[/iblock]
[maps source=kontur-map]
```

В редакторе файлов галочка отмечает файл темы. «Восстановить заводскую версию» возвращает выбранный файл из комплекта либо включает штатный файл CMS. Содержимое страниц и инфоблоков редактируется отдельно.
