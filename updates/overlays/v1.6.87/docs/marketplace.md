# Маркетплейс EWC Lite

На новой установке CMS работает как сайт. Откройте вкладку «Маркетплейс», проверьте обновления, установите модуль, включите его и сохраните настройку. Каталог и заказы сохраняются в `shop/data/`, изображения — в `shop/images/`.

## Карточки и разделы

Карточки имеют постоянный адрес `/shop/product/slug/`. Адрес раздела повторяет дерево категорий. Например, `/shop/instrumenty/dreli/bosch/` показывает Bosch внутри раздела «Дрели». Вторая страница сохраняет поиск, фильтры и сортировку, добавляя `p=2`.

В разделе «Каталог → Товары» список разбит на страницы по 20 товаров. Фильтр ищет по названию, артикулу, штрихкоду, разделу и статусу. По умолчанию видны название, артикул и цена. Дополнительные поля включаются в меню «Столбцы». В конце строки доступны редактирование, копирование и удаление. При копировании создаётся неактивная карточка с новыми артикулами, пустыми штрихкодами и нулевыми остатками. Удаление требует подтверждения.

В карточке задаются название, раздел, адрес, активность, тип, изображение и описание товара. У каждого предложения свои артикул, штрихкод, цена, активность и остаток. Склады добавляются на вкладке «Склады», их остатки задаются в карточке. Доступное количество считается по сумме складских остатков и остатка без склада с учётом оформленных заказов. Импорт обновляет остаток без склада.

Для отдельных таблиц каталога используется CSV в UTF‑8 с разделителем `|` и строкой заголовков. ID товаров и предложений постоянны. В CSV основную цену и другие виды цен указывайте в сотых долях валюты учёта. Листы «Дополнительные разделы», «Изображения» и «Комплекты» управляют размещениями, галереей и составом наборов.

Полное описание правится в том же HTML-редакторе, что и страницы CMS. В нём работают шорткоды. Редактирование HTML доступно администратору CMS. У редактора каталога есть доступ к таблицам и импорту, где текст введённого полного описания безопасно экранируется. Параметры вывода правятся во вкладке «Настройки» маркетплейса. Переменные шаблона записываются как `{{name}}`, `{{url}}`, `{{description}}` и т. п. Набор видно в исходном шаблоне.

Для общего поля оставьте `category_id` пустым. Поля раздела наследуются его подразделами, а размещение в дополнительном разделе тоже делает его поля доступными товару. `target` принимает `product` или `offer`. Тип — `list`, `number`, `boolean` или `text`. Включите `filter` для поля списка, числа или флажка. Для числового поля можно включить `sort`, чтобы появилась сортировка в обе стороны.

## Шорткоды

| Код | Что выводит |
| --- | --- |
| `[shop-categories]` | Дерево разделов. Параметр `category=tools` выводит подразделы выбранного раздела. |
| `[shop-items]` | Витрину с пагинацией. Параметры `category=drills limit=24` задают раздел и размер страницы. |
| `[shop-basket]` | Ссылку на корзину и счётчик, в том числе в шапке. |
| `[shop-search]` | Поиск по каталогу или текущему разделу. |
| `[shop-filters]` | Фильтры по цене и доступным характеристикам. |
| `[shop-sort]` | Сортировку по цене, новизне и числовым полям. |
| `[shop-pages]` | Дополнительную пагинацию. Используйте те же `category` и `limit`, что у списка. |
| `[shop-product id=p1]` | Полную карточку определённого товара. |
| `[shop-breadcrumbs]` | Навигацию по дереву разделов. |
| `[shop-cart]` | Содержимое корзины с изменением количества. |
| `[shop-checkout]` | Форму заказа с самовывозом или доставкой. |
| `[shop-account]` | Блок заказов личного кабинета. |
| `[shop-orders]` | Историю заказов текущего пользователя. |
| `[register]` | Регистрацию пользователей сайта. Работает при разрешённой регистрации. |
| `[account]` | Личный кабинет и вход. |

## Импорт, письма и обновление

Во вкладке «Импорт» загрузите CSV или YML, укажите постоянное имя источника, проверьте предпросмотр и примените его. Для CSV можно сопоставить заголовки, например `sku=Артикул`, `name=Название`, `price=Цена`. Запись `field:voltage=Напряжение` связывает параметр импорта с полем `voltage`. Файл с другой валютой требует предварительной конвертации. YML требует расширений XMLReader и SimpleXML. Когда в YML нет количества, остаток существующей позиции сохраняется. У новой позиции без количества он равен нулю.

Регистрацию и письма для сайта включите в общих настройках CMS. У шаблонов писем заказа свой редактор в настройках маркетплейса. Для сброса пароля задайте публичный URL сайта и настройте отправку PHP `mail()`. Ссылка одноразовая и действует 30 минут. В режиме «Сайт» в кабинете остаются личные данные и смена пароля, а служебные права назначаются через «Сайт и сервисы → Пользователи».

В блоке «Установить или обновить модуль» нажмите «Проверить обновления». CMS сверит отдельную версию маркетплейса с подписанным пакетом в GitHub Releases репозитория `bandaletov72/ewc-lite` и покажет описание релиза. При установке индикатор показывает ход загрузки, проверки подписи и записи файлов. Пакет собирается командой `php update.php --build-shop marketplace.zip`. Каталог, заказы, фотографии и настройки хранятся отдельно от пакета.
