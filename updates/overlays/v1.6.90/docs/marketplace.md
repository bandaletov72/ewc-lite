# Маркетплейс EWC Lite

На новой установке CMS работает как сайт. Откройте вкладку «Маркетплейс», проверьте обновления, установите модуль, включите его и сохраните настройку. Модуль размещается в закрытой папке `admin/shop/`. Вложенные каталоги `data/` и `images/` хранят записи и изображения магазина.

Откройте «Страницы → Магазин» для редактирования страницы `/shop/`. Вставьте `[shop]` в содержимое обычной страницы, чтобы вывести витрину со стандартными шапкой, меню и подвалом. Во вкладке «Маркетплейс → Фильтры» выберите положение сверху или слева, настройте цену и характеристики. Живой фильтр обновляет список товаров при изменении параметров.

Иконки «Плитка» и «Список» переключают вид витрины. Поиск, фильтры и сортировка сохраняются при смене вида. Выбор сортировки действует сразу.

## Карточки и разделы

Во вкладке «Маркетплейс → Бренды» можно задать описание, сайт и логотип. Бренды берутся из характеристики товаров. На витрине карточка открывает товары бренда. При отсутствии логотипа показывается первая буква названия.

Цена, штрихкод, остаток и числовые характеристики сохраняются прямо в списке после выхода из поля или по Enter. Для нескольких вариантов раскройте значение и выберите нужное предложение. Штрихкоды хранятся как последовательности цифр с ведущими нулями. Остатки по складам редактируются отдельно.

В меню «Столбцы» можно показать артикул, изображения и характеристики типов «Число» и «Цена». Перетаскивайте столбцы за ручки у названий и меняйте ширину за край заголовка. Порядок и ширина сохраняются в браузере. Столбец действий закреплён справа. Изображения открываются в лайтбоксе, названия активных товаров ведут на витрину, карандаш открывает редактор.

Стрелки сортируют весь отфильтрованный список перед разбивкой на страницы. Первый чекбокс выделяет товары текущей страницы. Под таблицей доступны активация, деактивация и удаление выбранных. После удаления на страницу подгружаются следующие товары, если они есть.

В карточке нажмите «Добавить характеристику раздела» и задайте название, единицу, тип инфоблока и значение. В настройках магазина выберите округление цен. По умолчанию для русской витрины применяется округление до десятков. Редактор хранит введённую цену, витрина и заказ используют округлённую. Допустимы только положительные цены товаров.

В «Шаблоны оформления → Магазин тем» можно установить тему с демо-страницами из GitHub и отдельно выбрать товары для импорта. В разделе «Обновления» показаны версия маркетплейса, изменения в релизе и прогресс установки.

Карточки имеют постоянный адрес `/shop/product/slug/`. Адрес раздела повторяет дерево категорий. Например, `/shop/instrumenty/dreli/bosch/` показывает Bosch внутри раздела «Дрели». Вторая страница сохраняет поиск, фильтры и сортировку, добавляя `p=2`.

В разделе «Каталог → Товары» список разбит на страницы по 20 товаров. Фильтр ищет по названию, артикулу, штрихкоду, разделу и статусу. По умолчанию видны название, артикул и цена. Дополнительные поля включаются в меню «Столбцы». В конце строки доступны редактирование, копирование и удаление. При копировании создаётся неактивная карточка с новыми артикулами, пустыми штрихкодами и нулевыми остатками. Удаление требует подтверждения.

В карточке задаются название, раздел, адрес, активность, тип, изображение и описание товара. У каждого предложения свои артикул, штрихкод, цена, активность и остаток. Склады добавляются на вкладке «Склады», их остатки задаются в карточке. Доступное количество считается по сумме складских остатков и остатка без склада с учётом оформленных заказов. Импорт обновляет остаток без склада.

Для отдельных таблиц каталога используется CSV в UTF‑8 с разделителем `|` и строкой заголовков. ID товаров и предложений постоянны. В CSV основную цену и другие виды цен указывайте в сотых долях валюты учёта. Листы «Дополнительные разделы», «Изображения» и «Комплекты» управляют размещениями, галереей и составом наборов.

Полное описание правится в том же HTML-редакторе, что и страницы CMS. В нём работают шорткоды. Редактирование HTML доступно администратору CMS. У редактора каталога есть доступ к таблицам и импорту, где текст введённого полного описания безопасно экранируется. Параметры вывода правятся во вкладке «Настройки» маркетплейса. Переменные шаблона записываются как `{{name}}`, `{{url}}`, `{{description}}` и т. п. Набор видно в исходном шаблоне.

Для общего поля оставьте `category_id` пустым. Поля раздела наследуются его подразделами, а размещение в дополнительном разделе тоже делает его поля доступными товару. `target` принимает `product` или `offer`. Тип — `list`, `number`, `boolean` или `text`. Включите `filter` для поля списка, числа или флажка. Для числового поля можно включить `sort`, чтобы появилась сортировка в обе стороны.

## Шорткоды

| Код | Что выводит |
| --- | --- |
| `[shop]` | Полную витрину на текущей странице. Поддерживает параметры `category` и `limit`. |
| `[shop-categories]` | Дерево разделов. Параметр `category=tools` выводит подразделы выбранного раздела. |
| `[shop-items]` | Витрину с пагинацией. Параметры `category=drills limit=24` задают раздел и размер страницы. |
| `[shop-basket]` | Кнопку модальной корзины со счётчиком, в том числе в шапке. Кнопки «В корзину» и обновление количества работают без перезагрузки. |
| `[shop-search]` | Поиск по каталогу или текущему разделу. |
| `[shop-filters]` | Фильтры по цене и доступным характеристикам. |
| `[shop-sort]` | Сортировку по цене, новизне и числовым полям. |
| `[shop-pages]` | Дополнительную пагинацию. Используйте те же `category` и `limit`, что у списка. |
| `[shop-product id=p1]` | Полную карточку определённого товара. |
| `[shop-breadcrumbs]` | Навигацию по дереву разделов. |
| `[shop-cart]` | Содержимое корзины с изменением количества. |
| `[shop-checkout]` | Форму заказа с самовывозом или доставкой. |
| `[shop-account]` | Блок заказов личного кабинета. |
| `[shop-orders]` | Историю заказов текущего пользователя. |
| `[register]` | Регистрацию пользователей сайта. Работает при разрешённой регистрации. |
| `[account]` | Личный кабинет и вход. |

## Заказы, накладные и статистика

На вкладке «Заказы» отображается по 20 заказов на страницу. Раскройте заказ, чтобы увидеть получателя, способ получения, товары и историю. Кнопка «Печать / PDF» открывает накладную с артикулами, вариантами, количеством и адресом доставки. В окне печати можно выбрать принтер или сохранение в PDF.

В меню «Добавить статус» задаются название и влияние статуса на остаток. Ожидающий заказ не резервирует товар. Резерв проверяет доступное количество. Завершение оставляет товары списанными, отмена освобождает резерв.

На вкладке «Статистика продаж» выберите 7, 30 или 90 дней. Графики Chart.js и таблица показывают созданные и завершённые заказы, а также сумму завершённых заказов по валютам. Суммы учитываются на дату завершения. Chart.js включён по умолчанию.

Форма `[shop-checkout]` показывает состав и итог заказа рядом с контактами. Для доставки покупатель указывает адрес. Для самовывоза адрес не требуется.

## Интеграции

Во вкладке «Интеграции» есть настройки Яндекс Маркета, Ozon, Wildberries, Почты России, Яндекс Доставки, СДЭК, SberPay, СБП, ЮMoney и оплаты картами через ЮKassa, Т-Банк, CloudPayments и Robokassa. При установке все модули выключены. Настройте и сохраните ключи перед проверкой соединения.

После оформления заказа покупатель может оплатить его на странице включённого платёжного сервиса. Администратор сверяет оплату в кабинете провайдера перед подтверждением заказа. Публикация товаров и создание отправлений выполняются в кабинетах соответствующих сервисов.

Кнопка «Проверить каталог» показывает совместимые профили интеграций на GitHub. Установка и обновление требуют действительной подписи. Профиль использует встроенный драйвер и собственные настройки. Действительные API-ключи вводятся в админке и хранятся в локальных защищённых данных.

## Импорт, письма и обновление

Во вкладке «Импорт» загрузите CSV или YML, укажите постоянное имя источника, проверьте предпросмотр и примените его. Для CSV можно сопоставить заголовки, например `sku=Артикул`, `name=Название`, `price=Цена`. Запись `field:voltage=Напряжение` связывает параметр импорта с полем `voltage`. Файл с другой валютой требует предварительной конвертации. YML требует расширений XMLReader и SimpleXML. Когда в YML нет количества, остаток существующей позиции сохраняется. У новой позиции без количества он равен нулю.

Регистрация включается в общих настройках CMS. Письма о регистрации, сбросе пароля, заказах и отправке форм редактируются во вкладке «Шаблоны оформления → Шаблоны писем». Кнопка «Добавить шаблон» создаёт собственное письмо, которое можно привязать к событию или форме. Для сброса пароля задайте публичный URL сайта и настройте отправку PHP `mail()`. Ссылка одноразовая и действует 30 минут. Служебные права назначаются через «Сайт и сервисы → Пользователи».

В блоке «Установить или обновить модуль» нажмите «Проверить обновления». CMS сверит отдельную версию маркетплейса с подписанным пакетом в GitHub Releases репозитория `bandaletov72/ewc-lite` и покажет описание релиза. При установке индикатор показывает ход загрузки, проверки подписи и записи файлов. Пакет собирается командой `php update.php --build-shop marketplace.zip`. Каталог, заказы, фотографии и настройки хранятся отдельно от пакета.
